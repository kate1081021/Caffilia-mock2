# カフィーリア シナジーモック 作業報告（REPORT）

## できたこと

`index.html` をダブルクリックで開くと遊べます（外部ライブラリなし・ビルドなし・ネット接続なし）。

**遊び方（3行）**
1. 味方をクリック（または 1〜3 キー）で選び、緑のマスをクリックで移動（最大2マス・省略可）。
2. 魔法を撃つマスをクリック（射程なし）。カーソルを乗せると予測が出る。風と「山に水」は矢印で向きを選ぶ。
3. 3人とも撃つと自動でターン終了。敵が動き、炎・渦巻きが働く。光るマス（強い光＝決め手）を狙って、森・山・川を変化させて決め手で吹き飛ばす。

**実装した内容**
- 盤面 7×7（エディットで 5〜11）、マス9種、魔法5種、シナジー表、山に水（川が流れる・止まった先へ水の効果・山→山の連鎖）
- 決め手3つ（燃え広がり・水蒸気爆発・センタクキ）と、範囲のフラッシュ＋名前の大きな表示
- ターン終了処理（燃え移り → 炎ダメージ → 小さな炎が消える → 渦巻きの引き込み → 敵の行動 → 倒れた者を消す）
- 敵の行動（幅優先探索で一番近い味方へ／隣なら攻撃／道がなければ待つ／泥沼・渦巻き）
- プレビュー（マスの変化・決め手の範囲・ダメージ予測・倒れるかどうか・押される先）、光る導き
- 1手戻す（何回でも）、リセット、ログ（日本語1行ずつ）、勝利・敗北の表示
- エディットモード（地形を塗る＝ドラッグ可、味方・敵を置く／動かす／消す、味方の魔法、敵の動く／止まる、盤面サイズ、地形を全部空きに）
- キー操作（1〜3・M・C・矢印・Esc・Enter・Z・E）、スマホ幅のレイアウト、タッチでは「1回目のタップで予測 → もう一度タップで撃つ」

## 仕様から外れたところ・自分で決めたこと（DECISIONS.md の要約）

- **直撃ダメージ**は仕様に数値がないので 草1・水1・土2・火2・風1 にした。決め手が起きたマスでは直撃は入れず、決め手のダメージだけ。
- **燃え広がりの範囲** ＝ 起点＋風下の通り道（最大4マス）＋燃えた森（つながった森も全部）。通り道の炎・小さな炎・泥沼は止めずにそのまま残す。
- **小さな炎**は燃え移りも、ターン終了時のダメージもしない（仕様で「炎」にだけ書かれているため）。燃え広がりの起点にはなる。ユニットがいる空きマスに火を撃っても小さな炎はできる（作れない制限は草・水・土だけなので）。
- **山に水**で止まった先が山なら、その山からも同じ向きに川が続けて流れる。止まった先にユニットがいれば、地形が自然でも何も起きない。
- **風の向き**は「押す向き」と「燃え広がりの風下」で共通。押せないとき（盤の端・通れないマス・ユニットがいる）はその場に残るだけ。渦巻きの中の者は押されない。
- **泥沼**: 「次の移動を1回休む」。味方が自分のターン中にまだ移動が残っている状態で入ったら、残りの移動がなくなる（これで1回休み）。移動を使い切って入った場合や敵は、次の移動の機会（味方は次のターン、敵は次の行動）を休む。移動の経路は泥沼を通り抜けられない（入ったら止まる）。
- **味方が「終わった」** ＝ 魔法を撃ったこと。生きている味方が全員撃ったら自動でターン終了（移動が残っていても）。移動は2マスを分けて使える。
- **倒れた者**は、ターン終了の6番だけでなく、各魔法のあとにもすぐ消す（倒れた味方が動けてしまうのを避けるため）。勝敗は「その操作で倒れた者が出て、どちらかが全滅したとき」に決まる。
- **敵の道のり**では、他のユニットがいるマスも通れないものとして数える。攻撃する相手は、隣にいる味方のうち番号の小さい方。
- **渦巻きの引き込み**は、渦巻きが複数あるとき盤の左上から順に処理する。すでに別の渦巻きの中にいる者は引き込まれない。
- **光る導き**の薄い光は「自然のマスが変わる所」だけにした。空きマスは草・水・土・火のどれでも何かができるので、全部光ると意味がなくなるため。決め手の強い光はどのマスでも出す。
- **操作**: 味方を選ぶと移動モード。緑のマスなら移動、緑以外のマスならそのまま魔法を撃つ。自分をクリックするか C キーで魔法モード（緑のマスにも撃てる）。撃ったあとは、まだ撃っていない次の味方が自動で選ばれる。
- **エディット**: 抜けると HP 満タン・ターン1 にそろえて、それをリセットの戻り先にする。盤面サイズを変えると、重なる部分は残り、はみ出したものは消える。味方は3人まで、敵は3体まで。

## 実装してみて気づいたこと（設計者向け）

**数値の手ざわり**
- **味方 HP3 は、どの決め手にも一撃で倒される。** 決め手の最低ダメージは4（森なしの燃え広がり）、センタクキの隣ダメージも4。「法則に例外はない」の緊張感は強く出るが、燃え広がりの範囲は「つながった森全部」まで伸びるので、森の多い盤面では味方の立ち位置がかなり縛られる。HP3 が意味を持つのは直撃（1〜2）と炎（2）の時だけで、ほぼ「決め手に巻き込まれたら死ぬ」の二択になっている。
- **敵の攻撃3 ＝ 味方HP3** なので、敵に隣まで来られると1ターンで1人落ちる。敵が歩いてくるのを待つセンタクキ作戦は、味方と敵の間に渦巻きを置けるかどうかの勝負になる。
- **敵 HP20 に対して決め手は 8〜12** なので、「決め手2回で倒す」感覚。直撃は誤差。

**一番安い決め手が「小さな炎＋風」になっている**
- 火の味方が敵のいるマスに撃つ（小さな炎＋直撃2）→ 風の味方が同じマスに撃つ（燃え広がり4）。これで準備なしで毎ターン6ダメージが入る。
- 森を1つ足しても +2 にしかならず、草の味方は1ターンに森を1つしか作れない。「森を並べて大きく燃やす」より「毎ターン小さな炎＋風」の方が速い場面が多い。森を並べる動機を強めるなら、森1つあたりのダメージを上げるか、森なしの燃え広がりを弱める（例: 起点のマスだけ）案がある。

**川の壁が強すぎる**
- 山に水を1発撃つと、盤の端まで一列の川ができる。7×7 だと山1つ＋水1発で盤面を横に区切れて、敵は「道がない」と判断して永久に待つ（テストにもある仕様どおりの動き）。待っている敵は安全に料理できてしまう。
- 「センタクキのために敵を歩かせたいのに、川を作ると敵が来なくなる」というジレンマ自体は面白い。ただ、敵側に「道がなければ川に沿って近づく」「泥沼（橋）を探す」などの対処がないと完封の手段になる。

**射程なしなので、「川を流して遠くのマグマに当てる」利点が薄い**
- どのマスにも直接撃てるので、マグマに直接水を撃てば水蒸気爆発になる。川の流れが活きるのは「川（壁）も同時に作れる」「1手で消火と壁作りを兼ねる」場面だけ。流れを面白くするなら、流れの通り道にいる者を押し流す、などの効果があると「狙撃」の意味が出そう。

**順番の工夫が出て面白かった所**
- 炎の燃え移りはターン終了時に1マスずつなので、森に火を付けたターンに風を撃たないと、隣の森が勝手に炎になって「燃えた森の数」が減る。「火 → 風は同じターンに」という連携が自然に生まれる。
- 小さな炎はターン終了で消えるので、火の味方と風の味方の連携がゲームの中心になる。草・土の味方は準備役で、すぐには効かない。
- **土で川を泥沼にすると、通れない川が通れるマスになる（通行料つきの橋）。** 自分で作った川の壁に「門」を開けて、敵を泥沼で足止めしながら呼び込める。地形を作る役の面白さが出ている所。
- 風で押すと、炎に押し込む（ターン終了で2）、渦巻きの隣に押す（次のターン終了で引き込み）、泥沼に押す（1回休み）など、準備の手として使い道が多い。

**事故が起きやすい所**
- 渦巻きは敵味方を区別せず引き込むので、渦の隣で止まった味方が引き込まれて動けなくなる。そこに仲間がうっかり火を撃つとセンタクキ12で即死する。プレビューでは見えるが、ターン終了時の引き込みは予測に出ないので気づきにくい。
- 決め手が起きたマスに敵が立っていると、決め手のあとで風に押されて範囲の外へ動く（ダメージは先に入るので損はない）。

## 動かない所・既知の不具合

- **タッチ操作のドラッグ塗り**: エディットのドラッグで続けて塗る機能はマウス向け。タッチでは1マスずつタップで塗る（タッチは指を置いた要素に入力が固定されるため）。
- **file:// での操作確認**: 動作確認は、内蔵ブラウザの制約で `tests/serve.js`（http）経由で行った。コードは file:// に依存する機能（fetch やモジュール）を使っていないので、ダブルクリックでも同じ動きになるはずだが、file:// で実際にクリックして確かめてはいない。
- 盤面サイズを変えても、味方を下の段に並べ直さない（重なる部分はそのまま残す）。
- 向きを選ぶ矢印ボタンが隣のマスに重なるので、そのマスの予測バッジ（「→炎」など）が隠れることがある。
- 渦巻きの中の敵は、毎ターン「渦巻きの中で動けない」とログに出るので、少しうるさい。
- ターン終了時の出来事（燃え移り・引き込み・敵の行動）はログには出るが、プレビューや一手ずつのアニメーションはない（結果が一度に反映される）。
