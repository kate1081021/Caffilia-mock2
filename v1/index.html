ログ

    遊び方・ルール早見
    1. 味方をクリックで選ぶ → 緑のマスをクリックで移動（最大2マス・省略可）
    2. 魔法を撃つマスをクリック（射程なし）。風と「山に水」は向きを選ぶ（矢印ボタン／矢印キー）
    3. 3人とも撃つと自動でターン終了。敵が動き、炎や渦巻きが働く

    マスにカーソルを乗せると何が起きるか予測が出ます。薄く光るマス＝変化が起きる、強く光るマス＝決め手。

    マス＼撃つ水土火風
    空き川山小さな炎押す
    森——炎—
    山川が流れる—マグマ—
    川—泥沼—渦巻き
    炎・小さな炎消火——燃え広がり
    マグマ水蒸気爆発———
    渦巻き——センタクキ—

    草は空きマスに森を作るだけ。どの魔法も、撃ったマスのユニットに直撃ダメージ（敵・味方とも）。

    キー: 1〜3 味方選択 / M 移動 / C 魔法 / 矢印 向き / Esc やめる / Enter ターン終了 / Z 1手戻す / E エディット
