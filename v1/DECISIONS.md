# 自分で決めたこと（DECISIONS）

仕様があいまいだった所で選んだ解釈を1行ずつ記録する。

- 直撃ダメージは仕様に数値がないので 草1・水1・土2・火2・風1 にした（`balance.js` の `directDamage`）。
- 決め手が起きたときは、撃ったマスのユニットへの直撃ダメージは入れず、決め手のダメージだけにした（二重に当たらないように）。
- 燃え広がりの範囲 = 起点のマス ＋ 風下の通り道 ＋ 燃えた森（つながった森も含む）。この範囲の全員に1回だけダメージ。
- 燃え広がりの通り道にある「炎」「小さな炎」「泥沼」はそのまま残す（止まらず通り抜ける）。止まるのは仕様どおり 山・川・マグマ・渦巻き・盤の端。
- 小さな炎は「燃え移り」も「ターン終了時のダメージ」もしない（仕様で 炎 にだけ書かれているため）。燃え広がりの起点にはなる。
- 火の魔法をユニットのいる空きマスに撃つと、小さな炎ができる＋直撃（「作れない」制限は草・水・土だけなので）。
- 山に水で川が流れて、止まった先が「山」なら、その山からも同じ向きに続けて川が流れる（「水を撃ったのと同じ効果」の素直な解釈）。止まった先のマスにユニットが乗っていれば、地形が自然でも何も起きない。
- 風の向きは「撃ったマスのユニットを押す向き」と「燃え広がりの風下」で共通（1回の魔法で1つの向き）。
- 押せないとき（盤の端・通れないマス・ユニットがいる）はその場に残るだけ。ぶつかりダメージはなし。渦巻きの中のユニットは押されない。
- 泥沼: 入った者は「次の移動を1回休む」。味方が自分のターン中にまだ移動が残っている状態で入ったら、残りの移動がなくなる（これで1回休み）。それ以外（移動を使い切って入った・敵）は stuck=1 になり、次の自分の移動の機会（味方は次のターン、敵は次の敵の行動）を休む。
- 味方の移動経路は泥沼を通り抜けられない（泥沼で止まる）。他のユニットのマスも通れない。
- 移動は2マスを分けて使える（1マス動く → 魔法 → 1マス動く も可）。
- 味方の「終わった」＝魔法を撃ったこと。生きている味方が全員撃ったら自動でターン終了処理へ（移動が残っていても）。移動だけしたいときは「ターン終了」ボタン。
- HP が0以下になったユニットは、ターン終了の6番だけでなく、各操作（魔法）のあとにもすぐ盤面から消す（倒れた味方が動けてしまうのを避けるため）。ターン終了処理中は 6番 でまとめて消し、それまでの間 HP0以下の敵は行動しない。
- 敵が全員倒れたら「勝利」、味方が全員倒れたら「敗北」と表示して操作を止める（1手戻す・リセット・エディットは使える）。
- 敵の道のり（幅優先探索）は、他のユニットがいるマスを通れないものとして数える。目的地（味方のマス）は地形に関係なく到達点にできる（渦巻きの中の味方にも近づける）。
- 敵が攻撃する相手は、隣にいる味方のうち番号の小さい方。
- 渦巻きの引き込みは、渦巻きが複数あるとき盤の左上から（行ごと）順に処理。すでに別の渦巻きの中にいる者は引き込まれない。
- ログでの味方の名前は「味方「火」」のように持っている魔法の文字。同じ魔法の味方が2人以上いるときは後ろに番号を付ける。敵は 敵A・敵B・敵C。
- 勝敗は「その操作で倒れた者が出て、その結果どちらかが全滅したとき」だけ決まる（最初から敵0体の盤面などでは勝敗をつけない）。
- 光る導きの「薄い光（変化）」は、空きマス以外（自然のマス）が変わる所だけにした。空きマスは草・水・土・火のどれでも何かができるので、全部光って意味がなくなるため。決め手の強い光はどのマスでも出す。
- 操作: 味方を選ぶと「移動モード」（移動できるマスが緑）。緑のマス→移動、緑以外のマス→そのまま魔法、自分をクリック or C キー→「魔法モード」（緑のマスにも撃てる）。他の味方は一覧かキー 1〜3 で選ぶ（魔法モード中に盤面の味方をクリックすると、その味方に撃つ＝味方への直撃も可能）。
- 魔法を撃ったら、まだ撃っていない次の味方が自動で選ばれる。
- 向きが必要な魔法（風・山に水）は、カーソルを乗せた時点では「最後に使った向き」でプレビューする（矢印キーで変更可）。クリックすると矢印ボタンが出て、ボタンに乗せた向きでプレビュー、クリックか矢印キーで決定。
- 決め手の演出は、範囲のマスを約1秒フラッシュ＋盤面中央に名前を大きく表示（1.6秒）。
- 1手戻すは、移動・魔法・ターン終了・リセット・エディット操作をすべて1手として戻せる（最大500手）。自動ターン終了は、最後の魔法と合わせて1手。
- エディットで盤面サイズを変えると、重なる部分の地形とユニットは残り、はみ出したものは消える（味方を下の段へ並べ直すことはしない）。
- エディットを抜けると、全員の HP を満タン・ターン1・泥沼のはまりを解除した状態にそろえ、それをリセットの戻り先にする。
- 味方は3人まで、敵は3体までエディットで置ける（balance.js で変更可）。
- タッチ操作では、1回目のタップで予測を表示し、同じマスをもう一度タップで撃つ（カーソルを乗せられないため）。
