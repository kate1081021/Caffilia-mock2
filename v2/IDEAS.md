## 1つずつ（想像できるか・検証の結果・気になる点）

### 噴火（外へ広がるように直した）
- 想像: 山に火 → 火山 → 溶岩があふれる。山が大きいほど大きく噴く。
- 検証: 1発で変わるマスは 山1つ→6、3つ→10、6つ→16、9つ→21（溶岩が外へ流れる前の数字。流れるようにしたので今はもっと多い。山3つで溶岩16マス）。
- 気になる点: **山を盛った本人が溶岩に巻き込まれやすい**（土は2〜3マス先に盛るので、溶岩の届く範囲に立っている）。盛ってから1ターン離れる、が必要。敵の火がこちらの山に当たっても噴火するので、山を盛るほど危ない。
- 見せ場: デモ「山脈を盛って、離れて火 → 噴火で溶岩があふれ、風で桜吹雪」（8×8）。

### 竜巻 → 火炎竜巻／センタクキ
- 想像: 風が渦を巻いて残る → 育って竜巻 → 火が入ると火の竜巻（現実の火災旋風）、水が入ると洗濯機のように回る（空想）。「風が先、最後に水」の順にした。山は要らない。
- 検証: 自動プレイ（1手先しか読まない）ではほとんど起きない（20戦でセンタクキ1回）。**風を2ターンかけて育てる必要がある**ため。見せ場デモでは期待どおりに動く。
- 気になる点: 風を撃つたびに、つむじ風があちこちに残る。竜巻の見た目は回転する模様だけ（控えめ）。

### 氷の上は滑る（残す候補）
- 想像: 凍った川で押されたら滑る。誰でも分かる。
- 検証（凍った湖の上の敵に、風を全部の位置と向きから撃つ）: 2マス以上動かせる撃ち方 **0 → 10**、炎の上まで運べる撃ち方 **0 → 2**。
- 良い点: 凍結のあとに「敵を遠くへ運ぶ・炎や泥沼に送りこむ」という使い道が生まれる。やってみたかったこと「敵の進路を誘導する」に近い。

### 水辺の森はよく育つ（残す候補）
- 想像: 川沿いの森はよく茂る。
- 検証（川のそばで草を全部の位置と向きから撃つ）: 森の数の平均 **1.62 → 2.37**、いちばん多いとき **4 → 6**。水のない所では変わらない。
- 良い点: 「水 → 森 → 燃え広がり」と、別の自然が燃え広がりの材料を増やすつながりができる。

### 土をかぶせて火を消す（残す候補）
- 想像: 焚き火に土をかけて消す。
- 検証（「火の敵」で敵が火を撃ったあと）: 土1発で火を消せる撃ち方 **0 → 22 / 124**。1発で消せるのは1マスまで。
- 良い点: 土に「守り」の役目ができる。燃え移りの前に止められる。

### 燃え広がりは氷を溶かす（様子見）
- 想像: 火が氷の上を走れば溶ける。
- 検証: 燃え広がり1発で戻る氷 0 → 2。遊びはほとんど変わらない。ないと「火が氷の上を走っても氷のまま」で違和感が出るので、つじつま合わせとして置いている。

### 風で蜃気楼が晴れる（消す候補）
- 想像: 風で陽炎や霧が晴れる。
- 検証: だれもいない蜃気楼を消せる撃ち方 0 → 10。ただし、**中に隠れている者は、この案がなくても風で押し出されて見つかる**ので、遊びへの影響は小さい。

## 全体への影響（自動プレイ20戦 × 8シナリオ、小さな案を全部入れた／切った）
- 勝ち負けの数の差は、20戦の振れ幅の中に収まった。**小さな案は、ゲーム全体の流れを壊していない。** 新しい選択肢を足すだけになっている。
- 「燃え広がり」「桜吹雪」シナリオでは、入れたときに勝ちが少し増えた（3勝→4勝、0勝→3勝）。偶然の範囲かもしれない。

## 見つけた問題と直したもの
- 「【新案】竜巻」シナリオは、何もしないと1ターン目に全滅していた → 敵を1体・(3,0) に変えて、1ターン目は安全にした。デモでは、敵が竜巻の中にとらわれる形になった。
- 噴火の見せ場は、探索では「作った本人が巻き込まれない手順」が見つからなかった → 手で組んだ（土は盛ってから離れる）。
