# IMPROVE_tutorial1 — チュートリアル①「重ねる」

10/17 展示用のチュートリアル、1つ目のステージ。今の標準（IMPROVE_enemy・IMPROVE_fire・IMPROVE_mission のあと）に足す変更。
細かい決めごとは `DECISIONS.md`、シナジーの一覧は `SYNERGIES.md`。

## 目的

- 展示で最初に触るステージ。知らない人が説明なしで、1〜2分で次のことを体験できるようにする。
  - **味方が構えている魔法に、自分の魔法を重ねるとシナジーが起きる**
  - **敵ではなく、関係なさそうなマスに撃った一手で勝てる**
- 教えることは「重ねる」の1つだけ。迫ってくる敵・お題・強化は出さない。
- テキスト・世界観の説明は入れない。**盤面と表示だけで伝わるか**を確かめる。

## 大前提

- **このステージの数値は、このステージの中だけで上書きする。** 標準の値（風は正面2マス、燃え広がりは最大4マス など）と、ほかのシナリオの挙動は一切変えない。
- 今あるテスト（`tests/run.js`・`tests/scenarios.js`）は、変更後もすべてそのまま通ること。

## 変えること

### 1. ステージごとの数値の上書き

- シナリオに `overrides` を持たせ、`balance.js` の値をそのシナリオの間だけ上書きできるようにする。
- JSON の保存・読み込みに `overrides` を含める。
- このステージで上書きするもの:
  - 風の形: **正面1マス**
  - 燃え広がりの長さ: **3マス**
  - 移動: **2マス**（標準と同じならそのまま）

### 2. 構える味方（指示できない味方）

- 味方に「構える味方」を足す。プレイヤーは選べない・動かせない・撃たせられない。
- 毎ターン、**同じ位置・同じ向きで同じ魔法を構え直す**（このステージでは右向きの風）。
- 構えた魔法は **発動フェーズ** で撃つ。手番は今の流れのまま:
  敵の移動と予告 → 味方（プレイヤー）→ **発動（構える味方 → 敵の順）** → ターン終了処理
  - プレイヤーの火が先に置かれ、そこに風が吹くので「火 → 風 ＝ 燃え広がり」になる。風が先に盤面に残ると火の渦になってしまうので、構える味方の風は発動まで盤面に置かない。
- 表示は敵の予告と同じ形（形のマス・変わるマス・決め手の範囲・誰に何ダメージ）で、**色だけ変える**（敵は赤系、構える味方は青系など）。
  - 構えている向きの矢印と、狙っているマスの枠を常に出す。
  - プレイヤーが火を構えて予測を出している間は、**撃ったあとの盤面で構える味方の結果を計算し直す**（敵の予告と同じ扱い）。正しく構えると「燃え広がり・敵 -20」が見える。
- 構える味方も味方なので、ダメージは受ける（法則は同じ）。

### 3. このステージの風

- 正面1マスに吹く。そのマスにあるものによって:
  - **ユニット**: 風の向きに1マス押し出す（押した先が通れなければ動かない）
  - **火（弱い火）・炎**: 風の向きに **3マス先まで燃え広がる**。通り道とつながった森はまとめて燃える（森の上は強い炎 20、それ以外は今の決めごとどおり）
  - **何もない**: 何も起きない
- 弱い火は、ターン終了で隣の森へ **燃え移らない**（今の決めごとどおりのはず。違っていたら合わせる）。

### 4. 外したときのヒント

- 敵が残ったままターン終了を **1回** 迎えたら、次のターンから **構える味方が狙っているマス（2-2）を光らせる**。
- 光り方は控えめに（点滅かふちの色）。文字は出さない。

### 5. 敵

- 敵の個性に「動かない」を足す。移動しない・魔法を撃たない・予告を出さない。
- HP・ダメージの受け方は標準どおり（強い炎 20 で倒れる）。

### 6. シナリオ「【チュートリアル】① 重ねる」

5×5。座標は（行, 列）、左上が（1, 1）。

```
     1      2     3    4    5
1    ・     ・    ・   森   森
2  風使い→  ・    ・   森  敵(森)
3   自分    ・    ・   ・   ・
4    ・     ・    ・   ・   ・
5    ・     ・    ・   ・   ・
```

- 風使い（構える味方）: （2, 1）、右向き、風を構える
- 自分（炎・プレイヤー）: （3, 1）。火は正面1マス
- 森: （1, 4）（1, 5）（2, 4）（2, 5）の 2×2
- 敵: （2, 5）、森の中、「動かない」
- ほかのマスには何も置かない
- お題: 全滅（`annihilate`）
- **正解の手順**: 自分が（3, 2）へ1マス動き、上を向いて（2, 2）に火 → 発動で風が吹き、（2, 3）〜（2, 5）へ燃え広がる → 森ごと燃えて敵が倒れる
- 初期シナリオの一覧に入れ、すぐ選べるようにする。

## 確かめること

- `node tests/run.js` と `node tests/scenarios.js` がすべて通る。テストを足す:
  - `overrides` がそのシナリオの中だけで効き、ほかのシナリオに漏れない
  - 構える味方が毎ターン同じ所に構え直し、発動フェーズで撃つ
  - 構える味方はプレイヤーが選べない・動かせない
  - 正解の手順で、1ターンで勝てる
  - （2, 3）に火を置いた場合は勝てない（弱い火は燃え移らない、風も当たらない）
  - 外したあとのターンで（2, 2）が光る
  - 敵が動かない・撃たない
  - 風がユニットを1マス押し出す
- `tests/scenarios.js` に、このステージを勝ち切る手順を1つ。
- 内蔵ブラウザで最初から遊び、次を見る:
  - 風使いが「撃とうとしている」のが、説明なしで分かるか
  - 火を構えたとき、プレビューで答えが分かるか
  - 外したとき、「何も起きなかった」が分かるか
  - コンソールエラーがないか

## REPORT に書いてほしいこと（設計者向け。遠慮なく）

- 構える味方の表示で「味方が何をしようとしているか」が伝わりそうか。敵の予告と見分けがつくか。
- プレビューで答えが見えすぎて、自分で見つけた感が消えていないか。
- 外したときの盤面の変化（火が消えるだけ・風が空に吹くだけ）で、失敗が伝わるか。
- 1ターン目の正解率がどのくらいになりそうか（手で試した感触でよい）。
- 違和感のあったところ。

## 終わったら

- `DECISIONS.md` に「チュートリアル①:」として決めたことを足す（上書きの仕組み、構える味方の手番の位置、光らせ方など）。
- `REPORT.md` に今回の報告を足す。

## やらないこと

- テキスト・世界観の説明（ガイド文・セリフ）。
- チュートリアル②③、ステージをまたぐ進行（クリアしたら次へ、など）。
- 見栄え（演出・アニメーション・絵）の作り込み。
- 標準の数値の変更、新しい魔法・新しい自然を足す。
