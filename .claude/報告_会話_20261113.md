## 1. データの書き方

くわしくは `docs/会話の書き方.md`。

### キャラの登録（`game/chars.js`）

```js
var CHARS = {
  charA: { name: 'キャラA', color: '#c2410c', faces: { normal: '' } },
  charB: { name: 'キャラB', color: '#1d4ed8', faces: { normal: '' } }
};
```

- `name` 名札の名前／`color` 名札と仮の絵の色／`faces` 表情の名前 → 絵のファイル（`game/img/` の画像）。
- 絵が空のあいだは、色と名前の字で作った仮の絵が出る。絵を入れるときは `normal: 'game/img/char_a.png'` のように書く。
- 表情を足すときは `faces` に行を足し（`smile: '…'`）、会話の行に `face: "smile"` と書く。
- 登録したキャラは、どのステージの会話にも出せる。

### 会話（ステージの定義の `talk`）

```json
"talk": {
  "before": [
    { "who": "charA", "side": "left",  "text": "敵が村へ走ってくる。しかも次々に増える…倒しきれないよ【仮】" },
    { "who": "charB", "side": "right", "text": "倒さなくていい。村への道をふさげば守れる【仮】" },
    { "who": "charA", "side": "left",  "text": "山と水で、道をふさぐんだね【仮】" }
  ],
  "after": [
    { "who": "charA", "side": "left",  "text": "山に水を当てたら、川になって流れた！【仮】" },
    { "who": "charB", "side": "right", "text": "水は山の斜面を下って川になる。川は、敵の通れない壁になる【仮】" }
  ]
}
```

- `before` まえげき／`after` あとげき。1行は「どのキャラが（`who`）・どちら側に出て（`side`）・何を言うか（`text`）」。
- `who` に登録のない名前を書くと、その名前の仮の絵で出る。`who` を空にすると語り（キャラなし）。

### エディットで書く

エディットの右の欄に「会話」を足した。1行が1つの文。

```
左 キャラA「敵が村へ走ってくる。倒しきれないよ」
右 キャラB「倒さなくていい。村への道をふさげば守れる」
```

- 「まえげきを見る」「あとげきを見る」で、今の欄の中身をその場で流せる。
- 「見たしるしを消す」で、また初めてのように出る（確かめ用）。

### 入切と見た目

| 変えたいもの | 場所 |
|---|---|
| 並びごとに出す・出さない | `game/balance.js` の `talk.show`（`tutorial`・`shared`・`own`・`exhibit`。今は展示だけ切） |
| 重ねる層の色と透明度 | `game/style.css` の `--talk-veil`（1か所） |
| 文の窓の色 | `game/style.css` の `--talk-box` |

### いつ出るか

| | 出る | 出ない |
|---|---|---|
| まえげき | そのステージを初めて始めたとき | やり直し・リセット・2度目から |
| あとげき | 初めて勝ったとき（手の演出が終わってから） | 負け・2度目の勝ち |

「初めて」は、開発モードではそのブラウザが覚える。展示モードでは、題字の画面に戻るまで（次の人にはまた出る）。

### ステージの途中の会話を、あとで足す所

`talk` は「名前 → 行の並び」にしてある。`before`・`after` のほかの名前（たとえば `volcano`）を今から書いておける（今は出ない）。足すときは、条件（`conditions`）に `then: "talk"` と会話の名前を書き、条件のしくみから会話を出す形にする。画面の側は、名前を渡せば流せる作りになっている。

## 3. 画面で動かさないとわからない所・気になる所

1. **公開先のチュートリアルには、仮の会話が付かない。** 公開先の置き場所のチュートリアルは、コードの①②③ではなく、みんなのステージから移してきた3つ（id が `t`＋時刻）になっている。コードの仮の会話は、id が同じ（`tut1`・`tut2`・`ex3`）ときだけ出る。公開先で試すには、公開したあと、開発モードでそれぞれのチュートリアルを開き、会話の欄に書いて「チュートリアルに保存する」が要る（置き場所の中身は、こちらでは書きかえていない）。
2. **③は確かめていない。** ③のまえげきが出る所と、ボスを倒してあとげきが出る所は、画面では動かしていない（データが入っていることと、①②と同じ道を通ることだけ）。
3. **読まれるか・長さ・見た目。** 仮の絵は色のついた人の形で、画面の半分近くを使う。文の窓は下に横長。層の濃さは仮（後ろの盤面はかなり見える）。試遊で見てから直す所。
4. **スマホやタブレットの縦長の画面**では見ていない（パソコンの横長だけ）。
5. **あとげきの出る間。** 勝った手の演出が終わってすぐ（0.35秒おいて）出る。決め手の余韻を切っていないかは、見て決めたい。
6. **展示モードを入にしたとき**: あとげきを読み終えてから「次へ」が出る作りにしたが、通して（①→②→③→ありがとう）は動かしていない。
7. **みんなのステージ・自分のステージ**に会話を書いて遊ぶ所は、画面では試していない（同じ欄・同じ道）。自分のステージの「初めて」は名前で覚えるので、名前を変えるとまた出る。
8. 会話の欄で Ctrl+Z を押すと、欄の中の取り消しになる（盤面の「1手戻す」ではない）。
