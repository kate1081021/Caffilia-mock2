## 0. ねらい

- **盤面が勝手にずれない。** 盤面の上で、出たり消えたり長さが変わったりするものをなくす（絶対）。
- **盤面のクリックに変なものを持たせない。** 味方にさわる（選ぶ・動く）と、押したマスを出すことだけ。
- **見るところ（右上）と、さわるところ（右下）を分ける。** 押すボタンは右下にまとめる。

## 1. 全体の配置

```
┌ 上のバー ──────────────────────── [1手戻す][遊び方] ┐   ← 「発動」は外す
│                                                               │
│ 盤面の上（高さはいつも同じ）        右上：見るところ          │
│  目標 / お題 / 勝ち / ターン 4/5     味方  (山)(水)(火)        │
│  [絵] 森      通れない               発動の順番 ▲▼            │
│  [駒] 味方「山」 HP3/3 構えた        敵    A … / B …          │
│  案内の1行                                                    │
│ ┌ 盤面 ───────────┐       右下：さわるところ        │
│ │                        │              ↑                  │
│ │                        │         ←  向き  →   [ 魔法 ]   │
│ │                        │              ↓       [ 待機 ]   │
│ └────────────────┘       [ 発動／クリアする／次へ／やり直す ] │
└───────────────────────────────────────┘
```

- 「クリアする」（②）と「やり直す」（負けたとき）は、盤面の上から外して右下のボタンにまとめる。
- 盤面に重ねて真ん中に出す形は採らない（盤面が隠れるため）。

## 2. 盤面のクリック

| 押した所 | 起きること |
|---|---|
| 味方 | その味方を選ぶ（選べる味方のとき） |
| 緑のマス | 選んでいる味方がそこへ動く。元のマスを押すと戻る（今のまま） |
| どこでも | 押したマスを左上に出す（3-2） |
| 味方以外の、動けないマス | 選ぶのをやめる（今のまま） |

- **なくす:** 誰も選んでいないときに押して進む働き（発動・②のクリア・展示でクリアしたあとの次へ）。
- **なくす:** 発動の演出の途中で押して飛ばす働き（キーでは飛ばせる。6章）。
- 薄い味方（4-1）を押したときは、選ばない。マスの情報が出るだけで、「もう行動しました」も出さない。

## 3. 盤面の上（高さを変えない）

盤面の上の段は、それぞれ高さを決めておく。中身が変わっても、空になっても、高さは変えない。
**確かめ:** 選ぶ・動く・構える・発動・クリア・負け・やり直し・ミッション達成のあいだで、盤面の上端の位置が1ピクセルも変わらない。

### 3-1 目標の帯

```
目標    山と水で道をふさいで、村を守る【仮】
お題:   防衛
勝ち    ターン5の終わりまで村を守る（…）
ターン  4/5
```

- 目標・お題・勝ち は残す。
- 防衛の **村の行（「村 村1 HP1・村2 HP1…（壊れた 1）」）は消す。** 村の HP は、村のマスを押せば左上に出る。
- ターンは、決着の前もあとも **「ターン 4/5」の形** にそろえる（今は決着の前が「残り2ターン（今 4/5）」で、長さが変わる）。
- 状態の文は `rules.js` の `missionInfo` が作っている。`status` をテストで見ている所はない（`win` だけ）。
- ③のミッション（「□」→「✔ ミッション達成！」）も、変わっても高さを変えない。

### 3-2 押したマスの情報（左上）

```
┌──────────────────────────────────┐
│ [森の絵]  森        通れない              │  ← 地形の絵・名前・印
│ [山の駒]  味方「山」 HP 3/3  構えた・火傷  │  ← 駒の絵・名前・HP・ようす
└──────────────────────────────────┘
```

- **アイコン（絵）＋名前。** 名前は残す。
- 印・ようすは **今の短い文のまま** 名前のうしろに並べる。
  - 地形の印: 通れない・入ると止まる・ゴール・帰り口・宝
  - 駒のようす: 構えた・待機・移動した・泥沼で休み・宝を持つ・火傷
- **いつも2行。** 駒がいなければ2行目は空けておく。何も押していないときも2行分の高さをとる。
- 並びきらない分は、はみ出さずに切る（重なることは少ない）。
- **座標はなくす。**

### 3-3 そのほか盤面の上にあるもの

- 案内の1行: 高さを決めておく（折り返しても伸びない）。勝ち負けの文も、ほかと同じ字の大きさ。
- やり直したあとのヒントの1行: 出ていないときも場所をとっておく。
- 「クリアする」「やり直す」: 盤面の上から外す（5章の右下のボタンへ）。

## 5. 右下：さわるところ（コントローラー）

```
        ↑
   ←  向き  →    [ 魔法 ]
        ↓        [ 待機 ]
   [ 発動 ／ クリアする ／ 次へ ／ やり直す ]
```

### 5-1 向きと魔法

- 十字の矢印ボタン4つ（今ある）。押すとその向きになり、盤面の魔法のプレビューもその向きに変わる（今のまま）。今向いている矢印は選ばれた見た目（今のまま）。
- **十字の真ん中は「向き」**（今は魔法の名前）。
- 「魔法」「待機」は今のまま。**撃てないときは、魔法ボタンに理由を書く**（例:「宝を持つので撃てない」。展示では使っていない）。
- **なくす:**「味方「山」　その場　向き ↑」の行（`actInfo`）、「移動を取り消す」ボタン、誰も選んでいないときの「味方を選ぶと、ここで…」の文。
- 誰も選んでいないときは、矢印・魔法・待機は押せない見た目（今の `.off` と同じ）。

### 5-2 右下のボタン（1つ。同じ場所で文字が変わる）

| とき | 文字 | 押すと |
|---|---|---|
| まだ構えていない味方がいる | 発動（押せない） | — |
| 全員が構えた・待機した | 発動（光る。今の `fire-ready`） | 発動 |
| ②で村への道をふさいだ | クリアする | クリア |
| 展示でクリアした | 次へ | 次のステージ・ありがとう！・クリア！ |
| 負けた（チュートリアル） | やり直す | そのステージの頭から |
| 発動の演出の途中 | 押せない | — |

- 上のバーの「発動」（`btnEndTurn`）、盤面の上の「クリアする」（`btnSealWin`）「やり直す」（`btnRetry`）はなくし、このボタン1つにする。
- 「次へ」は今と同じく、会話の窓を閉じて0.4秒あけてから押せる（`EXHIBIT_NEXT_MS`。同じ場所なので、発動の連打で次のステージへ飛ばないように）。
- ③で負けたときは今のまま（少し見せて自動でやり直す）。

### 5-3 右上と右下の置き方

- 右の欄を、右上（味方・発動の順番・敵）と右下（5-1・5-2）に分ける。
- 右上の中身が変わっても、右下のボタンの位置が動かない置き方にする。

## 6. キー

- **矢印キーで向きを変えるのは、開発モードだけ。** 展示モードでは、向きは十字のボタンだけ。
- ほかのキーは **おまけで残す**（展示も開発も）:
  - Enter … 味方を選んでいれば「魔法」。選んでいなければ右下のボタンと同じ
  - W 待機 ／ 1〜3 味方を選ぶ ／ Esc 移動を戻す・選ぶのをやめる ／ Z 1手戻す
  - 発動の演出の途中で押すと飛ばす
- 会話の窓が出ている間の Enter・スペース（次の文へ）は今のまま。
- 開発モードのエディットの矢印キー（駒の向き）は今のまま。

## 7. 文

### 7-1 遊び方（展示）

オーナーの文（10/31）に、この仕様で変わる所だけ直したもの。直した所に ※。

```
あそびかた
味方を選ぶ：味方をクリックします。
動く：緑のマスをクリックすると、そこへ動きます。やめたいときは、元のマスをクリック。 ※
構える：十字の矢印で向きを決めて「魔法」。撃たないときは「待機」。
順番を決める：魔法は「発動の順番」の上から起こります。先に起きた魔法に後の魔法が重なると、シナジーが生まれます。▲▼で入れ替えられます。
発動：全員が構えると、右下の「発動」を押せます。 ※
進める：迷ったら右下のボタン。クリアしたあとも、ここを押すと先へ進みます。 ※
困ったら：「1手戻す」でひとつ前に戻れます。マスをクリックすると、そのマスのことが左上に出ます。
```

- `texts.js` の `howto` をこれに置きかえる（今の5行と、`mode` の出し分けは外す）。

### 7-2 「盤面をクリックか Enter で」をなくす

- `texts.js`: `readyToFire`・`sealReady`・`exNext`・チュートリアル①②の始めの【仮】の文 → 「右下の〇〇を押す」形に【仮】。
- `ui.js` の同じ文の既定値、`index.html` のコメントも合わせる。
- 処理中の文「処理中…（盤面のクリックかキーで飛ばせます）」→「処理中…」。
- `guideRestance`（構え直しの案内）は使わなくなる。
