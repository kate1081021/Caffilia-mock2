# IMPROVE_v3 — 開発モードの整理・ステージの共有・展示の並び

10/30 にオーナーと相談して決めたことをまとめた仕様書。
**オーナーが確かめてから作り始める。** 食い違う所は、この文書が正しい。

## 0. ねらい

- これからは **ステージエディターを本流** にして、ステージを作って・遊んで・展示に出す。
- 使っていない開発モードの道具は **アーカイブ** して、分かりやすく・伝えやすくする。
- 作ったステージを **ほかのパソコンでも遊べる** ようにする（クラウドに置く）。

```
遊ぶ   → 展示  index.html   最初の画面 → ステージを遊ぶ
作る   → 開発  #dev         ステージの一覧 → 遊ぶ ⇄ 作る（E）
試す   → 開発  #dev         試し中の機能（あるときだけ）
共有   → Cloudflare（今の公開先）にステージと展示の並びを置く
```

## 1. モード

| URL | モード | 中身 |
|---|---|---|
| `index.html`（印なし） | 展示 | 2〜3章 |
| `index.html#dev` | 開発 | 4〜6章 |

- **作るモード（`#make`）はなくす。** `#make` で開くと、印なしと同じ展示モードになる。
- 開発用の入口（`#review`・`#run`・`#q`・`#n`・`#trial`・`#today`・`#tune=…`）もなくす。開くと展示モードになる。
- 右下の点（2秒長押し）は残す。展示 ⇄ 開発 の行き来に使う。印なしで開いた展示モードでは何もしない（今と同じ）。
- どちらのモードも、ルールは同じ（一斉発動・③はつながる・`balance.js` の値）。調整パネルがなくなるので、値を変えるのは `balance.js` だけ。

## 2. 展示モードの流れ

```
最初の画面
  [はじめから遊ぶ] ──→ 並び（はじめから）の順に1つずつ ──→ ありがとう！
  [ステージを選んで遊ぶ] ─┐                                  ├ [最初の画面に戻る]
                          │                                  └ [ほかのステージで遊ぶ] ─┐
                          ↓                                                              │
                 選んで遊ぶの一覧（開発で選んだものだけ） ←──────────────────┘
                          ↓
                    1つ選んで遊ぶ → クリア！ ─┬ [最初の画面に戻る]
                                              └ [ほかのステージで遊ぶ]
```

- **最初の画面は新しく作る。** 今は、開くとすぐチュートリアル①が始まる。
- 「はじめから遊ぶ」: クリアすると、今と同じように少し見せてから次のステージへ進む。
- 「ありがとう！」の文は「ここまで遊んでくれてありがとう！」【仮】。
- 負けたときは、今と同じく、そのステージの頭からやり直す。
- 並びが空の段は、そのボタンを出さない（両方空なら、チュートリアル①②③を「はじめから」の並びにする）【仮】。
- 遊び方の窓は今のまま残す。

## 3. 展示の並び（開発モードで決める）

```
開発 ─ 展示の並び
  ⚠ 注意！ここを変えると、展示モードの並びがどのパソコンでも変わります

  ┌ はじめから遊ぶ の順番 ─────┐
  │ ≡ ① 重ねる                   │  ドラッグで並び替え
  │ ≡ ② 2人で守る        外す   │  チュートリアルも動かせる・外せる
  │ ≡ ③ 3人でつなぐ      外す   │
  └──────────────┘
  ┌ 選んで遊ぶ に出すもの ────┐
  │ ≡ 〇〇の森           外す   │
  │ ≡ △△の川           外す   │
  └──────────────┘
  ＋ 足す（チュートリアル・みんなのステージから選ぶ）

  [この並びで展示する] → ⚠ 確かめの窓「本当に変えますか？」→ はい → 展示モードが変わる
```

- 合言葉は付けない（子どもは開発モードを使わない）。開いたときに注意を出す。
- 画面の中で並べ替えている間は、展示モードは変わらない。「この並びで展示する」→ 確かめで「はい」のときだけ変わる。
- 同じステージを、上の段と下の段の両方に入れてもよい【仮】。
- **並びに入っているステージを上書きで共有し直すと、展示モードもすぐ新しい方になる**（確かめの窓は通らない。オーナー判断）。

## 4. 開発モードの最初の画面

```
┌ 開発 ──────────────────────────────┐
│ チュートリアル      ① ② ③                              │
│ みんなのステージ    〇〇の森  △△の川 …   （クラウド）  │
│ 自分のステージ      このブラウザに自動で残したもの [消す] │
│                                                          │
│ [新しく作る]  [展示の並び]                              │
│ 試し中: □ 〇〇   （試している機能があるときだけ出す）   │
└────────────────────────────┘
```

- ステージを押すと開いて、**遊ぶ側から始まる。** E（✎／▶）で 遊ぶ ⇄ 作る を切り替える（今のエディットと同じ）。
- 作る側にしたとき:
  - チュートリアル → 自分のステージに「〜のコピー」ができる（元は変わらない）。
  - みんなのステージ → 自分のステージに **同じ名前の写し** ができる。**共有するまで、みんなのステージは変わらない。**
  - 自分のステージにもう同じ名前があるときは、次を出す。

    ```
    ┌ 自分のステージにも「〇〇の森」があります ────┐
    │ [自分のステージを開く]                          │
    │ [みんなのステージの形で置きかえる] ⚠            │  ← 自分のステージで直していた所が消える。確かめを出す
    └────────────────────────┘
    ```
- 開いているステージから最初の画面に戻るボタンを置く。
- 「新しく作る」: 今と同じく味方3人・敵1体の盤面から。**押した時点で、自分のステージが1つ増える。**
- 自分のステージの「消す」には、⚠ 確かめを出す。
- エディットの中身（置く・動かす・消す・盤面の大きさ・勝ち方・会話の文・1手戻す）は今のまま。

### 4-1. エディットのステージ欄

```
ステージ
 名前 [〇〇の森]
 [共有する]
 みんなのステージにはまだありません   ← 共有のようす（5章）
```

- **保存ボタンはなくす。** 自分のステージは、直すたびにこのブラウザに自動で残す。「作りかけ」の枠はなくなる。
- **ファイルに書き出す／読み込む と、JSON（文字）で書き出す・読み込むはなくす。** ステージのやり取りはクラウドだけにする。
  - ただし、ファイルの書き出す・読み込むの2つは **段4（共有）ができるまで残す**。それまでは、ブラウザの外に逃がす手がほかにないため（8章）。
- 一覧・読み込む・削除・新しいステージは、最初の画面（上）へ移す。最初の画面ができるまでは、エディットの中に残す。
- ネットにつながっていないときは「共有する」を押せず、「ネットにつながっていません」と出す。

## 5. 共有（みんなのステージ）

```
自分のステージ ─[共有する]→ みんなのステージ（Cloudflare）
                                 │ 開発モードなら、どのパソコンでも遊べる・直せる
                                 └─ 展示の並びに足せる（3章）
```

- **置き場所は Cloudflare。** 今の公開先（`https://caffilia-jkwzvlbc7.kate108superstar.workers.dev`）に、ステージと展示の並びを入れておく場所（Workers KV）と、出し入れする小さなプログラムを足す。新しいアカウントは要らない。
- 置くものは、盤面の定義と会話の文。
- 自分のステージの「共有する」（4-1）で、みんなのステージに置く。
- **同じ名前で共有すると上書き。** 先に「同じ名前のステージがあります。上書きしますか？」と確かめる。

### 共有のようす（ステージ欄に出す文）

| 自分のステージ と みんなのステージ | 出す文 |
|---|---|
| まだない | みんなのステージにはまだありません |
| 同じ | みんなのステージと同じです |
| 自分が直した | 共有したあとに直した所があります |
| ほかの人が直した | ほかの人が直しています |
| 両方が直した | 共有すると、ほかの人が直した所が消えます ⚠ |

- どちらが直したかは、最後に共有したとき（または、みんなのステージから写したとき）の形を覚えておいて、くらべて分ける。
- 「両方が直した」ときに「共有する」を押すと、⚠ の確かめを出してから上書きする。
- **消す:** 開発モードで消せる。⚠ 注意の確かめのあとに消える。**展示の並びに入っているものは消せない**（「展示の並びから外すと消せます」と出す）。
- 公開している版（`latest`・固定版）はどれも、同じみんなのステージと展示の並びを見る。
- URL を知っている人なら誰でも、共有・上書き・消す・並びを変えるができる（今の公開と同じく、URL が合言葉の代わり）。
- 無料の範囲で使う（書き込みは1日1,000回まで、読み込みは1日10万回まで）。

### ネットにつながっていないとき

| | ネットにつながっているとき | ネットにつながっていないとき |
|---|---|---|
| 展示 | 並びのとおり | チュートリアル①②③だけ（はじめから遊ぶ・選んで遊ぶ どちらも） |
| 開発の一覧 | みんなのステージも出る | 自分のステージ（このブラウザ）だけ |
| 共有・展示の並び | 使える | 押せない（「ネットにつながっていません」） |

- 開き方では分けない。**index.html をダブルクリックで開いても、ネットがあれば共有を使える。** Cloudflare 側で、ファイルから開いたページからの読み書きも受け付ける。

### 7-2. アーカイブの形

```
archive/開発モード_20261030/
  index.html ほか一式   … ダブルクリックで、アーカイブする前の開発モードがそのまま開く
  アーカイブ一覧.md     … 何をアーカイブしたか（7-1 の表）と、戻し方
```

- 本体からアーカイブする前に、そのときのモックを丸ごと写す（テスト・ツールも含める）。
- **引っ張り出す:** ①写しを開けば、そのまま見て遊べる。②「〇〇を戻して」と頼めば、前の版から本体に入れ直す（時間がたつほど合わせ直す手間が増える）。
- 公開済みの固定版（`kyouka`・`kyouka-1019` など）は、そのまま残る。

### 7-3. 外すときの注意（作る人へ）

- **ルール（`rules.js`）は変えない。** 外すのは、ラボの呼び口（`lab(...)`・`LX`・`LAB_PRESETS` など約40か所）だけ。シナジーやお題のルールは、エディットで作ったステージでも使うので残す。
- **「1人ずつ」（`B.turnMode = 'single'`）はルールに残す。** テスト（`tests/run.js` など）がこの形で動いているため。画面から選べなくするだけ。
- **シナリオ（`rules.js` の `PRESETS`）は残す。** テストが使っているため。画面の一覧から外すだけ。
- **遊び方の窓は `tune_ui.js` の中にある。** 調整パネルと一緒に消さず、残す所へ移す。
- **会話の窓は `texts_ui.js` の中にある。** 文章パネルと一緒に消さず、残す。
- **`tools/publish.js` は残す。** 版の表示を外しても、公開はできるようにする。5章の共有のために `wrangler.jsonc` の書き方を変える。
- アーカイブしたものだけを確かめるテスト（`tests/lab*.js`・`progress*.js`・`tune.js` など）は写しの方へ移す。ルールのテストは本体に残す。
- `texts.js` のうち、アーカイブしたものの文は外す（写しには残る）。

## 10. 話していないこと（作るときは【仮】で進め、あとで確かめる）

- 最初の画面のタイトルと、ボタンの名前の文【仮】
- 共有するステージの名前の決まり（長さ・使えない文字）【仮】
- 自分のステージの中で名前が重なる変え方は受け付けない【仮】
- 新しく作ったときの名前は「新しいステージ」。重なったら番号を付ける（「〜のコピー」が重なったときも同じ）【仮】
- 前の保存（配置だけ）で今の形に直せないものは、消さずに残す【仮】
- 作った人の名前を付けるか（付けない【仮】）
- 展示で、しばらく誰も触らないとき最初の画面に戻すか（戻さない【仮】）
- アーカイブしたあとの文（最初の画面・ありがとう！など）を書き換える場所（`texts.js` を直接【仮】）
