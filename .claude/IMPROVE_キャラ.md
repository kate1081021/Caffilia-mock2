# キャラの登録を、開発モードの「設定」へ（2026-11-13）

オーナー 11/13「実装に入ってください。公開は後で。裏で動かして用意するのが目的」。前の会話で決めた形（下の 0章）をそのまま作る。

## 0. 決まっていること（オーナーとの話）

- キャラの一覧を、コード（`game/chars.js`）ではなく、開発モードの「設定」からオーナーが自分で登録する。
- 1人のキャラが持つもの: 名前・色・会話の絵（表情ごと）・戦闘の絵（今は会話の絵と同じでよいが、あとで変わるので欄を分ける）。
- 味方は「魔法 → キャラ」を設定で割り当てる。敵も一旦は魔法ごと。割り当てがなければ「デフォルト敵」の絵（ボス・取り巻きも同じ）。
- 会話（まえげき・あとげき）は一覧のキャラを選んで使う（エディットの欄の書き方「左 名前「文」」のまま）。仮の文は足さない。
- 画像は開発モードから上げる。共有の置き場所（Workers KV）に置く。つながらないときの控えも考える。
- 盤面の駒は、立ち絵を立てて、向きは今の三角で見せる。

## 1. データ（共有の置き場所の `chars`）

```js
chars: {
  list: {                       // キャラの一覧（id → キャラ）。id は会話の行の who が指す。変わらない
    enemy: { name: '敵', color: '#b91c1c', faces: { normal: 'up:…' }, battle: '' },
    …
  },
  cast: {                       // 魔法 → キャラ
    ally:  { fire: 'c…', … },   // 味方
    enemy: { … },               // 敵（魔法ごと。ボス・取り巻きも、その敵の魔法で引く）
    enemyDefault: 'enemy'       // 敵で割り当てのないとき
  },
  at
}
```

- 絵の指し方: `'up:<画像の id>'`（開発モードから上げた絵）か、`'game/img/…png'`（リポジトリに入れた絵）。空は「絵なし」。
- 戦闘の絵 `battle` が空なら、会話のふだんの絵（`faces.normal`）を使う。
- 置き場所にまだ `chars` がなければ、コードの最初の中身（`game/chars.js` の `DEFAULT`。仮の2人＋デフォルト敵）。

## 2. 画像（共有の置き場所の `img:<id>`）

- 開発モードで絵を選ぶと、画面の中で長い辺 512px までに縮めて（透明はそのまま。webp、使えなければ png）、すぐ置き場所へ上げる（`PUT /api/img/<id>`）。1枚 1.5MB（字）まで。
- 読むのは `GET /api/img/<id>`（答えは `{ data: 'data:image/…' }`）。同じ id の絵は変わらない（差し替えは新しい id）。
- 一覧 `imgs`（`{ id: { at, size } }`）で数を数える（300枚まで）。キャラを保存したとき、どのキャラも指していない絵で1日より前のものは消す（下書きで上げたばかりの絵は残す）。

## 3. つながらないとき

- キャラのデータは、このブラウザに控える（`cafilia-mock-chars`。設定と同じ）。
- 絵は、読んだものを1枚ずつ控える（`cafilia-mock-img-<id>`）。入りきらなければ控えない（そのときは、つながらない間は色の仮の絵）。指していない絵の控えは消す。
- 順番: 置き場所 → 控え → コード。

## 4. 画面

- 開発の最初の画面に「キャラ」ボタン（「設定」の隣）。キャラの画面:
  - キャラ一覧: 名前・色・戦闘の絵・会話の絵（表情ごと。ふだん `normal` は消せない。表情を足す・消す）。キャラを足す・消す。
  - 魔法とキャラ: 魔法ごとに味方・敵のキャラを選ぶ。デフォルト敵を選ぶ。
  - 「このキャラで保存する」で置き場所へ。保存するまでは下書き（ほかの画面には当たらない）。
- 盤面（奥行きの見た目）: 駒のキャラの戦闘の絵があれば立てる。なければ前の決まった名前の絵（`game/img/ally_fire.png` など）、それもなければ今の駒。
- 会話: キャラの会話の絵（表情）を出す。読み込み中・絵なしは、色の仮の絵。

## 4b. あとから足したもの（オーナー 11/13）

- 村・トロッコの絵も「キャラ」の画面で上げる（`chars.objects { village, wagon }`）。
- 盤面に立てる絵の大きさを「設定」で変える（`settings.pieces { size, object, boards: { '横x縦': % } }`）。マスの高さの何%か。盤面の大きさごとに変えられる。ステージごとには変えない。
