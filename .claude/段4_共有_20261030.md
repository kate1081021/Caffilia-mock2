# 段4 共有（IMPROVE_v3、10/30）

## できたこと

```
エディット ─ ステージ欄
  名前 [〇〇の森]
  [共有する]  みんなのステージにはまだありません   ← 共有のようす（5つ）

開発の最初の画面
  チュートリアル   ① ② ③
  みんなのステージ 〇〇の森 [消す] …   ← 共有したもの。押すと遊ぶ。E で自分のステージに写し
  自分のステージ   …
  [＋ 新しく作る] [展示の並び]          ← 並びは みんなのステージ から足す

置き場所: Cloudflare（今の公開先）の /api/  ← tools/stage_worker.mjs
```

| 共有のようす | 出る文 |
|---|---|
| まだない | みんなのステージにはまだありません |
| 同じ | みんなのステージと同じです |
| 自分が直した | 共有したあとに直した所があります |
| ほかの人が直した | ほかの人が直しています |
| 両方が直した | 共有すると、ほかの人が直した所が消えます ⚠（赤字） |

- 同じ名前で共有するときは「上書きしますか？」と確かめる。ほかの人が直した所が消えるときは ⚠ を足す。
- みんなのステージを作る側にすると、自分のステージに同じ名前の写しができる。自分のステージにもう同じ名前があれば、選ぶ窓（自分のステージを開く／みんなのステージの形で置きかえる ⚠）。
- みんなのステージの「消す」は ⚠ で確かめる。展示の並びに入っているものは消せない。
- 展示の並びは置き場所に置く（どのパソコンでも同じ）。
- ネットにつながっていないとき: 共有する・展示の並びは押せない。展示モードはチュートリアル①②③だけ。
- ファイルの書き出し・読み込みはなくした。

## 確かめたこと（内蔵ブラウザ・手元のサーバー）

localhost と 127.0.0.1 は保存が別なので、2台のパソコンに見立てた。

- A: 自分のステージを共有 →「同じです」→ 直す →「共有したあとに直した所があります」
- B: みんなのステージを遊ぶ（ボス付き）→ E で同じ名前の写し →「同じです」→ 直す → 共有（上書きの確かめ）
- A:「共有すると、ほかの人が直した所が消えます ⚠」（赤字）。みんなのステージから E → 選ぶ窓 → 自分のステージを開く／置きかえる（B の直しが入る）→「同じです」
- B がもう一度直して共有 → A（直していない）:「ほかの人が直しています」
- A: 展示の並びに みんなのステージ を足して保存 → B の展示モードに出て、最新の中身で遊べた
- 並びに入っているみんなのステージは消せない → 外すと消せた（⚠ の確かめ）
- ネットを止めた形: 開発「ネットにつながっていません」・共有する／展示の並びが押せない。展示: 選んで遊ぶ が チュートリアル①②③
- コンソールのエラーなし。確かめに作ったものは片付けた
