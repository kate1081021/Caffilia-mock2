# LAB_F — 移動と手番（届いてしまう問題・同時に動く）

始める前に、`LAB_00_base.md` の「大前提」と `LAB_PROGRESS.md` を読み直す。

## このカテゴリで確かめたいこと

今は移動にデメリットがない。予告を歩いて避けられる、撃ちたい場所にだいたい届く、の両方がある。移動でほぼ解決できてしまうのは違う（10/6）。
「動いたこと自体で魔法が変わる」形は外した（10/7）。ここでは、**自然・味方の魔法・手番の順** で、歩き方と届き方が変わる案を試す。
もう1つ、10/2 に出ていた「ターン終了時に同時に動く（構えた魔法を表示し続ける）形は合体技に近く、いけるかも」をここで試す。

（自然ごとの歩きにくさは LAB_A の A5、動いた者を狙う敵は LAB_D の D1 にある。）

---

### F1 移動を1にして、足りない分は魔法で運ぶ　★

元: アイデア100 案17。

ルール
- 味方の移動を1マスにする（`lab.F1.move` 1）。敵の移動は変えない【仮】（切り替え `enemyToo` で敵も1）。
- 遠くへは魔法で行く。風で押してもらう、闇で引き寄せてもらう、凍った川を滑る（A2）。法則に例外はないので、味方を運ぶ手段はもう全部そろっている。
- 味方への直撃ダメージは今どおり入る（法則）。直撃1が痛すぎる場合は、そのことを `LAB_REPORT.md` に書く（味方だけ0にする例外は入れない）。

シナリオ「ラボ: 運んでもらう」: 味方 風・闇・火。敵2体は離れた所。
問い
- 誰を動かすために誰の手番を使うか、で悩んだか
- 「届いてしまう」が「届かせるには手番が要る」に変わったか、ただ不便になったか

### F2 追い風・向かい風　★

元: アイデア100 案16。

ルール
- 残った風（ターン終了まで残る風）の上を、風下へ歩くと1歩で2マス進む。風上へは2歩で1マス【仮】。
- 敵も同じ。移動の候補・敵の移動の探索に入れる。
- 風の向きを、風のマスに矢印で出す（今出ていなければ）。

シナリオ「ラボ: 追い風」: 味方 風・火・土。敵は遠く。
- 試し方: 風の人が先に吹かせ、次の人が追い風で遠くへ回り込む。手番の順の工夫を見る。

問い
- 手番の順（誰から動くか）を工夫したか
- 移動と魔法が、味方同士のあいだでつながった感じがあったか

### F3 足場（足元の自然で魔法が少し変わる）　★

元: アイデア100 案19。10/2「自分の色の上に立つと強いは割と良い」の言い直し。吸収の「足元が大事」を自然の言葉で。

ルール（立っているマスの自然で、撃つ魔法が少し変わる）
- 山・丘の上: 形が正面へ1マス先にずれる（高台。A1 と同じ）
- 森の中で草: 森が1マス多く茂る（形の先にもう1マス）
- 水辺（水に接するマス）で水: 流れが1マス長い
- 風の中で撃つ: 形が風下へ1マスずれる
- それ以外は変わらない。予測にそのまま出る。
- LAB_G の G6（武器）がオンなら、武器の自然だけに効く。

シナリオ「ラボ: 足場」: 森・丘・川・風が少しずつある盤面。味方 草・水・火。
問い
- どこに立つかが「届くか」以外の意味を持ったか
- 覚えることが多すぎないか（どれが分かりやすく、どれが分かりにくかったか）

### F4 敵の予告は、味方が1人動くごとに1つずつ発動する　★

元: アイデア100 案10。課題「3段目が簡単に組めて強い」。

ルール
- 今の「敵の移動と予告 → 味方3人 → 敵の発動 → ターン終了」を、「敵の移動と予告 → 味方 → 敵A の発動 → 味方 → 敵B の発動 → 味方 → 残りの敵の発動 → ターン終了」と交互にする。
- 予告は先に全部出ているので、読めるまま。発動の順番を予告に番号で出す（①②③）。
- 味方の予測は「次に発動する敵の予告まで」を含めて計算する。

シナリオ「ラボ: 交互に発動」: 敵2体（火と風）。味方 草・火・風。
問い
- 組みかけの舞台に敵の魔法が割り込む緊張が出たか
- 敵の魔法を2手目に組み込む近道を見つけたか
- 順番が分かりにくくなっていないか

### F5 構えて、ターンの終わりに一斉に発動（合体技）　★

元: 10/2「ターン終了時に同時に動く（発動する）形は合体技に近く、いけるかもしれない。構えた魔法を表示し続けられそうなのが理由」。10/2「ポケダンの連携のイメージは魔法×魔法（同時撃ち・合体技）」。

ルール
- 味方は手番で「移動」と「構え」（立ち位置・向き・魔法）をする。構えた魔法はまだ起きず、**味方の予告として盤面に出し続ける**（敵の予告と同じ見せ方、色だけ変える）。
- 3人が構え終えたら、味方の構えを **構えた順に** 発動 → 敵の予告の発動 → ターン終了処理。
- そのターンのうちなら、構え直せる（移動は戻らない）。構えた順も入れ替えられる（一覧で順番を並べ替え）。
- 違う味方の魔法が、同じマスに続けて当たって決め手が起きたら、決め手の名前に「合体！」を付け、参加した味方の名前を並べて出す（中身は順序どおりのシナジー。見せ方だけ）。
- 予測は「構えた順に全部起きたあと」の盤面で出す。敵の予告の結果も、その盤面で計算し直す。

シナリオ「ラボ: 合体技」: 味方 草・火・風。敵2体。
問い
- 3人の構えが盤面に並ぶことで、合体技を組んでいる感じが出たか
- 撃った結果がすぐ見えないもどかしさが勝ったか
- 構えた順を入れ替える遊びが、順序のシナジーと噛み合ったか

### F6 共通の行動「壊す」　☆

元: 10/3「自然を壊すための物理的なもの（属性に関わるかは未検討）があってもいい。現状壊す方法が少なく難しい」「壊す手段は、共通の行動として分けるか、既存の魔法に持たせるかを考えるべき」。

ルール
- どの味方も、魔法の代わりに「壊す」を選べる（その手番は魔法を撃たない）。
- 正面1マスの自然を一段戻す（二段 → 一段、一段 → 空き。火山 → 山、死の森 → 空き、氷 → 水たまり、桜 → 山）。ユニットがいれば直撃1。
- 敵は使わない【仮】（敵も使うかは切り替え `enemyToo`）。
- 予測にそのまま出る。

シナリオ「ラボ: 壊す」: 自分たちの作った森や山で道がふさがっている盤面。
問い
- 自分の作った自然に足を取られたとき、「壊す」で道を開けるのが助かったか
- 魔法を撃たない手番が、もったいなく感じたか（できることを増やすより減らすほうが面白い、9/16 とくらべて）

### F7 作業台（範囲の中だけで混ぜる）　☆

元: 10/2「シナジーの別案として、マイクラの作業台のように1人のキャラが範囲を設定し、その中でクラフトしてシナジーを発生させ、効果（自然現象・地形・大きな魔法など）が起きる形も思いついている。今までのものとはまあまあ違う」。**今の骨格（魔法を撃つと、すぐ自然になる。法則に例外はない）から大きく外れる。くらべるためだけに入れる。**

ルール
- どの味方も、魔法の代わりに「作業台」を置ける。正面の3×3（術者の前の辺から）に枠が出る。枠はそのターンだけ。
- 枠の中に当たった魔法は、すぐには自然にならず、「材料」として枠に積まれる（枠の横に、積まれた順に魔法の印が並ぶ）。
- ターンの終わり（敵の発動の前）に、積まれた順のとおりに、枠の中の全マスへ順に当たったことにして、まとめて変わる（今のシナジー表をそのまま使う。結果は枠いっぱいの大きさになる）。
- 予測は「枠の中が最後にどうなるか」を出す。

シナリオ「ラボ: 作業台」: 味方 草・火・風。敵2体。
問い
- 「3人で1つの物を作っている」感じが、今の形より強かったか
- 撃ってすぐ変わらないことで、分かりにくくなったか
- 今の形を捨ててでも欲しい手触りがあったか
