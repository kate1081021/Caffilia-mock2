# LAB_K — 時間と繁栄（時間あり・なしをくらべる）

始める前に、`LAB_00_base.md` の「大前提」と `LAB_PROGRESS.md` を読み直す。

## このカテゴリで確かめたいこと

- 時間の扱いはまだ悩んでいて、あるパターンとないパターンを作って比べるのがいい（10/7）
- 繁栄（時間経過の扱い）は悩みどころ。自然の醍醐味だと思う反面、自分でコントロールするものではない難しさがある。やった方が楽しそうで新しいので、分かりやすくて納得感があれば OK（10/4）
- 時間で勝手に変わる自然は扱いが難しいが、現実としてはありうる（10/3）
- 時間で表現できる自然もある（例: 炎が燃え尽きて灰になり、灰から森がよみがえる）（NOTES）

「時間のブレーキ」（植えたばかりは弱い、育つまで待つ）は 10/6 に「今ではない」と決めたので、ここでも入れない。ここで試すのは、**時間が自然を「動かす」かどうか** と、**時間で自然が「育つ」か** の2つ。

### K1 時間の3つの切り替え　★

元: 10/7（上の言葉）。導火線（案28）は時間あり・なしの両方で成り立つので、差が一番よく出る見本（10/7 アイデア100）。

ルール（切り替え `mode`）
- `'none'` **時間なし**: ターン終了で自然は変わらない。燃え移り・燃え尽き・小さな炎が消える・風がやむ・火の渦が解ける・花びらが散る、を全部止める。炎の上と火傷のダメージは残す【仮】。自然が変わるのは、魔法が当たったときだけ。
  - 小さな炎・風・花びらが残り続けるので、盤面が散らかる・火の渦が組みやすくなる、などが起きるはず。そのまま観察して `LAB_REPORT.md` に書く。
- `'now'` 今のまま（初期値）。
- `'grow'` 繁栄（K2 のルールを足す）。

ラボ用シナリオ
- 「ラボ: 時間と導火線」: LAB_C の C6 の「導火線」と同じ盤面。`mode` を切り替えて、導火線がどう届くか（時間あり: ターン終了に1マスずつ遅れて届く／時間なし: 燃え広がりで一気に届けるしかない）をくらべる。C6 が作ってあれば `needs: ['C6']`。
- 「ラボ: 時間と燃え広がり」: 今の「燃え広がり」シナリオを、3つの `mode` で。

問い
- 時間ありと時間なし、どちらが「準備すら楽しい」に近かったか
- 時間なしで、盤面の流れが止まって退屈にならなかったか
- 時間ありで、勝手に変わるのが分からない・納得できない場面があったか

### K2 繁栄（時間で育つ自然）　★

元: 10/4「繁栄は自然の醍醐味」、NOTES「炎が燃え尽きて灰になり、灰から森がよみがえる」。

ルール（ターン終了に起きる。全部、前のターンに予告の印を出す）
- **灰からよみがえる**: 燃え尽きた炎の跡は「灰」になる（通れる。燃えない。風で運ばれない）。灰は2回目のターン終了で草むら（二段がなければ森）がよみがえる。
- **水辺の草むらは育つ**: 川・水たまりに接している草むらは、ターン終了で森に育つ（1ターンに1段だけ）。
- **溶けて流れる**: 火山に接する氷は、ターン終了で水たまりに溶ける【仮】。
- 盤面に「育」の印（次のターン終了で育つマス）と「よ」の印（よみがえるマス）。今の「燃」「尽」と同じ見せ方。
- 敵にも同じ（敵の跡もよみがえる）。

シナリオ「ラボ: 繁栄」: 燃え広がりのあとの盤面（灰と草むらと川）から始める。味方 草・火・風。敵2体。
- 試し方: 1回燃やして、灰からよみがえった森をもう一度燃やす。水辺に草むらを置いて、勝手に森になるのを待つ。

問い
- 勝手に育つのを見ているのが楽しかったか（見ているだけで楽しい）
- 自分でコントロールできない不満が出たか、予告があれば納得できたか
- 「燃やす → よみがえる → また燃やす」の繰り返しが、戦い方になったか
