# LAB_C — 決め手（3段目の近道と、決め手がどこまで届くか）

始める前に、`LAB_00_base.md` の「大前提」と `LAB_PROGRESS.md` を読み直す。

## このカテゴリで確かめたいこと

今は3人で1ターンに3段目まで通せるので、作った自然を活かさずに毎回シナジーで片づいてしまう。準備（関係ないところに撃つ）と、縛る（敵を罠にはめる）が飛ばされる。
もう1つ、火（1マス）・風（2マス）・闇（1マス）は届く距離が短いので、決め手を起こした本人がそのすぐ隣に立っていて、同じターンに起こすと巻き込まれる。

ここでは、
- **舞台を先に作って、敵に入ってもらう** しかない形（近道をふさぐ）
- **決め手がどこへ広がるかを、最後に来た魔法の動き方から納得させる** 形
- **遠くに撃った一手が、連鎖して決め手まで届く** 形

を試す。時間のブレーキ（育つまで待つ）は使わない。近道をふさぐのは「納得できるルール」でやり、決まりごとで縛らない（オーナー: 二段のルールは近道対策のためではなく、納得感を生むためのルールにしたい）。

### C1 足元には生まれない　★

元: アイデア100 案5（10/6）。課題「3段目が簡単に組めて強い」。

ルール
- 「空き → 自然ができる」変化は、ユニットのいるマスでは起きない。今そうなっているのは草・土・水だけなので、**火（小さな炎）と風（残る風）にも広げる**。ユニットのいるマスは直撃だけ。
- もとからある自然が変わる（森に火で炎、風に火で火の渦 など）は今までどおり、ユニットがいても起きる。
- 敵にも同じく効く。

シナリオ「ラボ: 足元には生まれない」
- 味方 風・火・水、敵は火の敵1体（狙いは近い人）。真ん中に何もない盤面。
- 試し方: まず敵の足元に風 → 火で火の渦を作ろうとしてみる（できない）。次に、敵が来そうな所に風を置いて待つ、または風で敵を押して風の中へ入れる。

気づいたら `LAB_REPORT.md` に: 風はターン終了でやみ、敵は味方の手番の前に動くので、「敵が風の中に立っている」状況がほぼ作れないかもしれない。そうなら、それも書く（風を残す長さを変える案は、ここでは入れない）。

問い
- 「敵を舞台に入れる」ために、誘導や妨害を考えたくなったか
- 手数が増えて、ただ面倒になっていないか

### C2 20は化けた自然の中だけ　★

元: アイデア100 案6・案26（10/6）。課題「決め手の隣に術者が立つ」。

ルール
- 決め手の20（強い炎の20を含む）は、**その1発で化けた自然の「中」にいる者だけ** に入る。
  - 燃え広がり: 燃えた森の上（今と同じ）
  - 火の渦: 2×2 の中
  - 感電: 水の上だけ
  - センタクキ: 渦の中
  - オバケヤシキ: 中に閉じこめられた者
  - 桜吹雪: 扇の中（花びらになったマス。今と同じ）
- 「中」の外（隣・輪・引き寄せの範囲）にいる者の扱いは、切り替え `edge` で2通り:
  - `edge: 'weak'` 弱い5（炎なら弱い炎として火傷も）
  - `edge: 'move'` ダメージなし。動かされるだけ（センタクキの輪は回る、オバケヤシキの引き寄せは起きる）

シナリオ「ラボ: 中だけ20」
- 今のデモ「草で森 → 闇で死の森 → 火でオバケヤシキ」と「風 → 火で火の渦 → 水でセンタクキ」を、1ターンで味方を失わずに通せるかを見る盤面。
- 試し方: 1ターンで3段目まで通して、起こした本人が倒れないか見る。次に、敵が「中」にいないと倒れないことを確かめる。

問い
- 起こした本人が倒れなくなって、1ターンで3段目まで通すのが気持ちよくなったか。それとも楽になりすぎたか
- 「中に入れないと倒せない」が、敵を誘い込む理由になったか
- `weak` と `move`、どちらが納得できたか

組み合わせシナリオ「ラボ: 近道なし」: C1 と C2（`move`）を両方オン。舞台は先に作り、敵に入ってもらうしかない盤面。敵は火の敵2体（狙いは「近い人」と「自然」を1体ずつ）。

### C3 決め手は、最後に来た魔法の動き方を受け継ぐ　★

元: アイデア100 案30（10/7 書き直し）。オーナー「決め手に向き（指向性）を持たせるのは賛成。納得できる形でうまくやりたい」。

向きを後から足すのではなく、最後に来た魔法の動詞から出てくるようにする。「水を浴びせたんだから向こうへ流れるよね」と思える形。

ルール（最後に来た魔法の動き方 → 出来事の広がり方）

| 最後に来た魔法 | 広がり方 | 起こした人 |
|---|---|---|
| 吹く・流れる（風・水） | 向きの奥へ抜ける | 手前にいるので安全 |
| 走る・凍らせる（雷・氷） | つながった水や自然を伝う | つながりに触れていなければ安全 |
| 点ける・置く（火・草・土） | その場で四方に起きる | すぐ隣にいるので巻き込まれる |
| 吸う（闇） | 内側へ集まる | 引き寄せられる |

- 今の燃え広がり・桜吹雪・感電・凍結・オバケヤシキは、すでにこの表どおり。**変わるのはセンタクキ**: 水で起こすので、渦が水に押されて流れの向きへ転がる。輪のうち、水が来た側から見て奥の半分だけが回る【仮】。
- LAB_B の新しい組み合わせも、この表に従う（花筏・土石流は奥へ、雷で起こすオバケヤシキはつながった死の森を伝って全部が化ける、など）。C3 がオフのときの LAB_B は、各案に書いた形のまま。
- 予測・予告に、出来事の広がる向きを矢印で出す。

シナリオ「ラボ: 動き方を受け継ぐ」
- 火の渦が1つと、そのまわりに敵2体（水の来る側と、奥側）。味方は水・風・雷。
- 試し方: 水の向きを変えてセンタクキを起こし、奥の半分だけが回ることを見る。オフでくらべて、全部回る形と見くらべる。

問い
- 「水を浴びせたんだから、向こうへ流れるよね」と思えたか
- 誰で起こすかを、向きと安全から選ぶようになったか

### C4 3段目の届く範囲は、舞台の大きさで決まる　★

元: アイデア100 案8・案12・案58（10/6）。判断の基準「材料の大きさで変わるのは範囲。ダメージは一定」。

ルール
- **桜吹雪**: 扇の列の数＝つながった桜の数（1本で1列、2本で2列、3本以上で3列【仮】）。
- **オバケヤシキ**: 引き寄せの距離＝つながった死の森の数（1〜2で1マス、3〜5で2マス、6以上で3マス【仮】）。
- **センタクキ**: 回る輪の周数＝火の渦の大きさ（4マスで1周、8マス以上で2周【仮】。渦を大きくする方法が今なければ、1周のまま）。
- 2段目（燃え広がり・感電）は今どおり（もともと大きさで広がる）。
- 切り替え `sharp`（**災害は広く、超常は鋭く**、案12）: true のとき、3段目の範囲に上限（扇は最大3列、輪は1周、引き寄せは2マス）を付け、代わりに燃え広がりの走る長さを「4マス＋燃えた森の数の半分」に伸ばす（案58）。準備した大きな森の燃え広がりは全員を倒し、近道の3段目は1体だけ、という役割分け。

シナリオ「ラボ: 大きい舞台」
- 同じ盤面を2つ。片方は桜が1本、もう片方は山脈に桜が4本。敵は扇の2〜3列目に並べる。
- 試し方: 1本の桜に風（1列だけ）と、4本の桜に風（3列）をくらべる。

問い
- 1ターンで作った小さな舞台と、育てた大きな舞台で、届き方の差が見て分かったか
- 大きく育てたくなったか
- `sharp` を入れると、燃え広がり（準備型）と3段目（近道型）の使い分けが生まれたか

### C5 超常は、育った自然からしか化けない　★

元: アイデア100 案11・63・87（10/7【試す: 二段階】）。Claude の案「2段目は一段でも起き、育てると広がる。3段目は二段が要る」。

前提: `IMPROVE_grow`（二段で育つ）が入っていること。入っていなければ飛ばす。

ルール
- 3段目の入口を **二段の自然** にする。
  - オバケヤシキ: 森（二段）→ 闇で死の森 → 火。草むら（一段）に闇は今どおり何も起きない。
  - センタクキ: 強風（二段）に火で「大きな火の渦」→ 水。ふつうの風（一段）に火の火の渦に水は、**普通の結果**（炎に水と同じく消える）で終わる。
  - 桜吹雪: 山（二段）に咲いた桜に風。丘（一段）に咲いた桜に風は、花びらが少し舞うだけ（扇1列、弱い5）。
- 一段の舞台に最後の一手を構えると、予測に「育っていれば: センタクキ」と薄く出す。二段が要ることを、撃つ前に知るきっかけにする。
- 2段目は一段でも起き、二段なら範囲が広がる（IMPROVE_grow のまま）。

シナリオ「ラボ: 育てて化ける」
- 味方 草・闇・火（オバケヤシキの筋）。草むらが少しある盤面。敵2体。
- 試し方: 草むらに闇（何も起きない）→ 草をもう一度当てて森に → 闇で死の森 → 火。1ターン目に1手、2ターン目に仕上げ、の流れになるかを見る。

問い
- 3人で1ターンの近道が減って、前のターンの準備に意味が出たか
- 「育っていれば化ける」の予測を見て、育てたくなったか
- 手数が増えてテンポが落ちすぎていないか（10/5「同じ魔法を重ねるのは手数がかかって微妙」とくらべて）

### C6 通った所すべてに「その魔法が当たった」ことにする（連鎖・導火線）　★

元: アイデア100 案62（10/6）、案28 導火線（10/7【面白い】「魔法しか通せない所を狙う形は面白い」）、案29。

ルール
- 燃え広がりの通り道・燃え移り・（LAB_B の）火の粉は「火が当たった」、源流・（LAB_B の）土石流・花筏の通り道は「水が当たった」、強風の通り道は「風が当たった」ことにして、**表どおりの変化を全部起こす**。
  - 例: 燃え移りの炎が死の森に届けばオバケヤシキ。燃え広がりが水たまりを通れば蜃気楼。源流が火の渦に着けばセンタクキ。
- 起きた変化が次の変化を起こすときは、1つずつ順に処理する（連鎖）。止まらなくならないよう、**同じマスは1発（または1回のターン終了）の中で1回まで**。
- 時間ありの今は、燃え移り（ターン終了）で遅れて届く。LAB_K の「時間なし」と組むと、燃え移りがない代わりに燃え広がりで一気に届く。
- 連鎖の見せ方は、LAB_J のドミノ（J4）があればそれを使う。なければ、変化ごとに少し間をあけて順に見せる。

シナリオ（3つ）
- 「ラボ: 導火線」: 死の森のそばまで細い森の筋が伸びている。遠くの森の端に火を点けて退がると、ターン終了の燃え移りで筋を伝い、死の森に届いてオバケヤシキ。
- 「ラボ: 中州の敵」: 川に囲まれた中州に敵（歩いては近づけない）。森の筋を中州まで伸ばして火を通すか、川に雷を流す。
- 「ラボ: 遠くからの起爆」: 盤の向こうの山に水を撃つと、源流が流れて火の渦に着き、センタクキ。

問い
- 「全然関係ないところに撃った一手」で勝てたか
- 連鎖が起きたとき、何が起きたか追えたか
- 森の筋を伸ばしておく準備に、意味を感じたか
