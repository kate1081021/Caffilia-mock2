# LAB_D — 敵のつくり（欲・体・大きさ・強さ）

始める前に、`LAB_00_base.md` の「大前提」と `LAB_PROGRESS.md` を読み直す。

## このカテゴリで確かめたいこと

オーナーの言葉から:
- 敵はでかくてめちゃ強く、こちらはほぼ一撃でやられる（10/2）。ダメージを食らわないように進むゲームではない（10/5）。
- このゲームの変なところは、敵を倒すために自然を作ること。だから敵の設計はかなり大事（10/4）。
- 敵も自然を作る。大きい敵は山や森を力ずくで崩して進める、はそうかも（10/4）。
- 敵の行動は、こちらが納得できるものにしたい。重みづけは極端にしてよい（10/7）。ワンパンしてくる相手なので、こちらにとっての公平さは「読めること」。
- 敵がおバカに見えるのは、極端さより、欲と体がかみ合っていないとき。欲は1つにはっきりさせ、見た目とそろえ、予告に理由を一言（10/7）。

ここでは、敵の「欲」「体」「大きさ」「強さ」「敵だけの魔法」を1つずつ試す。
今の敵の個性（狙い: 人数／近い人／自然／的、避ける、越える）と、予告を先に出す流れはそのまま使う。

---

### D1 欲を1つに極端に＋予告に理由を一言　★

元: 10/7（アイデア100「進路の誘導」の反応）。

ルール
- 敵の個性に「欲」を足す。欲を持つ敵は **欲を最優先し、それ以外はほぼ見ない**（巻き込まない決まりはそのまま）。
  - **森**: 燃やせる森・草むらに火を点けられる手を最優先。点けられないときは、一番近い森へ向かう。（炎使い向け）
  - **自分の自然**: 自分の魔法の自然（水の敵なら川・水たまり、土の敵なら山・丘、火の敵なら炎）の上か隣に立てる所へ向かい、そこから撃つ。（10/2「自分の色の上で強い」の言い直し）
  - **逃げる**: 味方から一番遠くなるマスへ動く。撃つのは、隣まで来た者だけ。
  - **動いた者**: 前のターンに動いた味方を最優先で狙う（案21。動くと狙われるので移動に損が生まれ、わざと動いて囮にもなる）。
  - 今の「人数」「近い人」「自然」「的」も、欲として選べる。
- 予告の一覧と、盤面の敵の上の吹き出しに、理由を一言出す（「森を燃やしに行く」「水辺へ向かう」「逃げる」「動いた〇〇を狙う」）。
- 駒に欲の印（今の 人／近／自 に、森／水／逃／動 を足す）。体の見た目も、欲と合うように色や形を少し変える（炎使いは赤、逃げる敵は小さい、など。簡単でよい）。

シナリオ「ラボ: 4つの欲」
- 欲の違う敵を1体ずつ置いた、4つの小さな盤面（シナリオを4つ、または1つの盤面を区切って）。
- 試し方: 1ターン目、何もせずに敵がどう動くかを見て、2ターン目から欲を使って誘う。

問い
- 「あの炎使いは森しか見ていない」と読めたか
- 読めたことで、誘導が賭けではなく確実な手になったか
- 敵がおバカに見えなかったか

### D2 敵の行き先を薄く見せる　★

元: アイデア100 案40。

ルール
- 敵が次のターンにどこへ向かいたいか（欲に向かう道筋）を、馬車の道筋と同じ薄い線で出す。
- 味方の予測を出しているあいだは、撃ったあとの盤面で計算し直す。「山を盛ると道筋がこう曲がる」が撃つ前に分かる。
- 敵1体ごとに線の色を分ける。

シナリオ: D1 の「4つの欲」に重ねて使う（D2 だけのシナリオは、敵2体が森へ向かう盤面）。
問い
- 道筋を見て、山や森の置き場所を決めたか
- 盤面の情報が多すぎてうるさくないか

### D3 大きい敵（2×2）　★

元: 10/2「敵はでかくてめちゃ強く」。アイデア100 案9。IMPROVE_grow の `enemy.size`（入っていればそれを使う）。

ルール
- 敵は2×2を占める。占めるマスは向きで回らない。通れるのは4マスとも通れるとき。1発の魔法でのダメージは1回（一番大きいもの）。
- **決め手で倒れるのは、決め手の20の範囲が体の4マスを全部覆ったときだけ。** 一部なら弱い5（案9。「大きいものには大きな炎」）。
- 風で押す・闇で引き寄せるは、4マスとも動けるときだけ動く。
- 魔法の形は、前の辺の真ん中あたりを起点【仮】。
- 大きさは `size` で 2（2×2）か 3（3×3）を選べる（9/15「ボスの占有サイズは3×3が本来の意図」）。3×3 が重ければ 2 だけでよい。

シナリオ「ラボ: 大きい敵」: 2×2の火の敵1体と、小さな敵1体。広めの盤面（8×8）。味方 草・火・風。
問い
- 大物には育てた大きな舞台が要る、が伝わったか
- 雑魚と大物で、戦い方が変わったか
- 2×2の体が、盤面の中で「でかい」と感じられたか

### D4 大きい敵は自然を力ずくで崩して進む　★

元: 10/4「大きい敵は山や森を力ずくで崩して進める、はそうかもと感じている」。

ルール
- 2×2の敵は、森・山・丘・氷・桜を通り抜けられる。通ると壊れる（森 → 草むら（二段がなければ空き）、山 → 丘（なければ空き）、丘 → 空き、氷 → 割れて水たまり、桜 → 山）。
- 川・炎・泥沼は今どおり（川は渡れない、炎は避けるなら避ける、泥沼ははまる）。
- 移動の予告に、壊すマスを出す（「森を踏みつぶす」）。

needs: D3

シナリオ「ラボ: 力ずくの大物」: 大きい敵が、こちらの山の壁を崩して進んでくる。味方 土・水・氷。
問い
- 壁で止められない大物に、別の止め方（川・泥沼・凍らせる）を考えたか
- 自分の作った自然が崩されるのが、良い意味で悔しかったか

### D5 一撃で盤面が荒れる、めちゃ強い敵　★

元: 10/2。アイデア100 案20「避けると組めない広さの予告」。

ルール
- 1体だけ。HP は決め手3発分【仮】（`lab.D5.hp` 60）。
- 予告の形が広い（例: 炎の扇 1・3・5、土の壁 5マス横一列）。避けるのに移動を使い切るくらいの広さ。
- こちらは今どおり一撃で倒れる。
- この敵の魔法も、ほかの敵と同じ法則で自然を作る（広い範囲が一気に炎や山になる）。

needs: D3 があれば2×2にする（なくても試せる）

シナリオ「ラボ: めちゃ強い敵」: 広めの盤面に、この敵1体。味方 草・火・風。
問い
- 「避ける」と「組む」が、同じ移動を取り合ったか
- 予告を潰す・材料にする価値が上がったか
- ただ理不尽ではなかったか

### D6 体が跡を残す　★

元: アイデア100 案52（「違いは体に出る」と「敵を利用」が一緒に立つ）。

ルール
- 炎の体の敵は、歩いた跡のマス（空きだけ）に小さな炎を残す。
- 水の体の敵は、歩いた跡のマス（空きだけ）に水たまりを残す。
- 跡は普通の自然（小さな炎はターン終了で消える）。敵は味方の手番の前に動くので、跡は味方の手番のあいだ残る。
- 駒の見た目で体が分かるようにする。

シナリオ「ラボ: 足跡」: 炎の体と水の体の敵1体ずつ。味方 風・雷・水。
問い
- 敵の足跡を材料にしたか（水の足跡に雷 → 感電が敵自身に返る、炎の足跡に風 → 燃え広がり）
- 敵が歩くだけで盤面が変わっていくのが面白かったか

### D7 体の違いで効かない決め手がある　☆

元: アイデア100 案25。骨格「違いは体（何を越えられるか、何を壊せるか）に出る」。

ルール
- 水の体: 炎のマスに入ると、そのマスの火が消える（炎に水と同じ）。燃え広がりでは倒れない（弱い5のみ）。
- 岩の体: 電気を通さない。感電しない。重い（A11 があれば）。
- 浮いている体: 泥沼にはまらない。川を渡れる。
- 体は駒の見た目と、敵の説明に出す。

シナリオ「ラボ: 体の違い」: 体の違う敵3体。味方 草・火・風（燃え広がりで全員は倒せない）。
問い
- 敵を見てから舞台を選ぶようになったか
- 「1つのレシピでどの敵も倒せる」が崩れて、面白くなったか、面倒になったか

### D8 敵だけの魔法「戻す」　★

元: アイデア100 案100。10/5「敵しか使えない魔法・動詞によるアンバランスな戦闘もやってみたい」。

ルール
- 敵だけが使う魔法「戻す」。形は正面2マス【仮】。当たった自然を **一つ前の姿に戻す**（炎 → 森、火山 → 山、氷 → 川、死の森 → 森、森 → 草むら、山 → 丘、強風 → 風、桜 → 山）。一段の自然や空きには何も起きない。ユニットには直撃1。
- 今の「敵だけの魔法」の仕組み（シナリオごとの一覧）に乗せる。味方は選べない。

シナリオ「ラボ: 戻す敵」: 戻す敵1体と、火の敵1体。味方は育てる魔法を持つ（草・土・風）。
問い
- 「戻される前に起こすか、戻されない所で育てるか」で迷ったか
- 敵の目的が「人」ではなく「盤面」になる手触りがあったか

### D9 大技を組む敵（2ターンかけて舞台を作る）　★

元: アイデア100 案48・案54 の敵側。

ルール
- 1体で2段目まで組む敵。1ターン目に舞台を作る魔法（例: 風）を撃ち、次のターンに決め手（例: 火で火の渦）を撃つ。
- 予告は2ターン分出す（「このターン: 風を吹かせる → 次のターン: 火の渦！」）。2ターン目の予告は、舞台が残っていれば出す。舞台が壊れていたら、ふつうの手に変える。
- この敵は、風と火の2つの魔法を持つ（敵だけの決まり。味方の「1人1つ」とは違う）。
- 舞台は普通の自然なので、こちらが壊す・乗っ取ることができる（LAB_E の E8）。

シナリオ「ラボ: 大技を組む敵」: この敵1体と、ふつうの敵1体。味方 水・土・火。
問い
- 敵の舞台を見て「壊すか、使うか」で迷ったか
- 2ターン先が読めることで、敵が賢く見えたか

### D10 歩いても避けられない予告（シナリオだけ）　☆

元: アイデア100 案18。

今の法則のままで起きるか見るためのシナリオ。新しいルールは足さない。
- 「ラボ: 伝う予告」: 敵の雷使いが、味方の近くの川に向けて予告している（感電がつながった水全体に走る）。味方は1〜2マス歩いても水の隣から出られない。
- 試し方: 歩いて逃げるのではなく、土で川の一部を泥沼にしてつながりを切る、凍らせる（雷は氷を伝わらない）。

問い: 避けるのではなく、自然を変えて返す手が気持ちよかったか
