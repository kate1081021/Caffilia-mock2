# LAB_G — 強化と融合（強化は要るか、何を変えるか）

始める前に、`LAB_00_base.md` の「大前提」と `LAB_PROGRESS.md` を読み直す。

## このカテゴリで確かめたいこと

強化がこのゲームに必要か、必要なら **何を変える強化か** を、並べてくらべて決める。オーナーの言葉は次のとおりで、互いに引っぱり合っている。ラボで遊んで、どれが残るかを判定する。

- 魔法は前1マスから始まり、強化で伸びたり強くなる形がいい（10/7）
- 強化は「伸びる」と「一気に二段」を別のパターンにする。スキルツリーにはしないが近い形、ランダムに3つから選ぶような形（10/7）
- 大きさ・届き方の強化ならいらない。普通にする要素は不要（10/9）
- 強化で魔法の姿形が変わっていくのは良いが、方向性は「カッコいい」。炎 → 溶かす、のような化学的な変化は違う（10/9）
- 魔法は属性で意識されているので、同じ魔法（属性）で内容が違うと違和感になりそう（10/9）
- 融合は最終強化として必要。1人でもシナジーは起きるが、威力は控えめにして差別化する（10/6）
- 最終強化まで行った融合魔法は、一撃でシナジーを出せる（10/6）
- 強化系の魔法は、最初は敵が少し強いものとして持っていて、やがて自分も使えるようになる（10/12）
- 武器が「どの自然の上で強いか（足場）」を決める案はとてもいい（10/7）
- やりたかったこと: あえて味方に魔法を撃って威力アップ（ダメージは食らう）／何もないところに撃つ（味方撃ち）に価値を持たせる／尖った強化で最強火力を作る（10/1）

## ラボの仕組み（このファイルで足す）

- エディットで、味方1人ごとに「強化」を付け外しできるようにする。強化の種類は下の案ごと（G1〜G7）。1人に複数付けてもよい（ぶつかるときは後から付けたほうを優先、と `DECISIONS.md` に書く）。
- 駒に強化の印（小さな★と種類の1文字）。一覧に強化の名前。
- 強化した魔法の形と結果は、予測・光る導きにそのまま出る。早見表に、強化した形を図で出す。
- お題・周回（LAB_H）から強化を渡すときに使えるよう、強化を「付ける関数」にまとめる。

### G1 一気に二段　★

元: アイデア100 案87（10/7【試す: 二段階】）。10/6「同じ魔法を重ねて育てる工程を一気にできる方向」。

前提: `IMPROVE_grow`（二段）が入っていること。なければ飛ばす。

ルール: 強化した魔法は、空きに撃つと一発で二段になる。草 → 森、土 → 山、水 → 川（向きの奥へ）、風 → 強風、火 → 炎（燃え続ける）。一段の自然に当てたときは、二段を飛ばさず、そのまま二段に育つ（三段目はない）。

シナリオ「ラボ: 一気に二段」: 同じ盤面で、強化ありの土と、強化なしの土をくらべる（オフでくらべる）。
問い
- 「手数を買う」強化として価値を感じたか
- 二段の舞台をすぐ作れて、3段目の近道が戻ってこないか（LAB_C の C5 と一緒に見る）

### G2 形が伸びる　★

元: アイデア100 案88、10/7「魔法は前1マスから始まり、強化で伸びたり強くなる」。ただし 10/9「大きさ・届き方の強化ならいらない」もある。**遊んで、どちらの気持ちが残るかを判定するための案。**

ルール
- この案をオンにすると、強化前の味方の魔法は全部「正面1マス」になる（雷・氷・闇も。IMPROVE_grow の `shape.frontOne` があればそれを使い、雷・氷・闇も含める）。
- 強化1回ごとに、形のマスが1つ増える。伸びる向きは魔法の動き方から: 水・風・雷・氷は奥へ、草・土は横へ（左右交互）、火・闇は斜め前へ【仮】。強化は3回まで。
- 点ける系（火）は、強化前は決め手のすぐ隣に立つことになり、強化で離れて起こせるようになる。

シナリオ「ラボ: 伸びる魔法」: 強化0回・1回・3回の味方を並べて、同じ舞台に撃ちくらべる。
問い
- 「危なかった一手を、安全に撃てるようになった」手応えがあったか
- 10/9 の「大きさ・届き方の強化ならいらない」は、遊んでもそう思うか

### G3 姿形が変わる（カッコいい強化）　★

元: 10/9「強化で魔法の姿形が変わっていくのは良いが、方向性は『カッコいい』」。9/15「核は左右非対称にしてアンバランスにする方向」「魔法の形がかっこいい」。世界設定（9/15）「魔法ごとに信仰する神があり、強化はその神に近づく方向で行われる」— 姿が変わる先は、その魔法の神のイメージに近づく形にすると設定とつながる（名前の付け方の参考に）。

ルール
- 魔法ごとに、強化で **形そのものが別の姿に変わる** 案を2つずつ作る（伸びるのではなく、並びが変わる）。**動詞（何が起きるか）は変えない**（同じ属性で内容が違うと違和感、10/9）。
- 形は Claude Code が考えてよい。条件:
  - 左右非対称でもよい
  - 強化前より「できること」が増える（届く向きが増える、今まで作れなかった並びの自然が作れる、決め手から離れて撃てる、など）。ただ大きくなるだけにしない
  - 名前を付ける（例: 火の鳥、風の鎌、大樹の根、雷の三叉）
  - 撃つ前に読める（予測に出る）
- 強化は「A の姿」か「B の姿」を選ぶ（両方は付けられない）。
- 早見表とカードに、強化前と後の形を小さな図で並べる。

シナリオ「ラボ: 姿の変わる魔法」: 味方3人それぞれ、A・B の姿を付け替えて遊べる盤面。敵は2体。
問い
- 姿が変わることを「カッコいい」と思えたか
- 新しい並びの自然が作れて、組み立てが変わったか
- A と B で、選ぶ楽しさがあったか

### G4 融合（2つの動詞を順に当てる1発）　★

元: アイデア100 案90。10/6「融合は最終強化なので必要。1人でもシナジーは発動するが威力は控えめ」。

ルール
- 融合した魔法は、形の各マスに「1つ目 → 2つ目」の順で当たる。
  - 例: 草＋火 ＝ 植えてすぐ点ける ＝ 1発で燃える森。風＋火 ＝ 火の渦。火＋風 ＝ 燃え広がり。順序で別の魔法になる。
- 1人で2段目まで行ける。「控えめ」の付け方は切り替え `weak` で2通り:
  - `weak: 'small'` 形が小さい（1〜2マス）
  - `weak: 'damage'` 決め手のダメージが半分（20 → 10）
- 形は、1つ目の魔法の形を使う【仮】。
- エディットで、味方に融合の組み合わせ（1つ目・2つ目）を付けられる。

シナリオ「ラボ: 融合」: 草＋火の融合を持つ1人と、ふつうの2人。敵2体。
問い
- 1人で起こせる2段目が、3人の連携を壊していないか
- `small` と `damage`、どちらが「控えめ」として納得できたか

元: アイデア100 案91。10/6「最終強化まで行った融合魔法は、一撃でシナジーを出せる」。

- 形は1マス。範囲は舞台の大きさで決まる（LAB_C の C4 がオンなら）ので、狭い。
- 1戦に何回でも撃てる（決まりごとで縛らない）。

needs: G4

### G6 武器は「どの自然の上で強いか」を決める　★

元: アイデア100 案92（10/7【とてもいい】）。吸収が担っていた「武器の個性」の行き先。10/2「自分のマナの上に立つと強いは割と良い」。

ルール
- 武器を3つ用意する【仮】: 杖（森の中で強い）、弓（山・丘の上で強い）、錫杖（水辺＝水に接するマスで強い）。
- 「強い」とは、立っているマスから撃つと、魔法の形が少し変わること（LAB_F の F3「足場」と同じ中身）:
  - 森の中: 草なら森が1マス多く茂る。ほかの魔法は、形の最後のマスの先にもう1マス【仮】
  - 山・丘の上: 形が正面へ1マス先にずれる（高台）
  - 水辺: 流れる・吹く魔法は届く長さが1マス長い。ほかの魔法は、形の横にもう1マス【仮】
- その武器の自然以外では、足場の効果はない（F3 がオンのときも、G6 がオンなら武器の自然だけに効く）。
- エディットで、味方に武器を付け替えられる。駒に武器の印。

シナリオ「ラボ: 武器と足場」: 森・丘・川が少しずつある盤面。味方は同じ魔法のまま、武器だけ付け替えてくらべる。
問い
- 武器を持ち替えると、立ちたい場所が変わったか
- 「足場を作ってから立つ」という手順が生まれたか

### G7 味方撃ちで「まとう」　★

元: 10/1「あえて味方に魔法を撃って威力アップ（ダメージは食らう）」「何もないところに魔法を撃つことに価値を持たせる（味方撃ちに効果を持たせたい）」。

ルール
- 魔法がユニットに当たると、そのユニットは今どおり直撃を受け、さらにその魔法を **まとう**（駒に、まとった魔法の印）。
- まとった者の次の1発は、自分の魔法より先に、まとった魔法が形の各マスに当たる（G4 の融合と同じ処理。1回で消える）。
  - 例: 火の人に風を撃つ → 火の人の次の火は「風 → 火」＝ 火の渦。草の人に水を撃つ → 次の草は「水 → 草」（LAB_B の B2 がオンなら森）。
- まとうのはそのターンの終わりまで。撃たずにターンが終わると消える。
- 敵にも同じく効く（敵に撃つと、敵がまとう。敵の次の予告に、まとった魔法が乗る）。予告に「まとっている: 風」と出す。

シナリオ「ラボ: まとう」: 味方 風・火・水。敵2体。
- 試し方: 風の人が火の人に風を撃ち、火の人が1発で火の渦を出す。敵に風を撃つと、敵の火が火の渦になって敵の仲間を巻き込む。

問い
- 味方撃ちが「わざとやりたい手」になったか
- 敵にまとわせて、敵の魔法を化けさせる手が気持ちよかったか
- 1人で2段目へ行けてしまう問題と、ダメージを食らう代償が釣り合っていたか

### G8 強化系の魔法は、敵が先に持っている　★

元: 10/12「強化系の魔法は、最初は敵が少し強いものとして持っていて、やがて自分も使えるようになるイメージがいい」。

ルール
- 敵が強化された魔法（G1 の一気に二段、G3 の姿の変わった形 など、作ったもの）を使ってくる。予告と早見表に「強化: 〇〇」と出す。
- その敵を倒すと、戦闘の終わりに「〇〇を覚えた」と出て、同じ魔法の味方がその強化を得る。
- ラボでは2つ続きのシナリオで試す: 1戦目で強化を持つ敵と戦い、勝つと2戦目に強化を持って入る。LAB_H の周回（H1）があれば、その中でも起きるようにする。

シナリオ「ラボ: 敵の技を覚える」（2つ続き）: 1戦目は強風を使う風の敵。2戦目はこちらの風の人が強風を使える。
問い
- 「敵が使っていた技を、自分が使える」に嬉しさがあったか
- 敵が強化を使ってくることで、敵が強く見えたか

### G9 1人が2つの魔法を持つ　☆

元: 10/3「魔法が1人1種類なのも難しくしていて、複数使えるだけで何でもできるようになる。2つ持つ、1つの魔法でどちらにするか決めて放つ、メンバーごとに使えるものが違い使い分ける、なども考えられるが、全部使えればいいとはあまり思っていない」。アイデア.md「魔法の核を複数所持して、撃つときに決定できる形は？　スピード感とありきたりがいやだけど、丸い」。

ルール
- エディットで、味方1人に2つ目の魔法を付けられる。手番で、撃つ前にどちらを撃つか選ぶ（キーか一覧で切り替え。予測はすぐ切り替わる）。
- 1手番に撃てるのは1発のまま。
- 2つの組み合わせはオーナーが選ぶ（例: 草と水、土と氷）。

シナリオ「ラボ: 2つの魔法」: 2つ持ちの1人と、ふつうの2人。
問い
- できることが増えて、楽しくなったか、迷うだけになったか
- 「パーティがそのままレシピになる」がほどけたか
- キャラごとの個性（キャラ売り）が薄まらなかったか
