# 発動の途中の見せ方 — 型と、広げる順番（オーナー 11/16・11/17）

試遊で「この魔法を撃ったから、こうなった」が伝わらなかった。盤面が先に結果の形に描き直されて、自然が変わる瞬間が画面になかったから（オーナー 11/16）。
燃え広がりで試作し、オーナーが録画を見て「この型で進める」（11/17）。この仕様書は、その型をほかの決め手と小さな変化に広げるためのもの。

## 1. 決まった型

```
魔法の姿が進む ─→ 触れる ─→ そのマスが変わる ─→（当たった人に数字）─→ 次の瞬間へ … ─→ 全部終わって名前と光
  風の筋・炎の玉     ほどける      変わった先の色の光       同じ瞬間に、そのマスに            「火×風！」
                   ふくらむ      火の粉（炎・火山）
```

- **順番ではなく、変わる瞬間を見せる。** 「何歩目か」の波ではなく、魔法の姿が実際に動いて触れた所が、その場で変わる（オーナー 11/16）。
- **ルールは記すだけ。** `rules.js` が触れた順に瞬間を記し（`moment` → cast の出来事の `trace`）、画面がそれを順に再生する（`ui.js` の `midPlay`）。盤面の結果は変えない。
- **数字は当たったマスで、そのマスが変わるときに。** ダメージの出来事の `at`（当たったマス）と `when`（何番目の瞬間か）。
- **名前と範囲の光は最後。**
- **敵の魔法も同じ道を通る。** 法則に例外はない。
- **飛ばせる。** 今はどのキーでも飛ばせる（途中の姿も消える）。展示のタッチは 5章。
- **時間は調整できる。** `balance.js` の `fx.mid`。開発モードの「途中の見せ方」パネル。

### 1つの瞬間の形（今あるもの）

`{ by: 何が触れたか, dir: どちらへ, what: 何をした, at: 触れたマス, cells: [{ x, y, from, to }] }`

| what | 意味 | 画面 | 今使っている所 |
|---|---|---|---|
| cast | 形のマスすべてに同時に触れる | 形のマスに魔法の玉が現れ、マスが変わる | 草・土・山・火（置く・点ける） |
| pass | 吹き抜ける | 姿が1マス進む | 風 |
| stop | ぶつかって止まる | 姿がつぶれて消える | 風（山・火山など） |
| fan | 炎・火山に当たる | 姿がほどけて消える | 風 |
| swell | 炎がふくらむ | 炎の玉が大きくなる | 燃え広がりの起点 |
| spread | 流れて触れる | 姿が1マス進み、マスが変わる | 燃え広がりの通り道 |
| kindle | つながった全体が一度に変わる | 全体が同時に光る（`wave` で少しずらす） | 山脈ごと火山 |

## 2. 広げる先と、それぞれの瞬間

結果から逆算せず、動詞と自然の性質から「何がどう動いて触れるか」を決める（CLAUDE.md 4章）。足す `what` は太字。

### 小さな変化（魔法）

| 変化 | 今 | 瞬間の流れ（案） |
|---|---|---|
| 森に火で炎・炎に土で山・水たまりに土で泥沼 など（置く・点ける） | **済**（cast） | 形のマスに玉 → マスが変わる |
| 水（流れる）: 水たまり・森で止まる・炎を消す・人に当たる | まだ | 水の玉が正面へ進む（pass）→ 当たって変わる（spread）か止まる（stop） |
| 山に水で川が流れ出す | まだ | 水の玉が山に当たる（stop）→ 当たった所から下りへ、川が**流れ下る**（**flow**。1マスずつ進み、触れたマスが川になる。頂上なら4方向へ同時） |
| 川に風で水たまり | ほぼ済（pass で書き足し） | 風が吹き抜けた所が水たまりになる。水が運ばれる向きが分かるか、画面で見る |

### シナジー・決め手

| 決め手 | 瞬間の流れ（案） |
|---|---|
| 燃え広がり | **済** |
| 山に届いて火山 | **済**（kindle） |
| 桜吹雪 | 風が火山に当たる（fan）→ 火山がまるごと**吹き上がる**（**burst**。火山が山に戻る）→ 花びらが扇へ段ごとに**舞い散る**（**scatter**。1段ずつ進み、積もるマス・当たった人がそのとき変わる） |
| 感電（試し） | 雷がジグザグに走る（pass）→ 水に落ちる → つながった水に一瞬で走る（kindle） |
| 凍結（試し） | 冷気が水に触れる → つながった水へ、触れた所から凍っていく（kindle の `wave`。オーナーが「触れた所から波で広がるのが見える」を面白いと言った所） |
| 火の渦・センタクキ・オバケヤシキ（試し） | 渦が巻く・引き寄せられる、の姿を決めてから |

### 時間で変わるもの（ターン終了）

| 変化 | 瞬間の流れ（案） |
|---|---|
| 炎が隣の森・村へ燃え移る | 炎から隣のマスへ火が**移る**（同時に決まるので、全部いっしょに）→ 燃え上がる |
| 小さな炎が消える・花びらが散る・風がやむ | 消える・散る・やむ姿を、全部いっしょに |

ターン終了は cast の出来事ではないので、`fireSpread` などの出来事にも `trace` を付ける形にする。

## 3. 作る順番

| 段 | 中身 | 大きさ |
|---|---|---|
| 1 | 水（流れる・止まる・消す）と、山に水で川が流れ下る | 中 |
| 2 | 桜吹雪 | 中 |
| 3 | ターン終了の燃え移り | 小 |
| 4 | 試しの決め手（感電・凍結・火の渦・センタクキ・オバケヤシキ） | 中 |
| 5 | 展示のタッチで飛ばす操作・時間を決めて、`fx.mid` の【仮】を外す | 小 |

- 1 は展示の②（山 → 水で川の壁）がそのまま使う。②の「なぜ道がふさがったか」が見えるようになる。
- 2 は③の決め手。
- 3 は「炎は燃え移る」を見せ、時間の変化を読めるようにする（CLAUDE.md 3章「見える」）。
- 4 は展示で使っていないので後。

## 4. 各段に共通の約束

- 瞬間を記すのは `rules.js` だけ。画面は瞬間の形だけを見て再生する（魔法ごとの分岐を画面に増やさない。足すのは `what` と姿の見た目だけ）。
- 盤面の結果・出来事の文は変えない。テストは CLAUDE.md 11章のとおりすべて通す。足した `what` ごとに `tests/run.js` に「瞬間の並び」を確かめるテストを足す。
- 動いている所は録画して見せる（スクリーンショットでは変わる瞬間が分からない。オーナー 11/16）。
- `docs/画面構成.md` と `NOTES.md` を同じ変更の中で直す。

## 5. まだ決めていないこと（オーナー）

- ターン終了の変化も途中を見せるか（毎ターン見せると長くなる）。
