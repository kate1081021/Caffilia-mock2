# 段3 展示の流れと展示の並び（IMPROVE_v3、10/30）

## 展示モード

```
最初の画面   カフィーリア【仮】
  [はじめから遊ぶ] ──→ 並びの順に1つずつ ──→ ここまで遊んでくれてありがとう！【仮】
  [ステージを選んで遊ぶ] ─→ 一覧から1つ ──→ クリア！【仮】
                                  どちらのあとも [最初の画面に戻る] [ほかのステージで遊ぶ]
```

- 「選んで遊ぶ」の並びが空のときは、そのボタンを出さない（初めの形では「はじめから遊ぶ」だけ）。
- 負けたときは今までどおり、そのステージの頭からやり直す。
- 文（カフィーリア・ありがとう！・クリア！ など）は【仮】。texts.js の ui に置けば替わる。

## 開発モードの「展示の並び」

```
開発の最初の画面 → [展示の並び]
  ⚠ 注意！ここを変えると、展示モードの並びが変わります
  はじめから遊ぶ の順番   ≡ ③ 3人でつなぐ  [外す]    ← ≡ をつかんでドラッグ
                          ≡ ① 重ねる        [外す]
  選んで遊ぶ に出すもの   ≡ ① 重ねる        [外す]
                          ≡ 〇〇の森        [外す]
  ＋ 足す  [▼ ステージ] [はじめから に足す] [選んで遊ぶ に足す]
  [この並びで展示する] → 確かめ「本当に変えますか？」→ はい → 展示モードが変わる
```

- 並べ替えている間は、展示モードは変わらない（「まだ展示モードは変わっていません」と出る）。
- **段3 だけの形**: 並びはこのブラウザに残す。足せるのはチュートリアルと**自分のステージ**（段4 で、共有したみんなのステージに替える）。
- 並びに入っている自分のステージは消せない。名前を変えたら、並びの名前も付け替わる。

## 今まで通りに動かなくなったもの

| もの | どうなったか |
|---|---|
| 展示モードを開いたとき | 最初の画面から（前は、開くとすぐチュートリアル①） |
| ③をクリアしたあと | 「ありがとう！」の画面になる（前は③のまま止まっていた） |
| 自分のステージを消す | 展示の並びに入っているものは消せない |

テストの結果は前と同じ（ルールには手を入れていない）。

## 確かめたこと（内蔵ブラウザ）

- 展示モード（並びなし）: 最初の画面に「はじめから遊ぶ」だけ。
- 展示の並び: ③を本物のマウスで一番上へドラッグ → まだ保存されていない。②を外す・選んで遊ぶ に ①と「③ 3人でつなぐのコピー」を足す → 「この並びで展示する」→ 確かめの窓 → 保存された。
- 並びに入っている「③ 3人でつなぐのコピー」を消そうとする → 「展示の並びから外すと消せます」と出て消えない。
- 展示モード: 最初の画面に2つのボタン → はじめから遊ぶ で③から → ③を正解の手でクリア → ①へ → ①をクリア → 「ここまで遊んでくれてありがとう！」と2つのボタン。
- ほかのステージで遊ぶ → 一覧に ①・③のコピー → ① をクリア → 「クリア！」と2つのボタン → 最初の画面に戻る。③のコピー（自分のステージ）もボス付きで遊べた。
- 開発で「③ 3人でつなぐのコピー」の名前を変える → 並びの名前も変わる → 戻すと元に戻る。
- コンソールのエラーなし。確かめ用の並びは消して、初めの形に戻した。

- `style.css`: 展示の最初の画面と並びの画面の見た目
