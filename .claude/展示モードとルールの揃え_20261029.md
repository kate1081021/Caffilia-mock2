## 1. 展示モードと開発モード

### 入り方

| 開き方 | モード |
|---|---|
| `index.html`（URL に何も付けない） | 展示モード |
| `index.html#dev` | 開発モード（今までのモックそのまま） |
| 開発用の入口 `#review` `?review` `#run` `#q` `#n` `#trial` `#today` `#tune=…`、見て判定の Artifact | 開発モード（今までどおりその画面が開くように） |

- 開いたまま `#dev` を付けたり外したりすると、読み込み直してモードが切り替わる。
- 決めるのは新しいファイル `mode.js`。`<body>` の頭で読む。公開（`tools/publish.js`）と見て判定の Artifact（`tools/build_review.js`）は、`index.html` の script を拾うので、`mode.js` もそのまま入る。

### 展示モードで出すもの

- 盤面
- 味方の欄
- 行動の欄（向き ↑←→↓・その場で構える・構える・待機・移動を取り消す）
- 発動の順番
- 敵の一覧と予告
- 会話の窓
- 上のバーの「発動」「1手戻す」「遊び方」
- 負けたときの「やり直す」

ほかは消さずに隠した（`style.css` の `html.mode-exhibit`）。

### 展示モードで効くキー

1〜9（味方）・矢印（向き）・Enter（構える）・Space（その場で）・W（待機）・T（発動）・Z と Ctrl+Z（1手戻す）・Esc（取り消し）だけ。
E（エディット）・C（クリアする）・Q（持ち替え）・B・K（ラボ）は効かない。

### 展示モードの進み方

- チュートリアル①から始まる。
- クリアすると、会話の窓を閉じてから 2.2 秒で次のステージを読む（① → ② → ③）。③のあとは止まる。
- 次のステージに入ると「1手戻す」の履歴は消える（前のステージには戻らない）。
- ターンの形は一斉発動に決まる。③の魔法の出し方は「つながる」に決まる。
- 開発モードでは、今までどおり「1人ずつ」も、③の3つの出し方も選べる。

### 頼まれた文になかったところで、こちらで決めたこと

| 決めたこと | 中身 |
|---|---|
| 開発用の入口 | `#review` などの入口は、`#dev` がなくても開発モードで開く（展示モードにすると、その画面が開かなくなるため） |
| 保存した調整 | 展示モードでは、調整パネルで保存した設定（ブラウザに残っているもの）を使わず、balance.js の値で動く。開発モードは今までどおり使う |
| 行動の欄 | 「その場で構える」（Space）と「移動を取り消す」も出した（構える・待機と同じ行動の欄にあるため） |
| 上のバー | タイトル「Caffilia シナジーモック」と、ターン数・状態の表示も隠した |
| 次へ進む間 | クリアしてから 2.2 秒。会話の窓が出ていれば、閉じてから |
| 1手戻す | 次のステージに入ったら、前のステージの履歴は消す |

### 展示モードで起きること（確かめた事実）

- **② の「クリアする」が出ない。** 道をふさいでも途中でクリアにはできず、5ターン守って勝つ形になる。内蔵ブラウザで、ふさいだあと C を押しても何も起きず、ターン5の終わりに勝って③へ進むのを確かめた。
- **お題の帯（目標・勝ち方・残りの数）と、案内の1行（今やること・勝ち負けの文）が出ない。** 勝ち負けは、盤面と会話の窓と「やり直す」でだけ分かる。
- **予測の箱（撃つ前の一言）が出ない。** 盤面の形の輪郭は出る。
- 遊び方の文に「スーパープレイを見る」「上の調整で数値をいじれる」とある。どちらも展示モードでは隠れている（文は texts.js のまま）。
- 会話の窓には、今の texts.js の「（ここに文章）」が出る（開始・クリア・負け・やり直しの場面）。
- ③の盤面（12×7）は、横幅 1024 の内蔵ブラウザで盤面の左端が画面の外にはみ出す。開発モードでも同じで、今回変えていない CSS によるもの。

- 残したステージの中身は次のとおり。
  - ②: 突進の速さ1、守るターン5、ふさいだらクリア（`overrides` に残した）
  - ③: ボス・取り巻き・湧き・ミッション・ヒント・勝ち負け
  - ①: 構える味方・1マスずつ進む敵・敵だけの山の魔法
  - ②の増援
- 調整パネルの「予測の見せ方」と各ラベルを足した。どれも調整パネルで切り替えられる。

### 揃えたことで、一緒に変わった動き

- **水たまり・蜃気楼に水を流しても、川に戻らなくなった（どのシナリオでも）。** 頂上と腕（`tutorial.slope`）を入れると、水たまりの扱いも②と同じになるため。前は本編だけ、水たまりに水を流すと川に戻っていた。
- **頂上と腕のない山は、前と同じに源流になる。** 土で盛った山と、盤面にもとからある山のこと。頂上と腕ができるのは、山の魔法（盛る）で作った山だけ。
- **予測を形だけにしたので、開発モードでも次のものが出なくなった。** 立ち位置の導き（緑のマスの ◆・）、あと一手のヒント、予測の箱の中身、構えのダメージの数、発動の順番の「合体！」の一言。調整パネルの「予測の見せ方」を切ると、前のように出る。
- **① の光るヒント（1回外したあと）が (1,1)〜(4,1) の4マスになる。** 風が実際に吹くのは (1,1)(2,1) の2マス。光るマスは魔法の形の決まり（風は `lineLength` の4マス）から取るので、前は①の上書き（風の長さ1）で1マスに見えていた。
- **③のボス（HP40）は、桜吹雪（威力20）1発では倒れない。**
