# 展示モードへの切り替えボタン（10/30）

## 動き

```
  開発モード（#dev） ─┐                    ┌─ 長押し → 開発モードに戻る
                      ├─ 長押し → 展示モード ┤
  作るモード（#make）─┘                    └─ 長押し → 作るモードに戻る

  展示モード（印のない URL） … 長押ししても何も起きない
```

- ボタンは右下の隅の小さな灰色の点。どのモードでも同じ位置・同じ見た目。
- **2秒長押しのときだけ**効く。普通のクリック・2秒より前に離す・指（マウス）が点から外れると、何も起きない。
- 押している間は、点が濃くなり、点の上に細い線が伸びる（2秒で伸びきる）。
- 開発・作るモードでは、点にマウスを乗せると「2秒長押しで展示モードへ」と出る。展示モードでは何も出さない。

## 切り替えたあと

| 行き先 | 始まり |
|---|---|
| 展示モード | チュートリアル①から |
| 作るモード | エディットから。作りかけの続き |
| 開発モード | いつもの始まり（開いたときと同じシナリオ） |

- URL の印は書き換えない。切り替えた元のモードは、このタブだけに覚える（sessionStorage）。
  - **読み込み直しても**、切り替えたモードのまま。
  - 新しいタブや、ブラウザを閉じて開き直したときは、URL の印どおりのモードから。
- 切り替える前に、エディットの作りかけを残す。
  - 作るモード: 戻ると、作りかけの続きからエディットが開く（テストプレイ中に切り替えても同じ）。
  - 開発モード: 今までどおり、E を押すと今のシナリオから作り始める。作りかけは、エディットの一覧の「1つ前に作っていた「…」」から読める。

## 今まで通りに動かなくなったもの

なし。テストの結果は前のコミットと同じ（run・scenarios・simul・ex3・lab・stages・tune・progress）。ルールの処理には手を入れていない。

## 気をつけること

- 切り替えると読み込み直すので、エディットの「1手戻す」の履歴と、遊んでいた途中の盤面は消える（読み込み直したときと同じ）。作りかけそのものは残る。
- 開発モードで調整パネルを開いていると、点がパネルの右下の隅に少し重なる。
- 切り替えた展示モードの URL には、元の印（#dev・#make）が付いたまま。アドレスバーを見れば元のモードが分かる。
- ブラウザが保存を使えない設定のときは、切り替えない（読み込み直すと元に戻ってしまうため）。

## 確かめたこと（内蔵ブラウザ）

- 作るモード: 普通のクリック → 何も起きない。1.5秒で離す → 何も起きない。2秒長押し → 展示モード（チュートリアル①）。読み込み直す → 展示モードのまま。もう一度2秒長押し → 作るモードで作りかけの続き（置いた森が残っていた）。テストプレイ中に切り替えて戻っても、作りかけが残った。
- 開発モード: 2秒長押し → 展示モード（チュートリアル①・保存した調整は使わない）。もう一度 → 開発モード。
- 印のない URL の展示モード: 2秒長押ししても、線も出ず何も起きない。
- コンソールのエラーなし。確かめに置いた森は消して、作りかけを元に戻した。

## 変えたファイル

- `mode.js`: 切り替えた元のモードを覚える・切り替える（`CafiliaMode.toggle`）
- `ui.js`: 右下の点の長押し（2秒）・切り替える前に作りかけを残す
- `index.html`: 右下の点
- `style.css`: 点と、押している間の線
- `DECISIONS.md`
