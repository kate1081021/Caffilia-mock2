# シナジーの方向性（2026-10-05）

モックを作るときの拠り所。ここから外れる案を出すときは、外れる理由を添える。

---

## ここまでの流れ

**出発点（〜9月末）** マナを塗り、同じ場所に重ね、強魔法の吸収で解き放つ形だった。展示ではシナジーがほぼ起きず、起きても気づかれなかった。重ねても同じ所に撃っているだけに見え、準備に価値がなく、吸収とシナジーが同時に起きて見る場所が分からない。根っこは、マナそのものに存在価値がないことだった。

**転換（10/1〜10/2）** シナジーは「関係性」で、役割は「決め手」だと言葉になった。溜めて放つは手段として外れ、「準備すら楽しい」「関係ないところに撃って、その一手で勝つ」「環境を利用して倒す」が残った。

**骨格（10/3）** 魔法を撃つと自然になり、作った自然を敵ごとぶっ壊す。マナが自然として現れる、魔法が現実になるつなぎ目にシナジーを置く。魔法は属性より動詞で考える。

**モック（10/4）** 自由に1マス撃てる形は「カフィーリアではない」。着弾点を選べないことと、魔法が複数マスの形を持つことがカフィーリアらしさの一部だと分かった。制約を入れると、森 → 火 → 風の燃え広がりがはっきり面白くなった。凍結・噴火で、判断の基準がいくつか固まった。

**守りと火薬（10/4）** 作った自然は生き延びるための壁であり、壊すときの火薬でもある。敵も同じ法則で自然を作る。

## シナジーとは

- 関係性。新しいものを発見できそうな期待と、納得感の両方がある
- 役割は決め手。なくても削れるが、倒すにはシナジーが欲しい
- 準備すら楽しい。溜めて放つは手段であって目的ではない
- 中身はぐちゃっとしていていい。法則寄りのもの、突飛なもの、現実にあるものが混ざった世界

## 骨格

1. 魔法を撃つと、その形のマスが自然になる
2. 自然は現実の法則で振る舞う。例外を作らない
3. 同じものを当てると育つ。違うものを当てると、変わるか壊れる
4. 壊すことが決め手。自然の上で終わらず、自然を飛び出して作用する
5. 作った自然は守りでもあり火薬でもある。壊すと、その自然が担っていた守りも消える
6. 敵も同じ法則で自然を作る。違いは体（何を越えられるか、何を壊せるか）に出る

## 順序がシナジーを決める

シナジーは組み合わせではなく、順序で決まる。

先にそこにある自然が「舞台」で、後から来た魔法が「出来事」になる。結果は「〇〇があるところに、△△が来たから、□□になった」と一言で語れるものにする。語れないものは、イメージから遠い前提として外す。

同じ2つでも、順序が逆なら別の結果になるか、何も起きない。

| 先にあるもの | 後から来るもの | 結果 |
|---|---|---|
| 炎 | 水 | 消える |
| 水 | 火 | 立ちのぼる（蜃気楼など） |
| 山 | 火 | 噴火する |
| 炎 | 土 | 埋まって消える |
| 竜巻（風が先） | 水 | センタクキ |
| 川（水が先） | 風 | 渦にはしない（イメージから遠い） |

発火は、最後に来た魔法で決まる。

味方は1人ずつ、好きな順で動く。なので、手番の順番がそのまま自然の物語の順番になる。誰から動くかが、どのシナジーになるかを決める。

### 段の順序

- **1段目　作る**：魔法が自然になる。納得感を大事にする
- **2段目　変わる・壊れる**：現実の災害。現実とつながっていて、予想できる
- **3段目　化ける**：超常。法則からはみ出していい、突飛でいい

段は飛ばさない。2段目は1段目で作った自然の上で起き、3段目は2段目までに育った自然の上で起きる。同じ舞台でも、最後に来る魔法によって2段目にも3段目にもなる（竜巻に火なら火炎竜巻、竜巻に水ならセンタクキ）。

## 今あるつながり（順序で書く）

括弧は、後から来る魔法。

**森の筋**
- 草 → 森 →（火）炎 →（風）燃え広がり【2段目】
- 森 →（雷）落雷で炎

**山の筋**
- 土 → 山 →（土）山脈 →（火）噴火・溶岩【2段目】
- 溶岩 →（水）冷えて山
- 火山 →（風）桜吹雪【3段目・試し】

**水の筋**
- 水 → 池。山のそばなら源流になって川
- 川 →（雷）感電【2段目】
- 川 →（氷）凍結。壁が氷の道に変わる【2段目】
- 川 →（土）泥沼【変わる】

**風の筋**
- 風 → つむじ風 →（風）竜巻
- 竜巻 →（火）火炎竜巻【2段目】
- 竜巻 →（水）センタクキ【3段目】

**消す・変える**
- 炎 →（水）消える
- 炎 →（土）埋まって山
- 水たまり →（火）蜃気楼

## 判断の基準

- 作る側は納得感、壊す側は気持ちよさと突飛さを優先する
- 面白さより、世界の法則に従う
- イメージから遠い前提はいらない。「ここに撃ったら変わる」でいい
- 材料の大きさで変わるのは範囲。ダメージは一定にする
- 止め方は自然ごとに変える（渡れない、通れない、抜けられない、見えない）
- 見たいのは、倒せなくても場面が大きく変わって、見ているだけで楽しい場面。大きくなって、一気に変わる

## 開いていること

- 3段目の起こし方（桜吹雪は決め手まで届いていない）
- 光と闇の扱い（雷はある。闇の方向はまだ）
- 氷で凍らせたあとに何が起きるか
- 水蒸気爆発をどこに置くか（火山のものではない）
- 泥沼の壊れ方
- 時間で変わる自然をどこまで入れるか
- 人も山も1マスという縮尺の違和感
- 敵の設計（シナジーが安定してから）

## 次のモックで確かめること

- 順序を入れ替えると結果が変わることが、遊んで伝わるか
- 止め方の違いで、どの自然を作るか迷えるか
- 育てるか壊すかで手が止まるか
- 壊したときにどこまで届くかが、撃つ前に読めるか
