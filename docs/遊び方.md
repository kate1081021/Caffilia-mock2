# 遊び方

1戦の進み方・勝ち負け・操作。自然や魔法が何を起こすかは [自然と魔法とシナジー](自然と魔法とシナジー.md)、画面のどこに何があるかは [画面構成](画面構成.md)。

（11/03 時点のコードから書いた。数はどれも `game/balance.js` にある）

## 盤面と駒

- **盤面**はマスの並び。1マスに自然は1つまで（森・山・川・炎など。何もないマスは「空き」）。チュートリアルは ① 5×5、② 6×6、③ 10×7。新しく作る盤面は 6×6（5〜12 まで変えられる）。
- **味方**は1人1つの魔法を持つ。HP 3・1ターンに動けるのは2マスまで・魔法を人に当てたときの直撃は1。
- **敵**は HP 5・移動2・直撃3。敵の魔法が当たると、味方はほぼ一撃で倒れる（意図した手触り）。
- **置きもの**: 村（動かない・通れない。HP 1。燃える）とトロッコ（風で押される。HP 3）。お題で使う。

法則に例外はない。敵の魔法も自然を作り、敵の作った自然はこちらも使える。味方も風で運ばれ、炎で焼ける。

## 1ターンの流れ

ターンは「味方全員 → 敵」。味方は、移動して構え、ターンの終わりに全員で一斉に撃つ（一斉発動）。

1. **ターンの始め**: 敵の予告（紫の印。次に撃つ所）が出ている。味方はそれを見てから動ける。1ターン目、敵はエディットで置いた所から動かずに予告する（味方から動くのが基本。オーナー 11/03）。
2. **味方の手番**（順番は自由）
   1. 味方を選ぶ。
   2. 緑のマスへ動く（2マスまで。山・川など通れない所は通れない）。動かずにその場でもいい。
   3. 十字の矢印で向きを決めて「魔法」で構える。撃たないなら「待機」。
      - 着弾点は選べない。魔法は決まった形を持ち、立ち位置と向きで当たる所が決まる。盤面の点線が届く形。何が起きるかは出ない（撃ってのお楽しみ）。
      - 構えた魔法は、まだ撃たれない。
3. **発動**: 全員が構えるか待機すると、右下の「発動」が押せる。構えた順に1人ずつ、その人の位置と向きから撃つ。
   - 展示モードの順番は「魔法」を押した順。開発モードは右上の「発動の順番」で入れ替えられる。
   - 前の人の魔法でできた自然に、後の人の魔法が当たると、別の自然やシナジーになる。順番が結果を変える。
4. **敵の魔法の発動**: 予告したとおりに撃つ。
5. **ターン終了**: 時間で変わる自然が動く（炎が隣の森と村へ燃え移る・小さな炎や風が消える・火傷や炎の上・火山の隣のダメージなど。炎は燃え尽きない。くわしくは [自然と魔法とシナジー](自然と魔法とシナジー.md) の「時間で変わるもの」）。
6. 増援があるステージでは敵が増える。
7. **敵の移動と予告**: 敵が動いて、次のターンに撃つ所を予告する（前は次のターンの始めだった。中身は同じで、1ターン目だけ動かなくなった）。それから次のターンへ。

困ったら「1手戻す」（Z）でひとつ前に戻れる。

## ダメージ

| もの | ダメージ |
|---|---|
| 魔法を人に当てた（直撃） | 味方の魔法 1／敵の魔法 3 |
| 強い炎（燃え広がりで、燃えた森の上） | 20 |
| 弱い炎（燃え広がりの通り道など） | 5 ＋ 火傷 |
| 火傷 | ターン終了ごとに 2 を2回（水か氷が当たると治る） |
| 炎の上でターン終了 | 2 |
| 火山の隣か上でターン終了 | 2（熱） |
| ほかの決め手（桜吹雪など） | 20 |

1発の中では、1人が受けるダメージは1回だけ（一番大きいもの）。

## 勝ち方（お題）

| お題 | 勝ち | 負け |
|---|---|---|
| 戦闘 | 敵を全員倒す | 動かせる味方が全員倒れる |
| 村を守る（防衛） | 決まったターンの終わりまで村を守る。または、村への道をふさいで「クリアする」 | 村が壊される |
| ボスを倒す（③） | ボスを倒す（取り巻きは数えない） | 味方が1人でも倒れる → 少し見せて自動で頭からやり直し |
| 護衛・奪取 | トロッコをゴールへ／宝を持ち帰る | トロッコが壊れる など |

- 村を守るでは、突進の敵と増援の出てくる所から、地形だけで村へ行けなくなったら、右下の「クリアする」ですぐクリア（②）。前は「道をふさぐ」という別の勝ち方だったが、同じものなので1つにした（オーナー 11/03）。突進の敵がいないステージでは、ふさいでクリアにはならない。
- 護衛・奪取はルールに残っていて、エディットで選べる（展示のステージでは使っていない）。

## 展示で遊ぶ流れ

```
最初の画面 ─[はじめから遊ぶ]──→ ① → ② → ③ → 「ありがとう！」（試遊アンケートの QR）
          └[ステージを選んで遊ぶ]→ 一覧から1つ → 「クリア！」（QR）
```

- 「はじめから遊ぶ」の順番と「選んで遊ぶ」に出すステージは、開発モードの「展示の並び」で決める。共有の置き場所につながらないときは、チュートリアル①②③だけ。
- クリアすると右下のボタンが「次へ」になる。負けたら「やり直す」。
- 左上の「⌂ タイトル」で最初の画面に戻れる。

### チュートリアル①〜③

| ステージ | 味方 | 敵 | 教えること |
|---|---|---|---|
| ① 重ねる（5×5） | 火（自分）・風（構える味方。毎ターン同じ所へ風を構える） | 森の中にいて、毎ターン左へ1マス進む。山を盛る魔法 | 仲間の風が来るマスに火を構えると燃え広がり、森ごと敵が燃える。敵ではなく、何もないマスに撃つ一手で勝てる。1回外すと、構える味方の狙うマスが光る |
| ② 2人で守る（6×6・防衛） | 山・水 | 突進（人を無視して村へ1ターン1マス、村の隣で体当たり）。毎ターンの終わりに上から1体増える | 倒しきれない敵は、自然で道をふさぐ。山に水を当てると川が流れて壁になる。ふさぎきったら「クリアする」ですぐクリア。5ターン守っても勝ち |
| ③ 3人でつなぐ（10×7） | 山・火・風 | ボス（3×3・HP 20・前の2列に一撃）と取り巻き（浮く・HP 1・風の人へまっすぐ進む。2ターンごとに湧く） | 山 → 火山 → 桜吹雪。3人の魔法をつないで、扇の中の敵をまとめて吹き飛ばす。ミッション「火山を作る」 |

## 操作

### 盤面のクリック

| 押す所 | 起きること |
|---|---|
| 味方 | その味方を選ぶ（構えた・待機した味方は薄くなり、選べない） |
| 緑のマス | 選んでいる味方がそこへ動く。元のマスを押すと戻る |
| どのマスでも | そのマスの自然と駒のことが左上に出る |
| それ以外 | 選ぶのをやめる |

### キー（おまけ）

| キー | 働き |
|---|---|
| 1〜9 | 味方を選ぶ |
| 矢印・WASD | 向き |
| Enter | 味方を選んでいれば「魔法」。選んでいなければ右下のボタン（発動・クリアする・次へ・やり直す） |
| Z | 1手戻す |
| Esc | 動いていれば元の位置へ。でなければ選ぶのをやめる |
| 発動の演出中に何か押す | 演出を飛ばす |
| E・V・Delete（開発モードだけ） | エディット ⇄ テストプレイ・見た目（真上 ⇄ 奥行き）・エディットで駒を消す |
