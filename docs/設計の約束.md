# 設計の約束

カフィーリア シナジーモックが何で、何でないかを決めた文書。新しい案を出すとき・ルールを変えるときは、必ずここに照らして判断する。
書き換えるのはオーナーだけ。Claude は変更を提案してよいが、書き換えない（`CLAUDE.md` 1章）。
遊んで分かったことや今の課題は `NOTES.md`、今のゲームの説明は `README.md` と `docs/` の枝にある。

## 1. コア

**自分たちで広げた自然を、シナジーで一気にぶっ壊す快感。**

魔法 → シナジー → 超常現象

カフィーリア（タイル型の盤面で魔法を撃って戦う戦略ゲーム）の、シナジー部分だけを確かめるモック。主役はシナジー。
ゲームの目的は敵を倒すこと。シナジーはその決め手で、なくても削れるが、倒すにはシナジーが欲しい、という強さに置く。

## 2. 目指すもの

制約（7章）は越えてはいけない線。こちらは迷ったときに向かう方向。

**やりたいこと**

- シナジーを起こす快感
- 魔法を現実に存在させる。それでプレイヤーからの信頼を得る
- 盤面で楽しませる

**やってみたかったこと**

- 魔法を撃って、敵の進路を誘導する
- 何もないところに魔法を撃つことに価値を持たせる（味方撃ちに効果を持たせる）
- 環境を利用して倒す

## 3. 魔法・シナジー・超常現象

段階によって、何を優先するかが違う。

| 段階 | 中身 | 優先すること |
|---|---|---|
| 魔法 | 魔法を撃つとマスが自然になる。自然に別の魔法を当てると、別の自然に変わる | **納得感。** 動詞と現実から結果が予想できる |
| シナジー | 自然が広がる。プレイヤーが並べて広げ、自然も法則どおりに広がる | **納得感と読みやすさ。**  |
| 超常現象 | シナジーでできた自然を壊す。 | **気持ちよさと突飛さ。** 予想できなくていい。見て分かればいい |

- 魔法とシナジーは信頼を作る場所。ここで例外や説明のつかない結果を出さない。
- 超常現象は快感を作る場所。広げた自然が大きいほど、大きく壊れる。作って終わりにはしない。
- 突飛さが許されるのは超常現象だけ。

### シナジーと時間

シナジーの主役はプレイヤー。自分たちの手で並べて広げ、育てる。
そのうえで、自然が時間で自ら広がることも入れてよい。自然の醍醐味であり、新しさにもなる。ただし自分でコントロールできないものなので、次をすべて満たすこと。

- **見える。** 次のターン終了で何がどこへ広がるかが、盤面に予告される。
- **一定。** 決まった条件・決まった量で広がる。乱数を使わない。
- **曲げられる。** 魔法で止めたり、向きを変えたり、早めたりできる。天気のように、読めて、手で曲げられる。
- **現実に沿う。** そう広がるのが自然だと納得できる。
- **敵にも同じ。** 敵の自然も同じように広がる。

## 4. シナジーの生まれ方

シナジーは「面白いから足す」ものではなく、**世界の法則から出てくるもの**。

- 魔法とシナジーの結果は、関わる自然の性質と魔法の動詞（6章）から説明できなければならない。説明できない結果は、面白くても採らない。
- 新しいシナジーを考えるときは、結果から逆算しない。「この自然はこういう性質を持つ」「この魔法はこう作用する」を先に決め、そこから何が起きるかを導く。
- 法則は小さく、例外なく。敵にも味方にも、同じ盤面なら同じ結果になる。

## 5. 柱

1. **法則に例外はない。** 敵にも味方にも同じルールが効く。味方も風で運ばれ、炎で焼ける。敵も同じ魔法で自然を作り、敵の作った自然はこちらも使える。
2. **魔法 → シナジー → 超常現象。** 3章のとおり。
3. **立ち位置と向きで決まる。** 着弾点は選べない。どこに立ち、どちらを向くかがパズルになる。
4. **見て楽しい。** 動かして楽しいだけでなく、動いているのを見て楽しい。連鎖が1つずつ見え、決め手は派手に。

## 6. 魔法の動詞

魔法の作用は、その魔法の動詞の範囲で考える。動詞からはみ出すと違和感が出る。

- 新しい魔法を足すときは、まず動詞を1つ決める。
- 今ある魔法と動詞は `docs/自然と魔法とシナジー.md` の「魔法」にある。

## 7. カフィーリアの制約

モックでも必ず守る。

- 味方は最大3人。1人1魔法。ターンは「味方全員 → 敵」。味方の行動順は自由。
- 魔法は決まった複数マスの形を持つ。形のマスすべてで同じように効果が起きる。
- 着弾点はない。立ち位置と向きで決まる。
- 1マスに置ける自然は1つ。
- 乱数を使わない。撃つ前に結果がすべて見える。

## 8. やらないこと

案に出さない。

- マナや自然の濃淡（表現が難しく長期化する）
- 確率で起きる効果
- 3章「シナジーと時間」の条件を満たさない、時間による変化
- 正解の組み合わせがないと壊せない形
- 元からある地形に頼るしかない状況
- プレイヤーが想像できない現象


## 9. 案の出し方

新しい案・ルールの変更は、次の順に照らしてから出す。途中で引っかかったら、その案は出さないか、引っかかった理由を添えて相談する。

1. 7章の制約と8章のやらないことに触れていないか。
2. 2章の目指すもののうち、どれに近づく案か。どれにも近づかない案は出さない。
3. どの段階（魔法・シナジー・超常現象）の案か。
4. その段階の基準（3章）を満たすか。魔法・シナジーの案なら、どの性質と動詞から結果が出るかを1文で説明できるか。時間で広がる案なら「シナジーと時間」の条件をすべて満たすか。
5. 敵にも同じルールで働くか。
6. 立ち位置・向きで結果が変わるか。
7. 広げた自然が大きいほど、結果が大きくなるか（超常現象の案のとき）。
8. 見て楽しいか。連鎖が目で追えるか。
