# 会話の書き方（まえげき・あとげき）

ステージの前と、勝ったあとに、キャラの会話を出す。まえげきは目的を、あとげきは起きたことの仕組みを伝える。遊んでいる最中には出さない。
画面は `game/talk.js`、キャラの登録は開発モードの「キャラ」（[画面構成](画面構成.md) の「キャラ」。データの形は `game/chars.js`）、会話の中身はステージのデータ（定義の `talk`）。勝ち負けの条件は [条件の書き方](条件の書き方.md)。

## キャラの登録（開発モードの「キャラ」）

開発の最初の画面の「キャラ」で登録する（くわしくは [画面構成](画面構成.md) の「キャラ」）。登録したキャラは、どのステージの会話にも出せる。

| 項目 | 中身 |
|---|---|
| 名前 | 会話の窓の名札に出す名前。エディットの会話の欄では、この名前で書く |
| 色 | 名札と、仮の絵の色 |
| 会話の絵 | 表情ごとの絵。「ふだん（normal）」がいつもある。表情を足したら、会話の行に `face` を書く |
| 戦闘の絵 | 盤面に立てる絵（空なら会話のふだんの絵） |

- 会話の行の `who` は、キャラの見えない id（`charA` など。キャラの画面で名前の横に小さく出る）を指す。名前を変えても会話はそのまま。
- 絵がない・読み込み中のあいだは、色と名前の字で作った仮の絵を出す。
- 置き場所にまだキャラがないときは、コードの最初の中身（仮の2人 キャラA・キャラB と、デフォルト敵）。チュートリアルの仮の会話は、仮の2人が喋る。

## 会話（ステージの定義の `talk`）

```json
"talk": {
  "before": [
    { "who": "charA", "side": "left",  "text": "敵が村へ走ってくる。倒しきれないよ" },
    { "who": "charB", "side": "right", "text": "倒さなくていい。村への道をふさげば守れる" },
    { "who": "charA", "side": "left",  "text": "山と水で、道をふさぐんだね" }
  ],
  "after": [
    { "who": "charA", "side": "left",  "text": "山に水を当てたら、川になって流れた！" },
    { "who": "charB", "side": "right", "text": "水は山の斜面を下って川になる。川は、敵の通れない壁になる", "face": "smile" }
  ]
}
```

| 項目 | 中身 |
|---|---|
| `before` | まえげき。そのステージを初めて始めたときに出る |
| `after` | あとげき。そのステージに初めて勝ったときに出る |
| `who` | キャラの id。登録のない名前も書ける（その名前の仮の絵で出る）。空（`""`）か書かなければ語り（キャラなし・文は真ん中） |
| `side` | `"left"` 左／`"right"` 右。右のキャラは左を向く（向かい合う） |
| `text` | 文（200字まで） |
| `face` | 表情の名前（書かなければ `normal`） |

- 1つの会話は60行まで。
- `talk` は「名前 → 行の並び」。`before`・`after` のほかの名前も書けるが、今は出ない（のちに、ステージの途中の会話に使う）。

### エディットで書く

エディットの右の欄の「会話」に、まえげき・あとげきの欄がある。1行が1つの文。

```
左 キャラA「敵が村へ走ってくる。倒しきれないよ」
右 キャラB「倒さなくていい。村への道をふさげば守れる」
左 キャラA「山と水で、道をふさぐんだね」
```

- `左`・`右` を書かなければ、初めてのキャラは空いている側、2度目からは前にいた側になる。
- 表情は `キャラB:smile「…」`。「」のない行は語り。
- 「まえげきを見る」「あとげきを見る」で、今の欄の中身をその場で流せる。
- 「見たしるしを消す」で、このブラウザの「もう見た」を消す（どのステージも、次に始めたとき・勝ったときにまた出る）。

## いつ出るか

| | 出る | 出ない |
|---|---|---|
| まえげき | そのステージを初めて始めたとき | やり直し・リセット・2度目から |
| あとげき | そのステージに初めて勝ったとき（手の演出が終わってから） | 負けたとき・2度目の勝ち |

- 自分のステージ（テストプレイも）だけは、作りながら確かめるので毎回出る: 始めるたび・リセットのたび（まえげき）、勝つたび（あとげき）。負けたとき・やり直しでは出ない（オーナー 11/14）。

- キャラの大きさと位置は、開発モードの「設定」の「会話のキャラの大きさと位置」で変える（[画面構成](画面構成.md) の「設定」）。「会話で見ながら決める」で、本物の会話の画面を見ながら動かせる。
- 「初めて」は、開発モードではこのブラウザが覚える。展示モードでは、題字の画面に戻るまで（次の人には、また出る）。
- エディット中と、プレイ集を流している間は出ない。
- 並びごとの入切は `game/balance.js` の `talk.show`。

```js
talk: {
  show: { tutorial: true, shared: true, own: true, exhibit: true }
}
```

| 名前 | どの並びか |
|---|---|
| `tutorial` | 開発モードの一覧のチュートリアル |
| `shared` | 開発モードの一覧のみんなのステージ |
| `own` | 自分のステージ（テストプレイも） |
| `exhibit` | 展示モード（どのステージでも）。11/14 から入（オーナー「展示で表示したい」） |

## 見せ方

- ステージの画面の上に重ねる（後ろに盤面が見える）。キャラが左右に大きく出て、喋っているほうが明るく前に出る。
- タップ・クリック・Enter・スペースで次の文へ。右上の「とばす」か Esc で、いつでも終わる。
- 会話の間は、盤面もボタンもキーも受け付けない。
- 重ねる層の色と透明度は、`game/style.css` の `--talk-veil` の1か所。文の窓の色は `--talk-box`。

## 置き場所のチュートリアルとの関係

- チュートリアルの中身は共有の置き場所にある（コードの①②③は、最初の中身と控え）。置き場所のチュートリアルが `talk` を持っていれば、それが出る。
- 置き場所の①②③（id が `tut1`・`tut2`・`ex3` のもの）がまだ `talk` を持っていなければ、コードの仮の会話を出す。エディットで直して「チュートリアルに保存する」と、置き場所のものになる。
- みんなのステージから移してきたチュートリアル（id が `t`＋時刻のもの）には、コードの仮の会話は付かない。エディットで書いて保存する。

## 確かめ

`node tests/talk.js`（データの形・エディットの欄の書き方・定義に乗ること・出すかどうかの決め方）。画面は内蔵ブラウザで見る。
