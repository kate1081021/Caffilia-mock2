# 条件の書き方

勝ち・負け・「クリアする」のボタン・ミッションは、ステージのデータに条件として書く。コード（`game/rules.js`）が持つのは、盤面に問いかける部品と、条件を読むしくみだけ。
遊び方は [遊び方](遊び方.md)、エディットは [画面構成](画面構成.md)。決めたときの案と調査は `archive/仕様と調査/`（`IMPROVE_条件.md`・`調査_条件判定_20261112.md`）。

- ヒント・文のきっかけ・画面の進行・増援や取り巻きの湧きは、まだこの形ではない（今までどおりコードにある）。
- 条件を1つずつ編集する画面はまだない。エディットの「勝ち方」でひな形を選ぶか、ステージのファイル（JSON）を直接書く。

## ステージが持つもの

```json
{
  "name": "…", "rows": ["…"], "allies": ["…"], "enemies": ["…"],

  "template": "defense",
  "counters": { "lostVillages": { "add": { "see": "died", "where": { "kind": "village" } }, "reset": "never" } },
  "conditions": [
    { "id": "hold", "when": ["turnEnd"],
      "if": { "all": [ { "see": "turn", "min": 5 }, { "see": "units", "where": { "kind": "village" }, "min": 1 } ] },
      "then": "win", "text": "ターン5の終わりまで村を守る", "done": "ターン{turn}を守り切った。村は無事！（勝利）" }
  ]
}
```

| 項目 | 意味 |
|---|---|
| `template` | どのひな形から作ったかの札。一覧の区分（戦闘・ボス・防衛・護衛・奪取）と、残りの数の表示（「ターン 4/5」など）に使う |
| `conditions` | 条件の並び。**並び順が、同時に成り立ったときの優先順** |
| `counters` | 数え |
| `mission` | お題の名前。条件ではなく、しくみの入切（護衛ならトロッコが進む・奪取なら宝を拾える・敵の「的」の狙い）。今までどおり |

前の形のステージ（`conditions` がなく、`mission`・`ex`・`overrides['mission.defense.turns']` で勝ち方を持つもの）は、読むときにひな形へ展開する。内蔵のシナリオとチュートリアル、`stages/*.json`、ブラウザに残したステージ、みんなのステージのどれも同じ。エディットで直して残すと、展開した `conditions` を持つ形になる。

## 1つの条件

| 項目 | 中身 |
|---|---|
| `id` | 名前（ステージの中で重ならない） |
| `when` | いつ見るか（下の表）。複数なら並べる |
| `if` | 何を見るか（部品の組み合わせ） |
| `then` | `"win"` 勝ち／`"lose"` 負け／`"canClear"` クリアできるようにする（右下に「クリアする」が出る。勝手には勝たない）／`"mission"` ミッション達成 |
| `once` | `true` で一度だけ。ミッションは書かなくても一度だけ |
| `text` | 説明の文。画面の勝ち方の欄とミッションの欄は、ここから出る |
| `done` | 成り立ったときの文（決着の文）。なければ `text`。`{turn}` は今のターン数になる |
| `showIf` | 書くと、これが成り立つときだけ `text` を画面に出す（例: 突進の敵がいるときだけ「ふさいだらクリア」と書く） |

### いつ見るか

| `when` | いつ |
|---|---|
| `afterDamage` | ダメージを当てたあと・トロッコが進んだあと・ターン終了処理のダメージのあと |
| `turnEnd` | ターン終了処理が終わったあと（増援・次のターンの敵の移動より前） |
| `allyMoved` | 味方が自分で移動を終えたとき |
| `afterShot` | 魔法を1発撃ち終わるたび（敵の魔法も） |
| `afterFire` | 味方の一回の発動がぜんぶ終わったあと。一斉では、構えを全員ぶん撃ち終えたあと。1人ずつでは、その味方（か構える味方）が撃ち終えたあと |
| `always` | いつ聞いても。`canClear` 専用（`canClear` は `always` でしか書けない） |

- `afterShot` で勝ち負けを書くと、連鎖の途中で決着して、あとの人は撃たない。作ったら勝ちの類は `afterFire` と `turnEnd` で見る。

### 同時に成り立ったとき

- 同じときに見る条件の中で、負けが勝ちより先。
- 同じ側は、`conditions` の並び順で先のもの。
- 決着したら、もう何も見ない。

## 部品（`if` に書くもの）

どれも `{ "see": 名前, … }`。数は `min`（以上）・`max`（以下）・`eq`（ちょうど）。書かなければ「1以上」。

| `see` | 何を見るか | 例 |
|---|---|---|
| `units` | 絞ったユニットの数 | `{ "see": "units", "where": { "side": "enemy" }, "eq": 0 }` |
| `unitIn` | 絞ったユニットが、マスのどれかにいる | `{ "see": "unitIn", "where": { "kind": "wagon" }, "cells": "goal" }` |
| `tiles` | タイルの種類と数。`in` を付けると、そのマスの中だけ | `{ "see": "tiles", "tile": "forest", "in": [[2, 3], [3, 3]], "min": 2 }` |
| `turn` | ターン数 | `{ "see": "turn", "min": 5 }` |
| `died` | このとき、絞ったユニットが倒れた・壊れた | `{ "see": "died", "where": { "side": "ally", "npc": true } }` |
| `counter` | 数え | `{ "see": "counter", "name": "lostVillages", "min": 1 }` |
| `path` | 道がつながっているか | 下 |
| `spawn` | 増援の出てくる所がある（`where` で動き方などを絞れる） | `{ "see": "spawn", "where": { "stand": "rush" } }` |

組み合わせ: `{ "all": [ … ] }` かつ／`{ "any": [ … ] }` または／`{ "not": … }` ではない。

- `died` の「このとき」は、その1回の操作（1手、またはターン終了のひとまとまり）の中で、ここまでに倒れたもの。
- 「敵が0体」だけでは、最初から敵がいないステージですぐ勝ってしまう。ひな形は「このとき敵が倒れた、かつ敵が0体」と書いている。

### 絞り方（`where`）

書いた項目をぜんぶ満たすユニット。

| 項目 | 値 |
|---|---|
| `side` | `"ally"`・`"enemy"`・`"object"`（村・トロッコ） |
| `kind` | `"village"`・`"wagon"` |
| `stand` | 敵の動き方（`"move"`・`"still"`・`"march"`・`"rush"`・`"boss"`・`"float"`） |
| `npc` | `true` 構える味方／`false` 動かせる味方 |
| `magic` | 魔法の名前 |
| `carrying` | `true` 宝を持っている |
| `not` | 中の絞り方に当てはまらないもの |

マス（`cells`・`in`）は、`"goal"`・`"exit"`（ステージのゴール・帰り口）か `[[x, y], …]`。

### 道

```json
{ "see": "path",
  "from": [ { "units": { "side": "enemy" } }, "spawn" ],
  "to":   { "nextTo": { "kind": "village" } },
  "walk": "rush", "people": "ignore", "is": "closed" }
```

| 項目 | 中身 |
|---|---|
| `from` | 出発点の並び。絞ったユニットのいるマス（`units`）／`"spawn"`（増援の出てくる所）／マス（`cells`） |
| `to` | 行き先。絞ったユニットの隣（`nextTo`）／マス（`cells`） |
| `walk` | 通り方。`"rush"` 突進の敵と同じ（通れる地形で、水たまり・泥沼でない）／`"foot"` 通れる地形（省略でこれ） |
| `people` | `"ignore"` 人はいないものとして見る（省略でこれ）／`"block"` 人のいるマスは通れない |
| `is` | `"open"` どれかから着ける（省略でこれ）／`"closed"` 出発点が1つ以上あって、どこからも着けない |

`walk: "rush"` は、突進の敵が動くときと同じ部品（`rules.js` の `WALKS.rush`）を使う。突進の決まりを変えると、ふさぎの答えもいっしょに変わる。

## 数え

```json
"counters": {
  "madeVolcano": { "add": { "see": "tiles", "tile": "volcano", "min": 1 }, "on": "afterShot", "reset": "never", "keepOnRetry": false }
}
```

| 項目 | 中身 |
|---|---|
| `add` | 何で増えるか。`died` なら、倒れた数だけ、倒れたそのときに増える。ほかの部品なら、`on` のたびに、成り立っていれば1増える |
| `on` | いつ数えるか（`when` と同じ名前。`always` は不可）。省略で `turnEnd` |
| `reset` | いつ0に戻すか。`"never"`（省略でこれ）か条件（成り立ったら0） |
| `keepOnRetry` | `true` で、やり直しをまたいで残す |

今のひな形が使うのは、防衛の壊れた村（`lostVillages`）だけ。`on`・`reset`・`keepOnRetry` は、のちにヒントを同じ形に乗せるための枠。

## ひな形

エディットの「勝ち方」で選ぶと、この並びが `conditions` に入る（`rules.js` の `expandTemplate`）。入ったあとは普通の条件で、ファイルの中で1つずつ外せる・足せる。

| ひな形 | 入る条件（この順） |
|---|---|
| `annihilate` 敵を全員倒す | `npcDown` 構える味方が倒れたら負け → `allDown` 味方が全員倒れたら負け → `killAll` 敵を全員倒したら勝ち |
| `defense` 村を守る | `npcDown` → `allDown` → `villageLost` 村が1つ壊れたら負け → `hold` 決めたターンの終わりまで村が残れば勝ち → `seal` 村への道をふさぎきったらクリアにできる → `killAll` |
| `escort` トロッコをゴールへ | `npcDown` → `allDown` → `wagonLost` トロッコが壊れたら負け → `wagonGoal` トロッコがゴールのマスにいたら勝ち |
| `retrieve` 宝を持って帰り口へ | `npcDown` → `allDown` → `bringBack` 宝を持った味方が帰り口のマスにいたら勝ち（自分で移動を終えたとき・風で運ばれたとき） |
| `boss` ボスを倒す | `anyDown` 味方が1人でも倒れたら負け → `bossDown` ボスがいなくなったら勝ち |

- 守るターン数は、エディットで決めた数が `hold` の数と文に入る。
- ③のミッション「火山を作る」は、ボスのひな形のあとに並ぶ普通の条件（`then: "mission"`、撃ったあとに見る）。エディットでボスの勝ち方を外すとミッションも外れ、戻すと戻る。
- ボスの勝ち方の取り巻きの湧き・ヒント・負けたときの自動のやり直しは、条件ではなく `ex` が持つ（今までどおり）。

## 例: この自然を作ったら勝ち

一度でも火山ができたら勝ち。3人目の桜吹雪まで見せてから決着する。数えで「できた」を覚えておくので、そのあと火山を壊しても勝ち。

```json
"counters": { "madeVolcano": { "add": { "see": "tiles", "tile": "volcano", "min": 1 }, "on": "afterShot" } },
"conditions": [
  { "id": "makeVolcano", "when": ["afterFire", "turnEnd"],
    "if": { "see": "counter", "name": "madeVolcano", "min": 1 },
    "then": "win", "text": "火山を作る", "done": "火山ができた！（勝利）" }
]
```

盤面に残っていたら勝ち、と書くこともできる（発動の中で壊してしまうと勝たない）。

```json
{ "id": "keepVolcano", "when": ["afterFire", "turnEnd"],
  "if": { "see": "tiles", "tile": "volcano", "min": 1 },
  "then": "win", "text": "火山を残す" }
```

## 確かめ

`node tests/conditions.js`（部品・数え・ひな形・前のステージの読み替え・画面の文）。形の正しくない条件のステージは、読むときに理由の文を出して読まない（`rules.js` の `checkConditions`）。
