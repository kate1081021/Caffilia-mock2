# 自然と魔法とシナジー

魔法を撃つとマスが自然になり、自然に別の魔法が当たると別の自然やシナジーになる。このゲームの中心。
1戦の進み方は [遊び方](遊び方.md)。考え方の決まり（法則から出す・動詞・段階）は `CLAUDE.md` の3〜6章。

（11/03 時点のコードから書いた。標準の設定 `game/balance.js` で、展示のステージもエディットもこの動きをする）

## ひと目で

```
創造          繁栄                     破壊（2段目）          破壊（3段目）
草 → 森  ──→  森を並べる ─ 火 → 炎 ──→  風 → 燃え広がり
                       └ 時間で隣の森へ燃え移る
山 → 山  ──→  山をくっつける ─ 火 → 火山 ──────────────→  風 → 桜吹雪
                         └ 水 → 川が流れ出す（道をふさぐ・村を押し流す）
```

広げた自然が大きいほど大きく壊れる。つながった森が多いほど燃え広がりは広く燃え、つながった火山が大きいほど桜吹雪の扇は広い。

## 魔法

形の図は、術者（人）が上を向いているとき。■ が形のマス。形のマスすべてで同じように効果が起きる。

| 魔法 | 動詞 | 形 | 空きに撃つと |
|---|---|---|---|
| 草 | 植える | 2マス先と、3マス先の横3マス（T字） | 森 |
| 土 | 盛る | 2マス先と左、3マス先の左（3マス） | 山 |
| 山 | 盛る | 2マス先を真ん中に十字（5マス） | 山（十字の山を一度に） |
| 火 | 点ける | 正面1マス | 小さな炎（単体では弱い。マッチの火） |
| 水 | 流れる | 正面1マス。ぶつかった所に作用する | 水たまり |
| 風 | 運ぶ | 正面2マスを吹き抜ける | 「風」がそのマスに残る（ターン終了でやむ）。通り道の人や置きものを風下へ1マス運ぶ |

```
草          土          山          火・水     風
■■■ 3      ■□□ 3      □■□ 3
□■□ 2      ■■□ 2      ■■■ 2                  □■□ 2
□□□ 1      □□□ 1      □■□ 1      □■□ 1      □■□ 1
□人□       □人□       □人□       □人□       □人□
```

- 動詞は `CLAUDE.md` 6章のもの。ゲームのログには、草と土は「置く」、風は「吹き抜ける」と出る（`game/rules.js` の `MAGIC_INFO`）。
- 山・川・火山などにぶつかると、水や風はそこで止まる（山の陰では風が止まる）。
- **人に当てたとき**: どの魔法も直撃のダメージ（味方1・敵3）に加えて、足元にも自然ができる。足元に山ができた人は、山の外へ押し出される。水は人にぶつかって止まる。風は人を風下へ運ぶ。
- **水辺の森**: 水（川・水たまり）に接して草を植えると、森が水に沿って隣にも広がる。

## 自然

| 自然 | 通れるか | どうやってできるか | 性質 |
|---|---|---|---|
| 森 | 通れる | 空きに草 | 燃える。つながった森は燃え広がりで全部燃える。水は森で止まる |
| 山 | 通れない | 空きに土・山 | くっついた山は1つの山脈になり、頂上と斜面を持つ（頂上は、かたまりの真ん中に一番近いマス）。風と燃え広がりを止める |
| 炎 | 通れる（上でターン終了すると2） | 森に火・燃え広がりで燃えた森 | 強い火。ターン終了ごとに隣の森へ燃え移る。2ターンで燃え尽きて空きに戻る |
| 小さな炎 | 通れる | 空きに火・燃え広がりの通り道 | 弱い火。燃え移らない。ターン終了で消える |
| 水たまり | 通れる | 空きに水・風が川の水を運ぶ | 水の材料（土で泥沼、火で蜃気楼） |
| 川 | 通れない | 山（か丘）に水を当てると流れ出す | 盤の端まで流れる壁。人の足元も流れ、村は押し流す（壊れる） |

| 火山 | 通れない | 山に火（山脈ごと一気に） | 隣と上にいる者に、ターン終了ごとに熱で2。風で桜吹雪 |

| 風 | 通れる | 空きに風 | ターン終了でやむ |
| 蜃気楼 | 通れる | 水たまりに火 | 中にいる者は敵から見つからない。風で晴れる・水で水たまりに戻る |

ほかにも、試しの魔法でできる自然がある（下の「試しで残っているもの」）。

## シナジー

### 創造・変化（納得できること）

1人の魔法で自然を作り、別の魔法で作り変える。結果は動詞と自然の性質から予想できる。

- 森に火 → 炎（森は燃える）
- 山に火 → くっついた山脈がまるごと火山になる（火が山に点く）
- 川・水たまりに土 → 泥沼（水に土を盛る）
- 炎に土 → 山（土をかぶせて火を消す）
- 炎に水 → 消える
- 水たまりに火 → 蜃気楼（水が熱であぶられる）。風で晴れる
- 川に風 → 水を風下へ運んで水たまり（風は運ぶ）

### 山に水 → 川が流れ出す（源流）

水が山に当たると、山の高さで流れる向きが決まる（水の向きではない）。

- **斜面に当たる**: 当たった所から、下り（頂上と反対）の向きへ川が流れ出す。
- **頂上に当たる**: 4方向すべてへ川が流れ出す（1マスの山は頂上）。
- 川は盤の端まで流れる。人の足元も流れ（ダメージなし）、村に流れこむと村を押し流して（壊れる）そのまま流れ続ける。
- 川は通れない壁になる。②「2人で守る」の答えは、山を盛って、その腕に水を当て、村への道を川でふさぐこと。

### 燃え広がり（破壊2段目）

炎か小さな炎に風が当たると起きる。森 → 火 → 風。3人それぞれに役割がある（植える・点ける・放つ）。

- 風が当たった炎から、風下へ最大3マス走る。通り道の空きは小さな炎になる。
- 通り道に森があれば、その森とつながった森が全部燃える（炎になる）。
- 燃えた森の上にいる者は強い炎で 20、ほかの範囲（通り道・起点）は弱い炎で 5 ＋ 火傷。味方も巻き込む。
- 山・川・火山などで止まる。山に届くと、火が山に点いたのと同じく山脈ごと火山になる（燃え広がりのあとに火山。連鎖が順に見える）。
- 森が多いほど燃える範囲は広い。ダメージの大きさは森の数では増えない。

### 桜吹雪（破壊3段目）

火山に風が当たると起きる。山 → 火 → 風。

- 火山の花びらが、風下へ扇の形に舞い散る。扇の中の敵は、浮いている敵も含めてまとめて 20。
- 扇は、つながった火山の幅（風と直角の向き）から始まり、1段ごとに左右へ1マスずつ広がる。つながった火山の一番先から、さらに3段先まで届く。火山1つなら 1・3・5 マスの扇。
- 空きのマスには花びらが積もる（ターン終了で散る）。吹き終えた火山は冷えて山に戻る。
- ③「3人でつなぐ」は、十字の山 → 火山 → 桜吹雪で、ボスと取り巻きをまとめて吹き飛ばすステージ。

## 時間で変わるもの

ターン終了ごとに、決まった条件・決まった量で変わる。乱数は使わない。敵の自然も同じ。

1. 炎が隣の森へ燃え移る（ターン終了の始めの盤面で、同時に決まる）。準備した森が崩れる圧にもなり、「火と風は同じターンに」という連携にもなる。
2. 炎の上にいる者に 2、火山の隣と上にいる者に 2（熱）、火傷の者に 2。
3. 炎は、できてから2回目のターン終了で燃え尽きて空きに戻る（いま燃え移ったマスはここから数える）。
4. 小さな炎が消える・花びらが散る・風がやむ。

## 試しで残っているもの

エディットで味方に持たせて試せる魔法と決め手。展示のステージでは使っていない。画面とログでは【新案】の印が付く。

| 魔法 | 動詞 | 形 | 起きること |
|---|---|---|---|
| 雷 | 走る | ジグザグ4マス | 森に落ちると炎。水（川・水たまり）に落ちると**感電**: つながった水全体に走り、上と隣の全員に 20 |
| 氷 | 凍らせる | 正面へ2マス、最初に当たったものに作用 | 水に当たると**凍結**: つながった水が氷になる（歩いて渡れる。風で押されると氷の上を滑る）。炎を消す・溶岩を山にする。氷に火で水たまり |
| 闇 | 吸う | 正面1マス | 森の命を吸って、つながった森が死の森になる。死の森に火で**オバケヤシキ**（まわりの者を引き寄せて 20） |
| 旋風 | 巻く | 正面の2×2 | つむじ風を置く（竜巻は今は起きない） |

- 残っている風に火を当てると**火の渦**（2×2で燃え上がる）。火の渦に水で**センタクキ**（まわりを回して 20、渦は消える）。
- 切ってあるもの（`game/balance.js` で入れると動く）: 自然が育つ（土 → 丘 → 山 など。`grow.enabled`）、竜巻（`tornadoRecipe`）、噴火の溶岩（`funka.lava`）。

## 数を変えるには

数はすべて `game/balance.js` にある。よく触るもの:

| 数 | 場所 |
|---|---|
| 魔法の形 | `shapes` |
| 水が流れる長さ・風の長さ | `waterLength`・`breezeLength` |
| 燃え広がりの長さ | `spread.maxLength` |
| 炎の強さ・火傷・燃え尽き | `fire` |
| 桜吹雪の扇 | `eruption` |
| 火山の熱 | `stage3.heat` |
| 試しのシナジーの入・切 | `ideas` |
