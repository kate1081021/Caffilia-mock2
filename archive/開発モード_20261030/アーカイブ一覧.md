# アーカイブ一覧（開発モード、10/30）

IMPROVE_v3 段1（オーナー 10/30）で、本体から外したもの。このフォルダは、外す前のモックをまるごと写したもの（git の `00a6e39` の版）。

## 開き方

- このフォルダの `index.html` をダブルクリックすると、**外す前の開発モード**がそのまま開く（ラボ・調整パネル・スーパープレイなど全部）。
- 展示モードで見たいときは、右下の点を2秒長押し。
- 気をつけること: ダブルクリックで開いたときは、本体と同じブラウザの保存（localStorage）を使う。
  - 自分のステージ（エディットで作ったもの）は、本体とこの写しの両方から見える。
  - この写しの調整パネルで保存した数値・ラボの判定は、この写しの中でだけ効く（本体は読まない）。

## 本体に残したもの（外していない）

- ルール（`rules.js`）の中身。シナジー・お題・チュートリアルの決まりは、エディットで作るステージでも使う。外したのは、ラボの呼び口（`lab(...)`・`LX` など約110か所）だけ。
- 「1人ずつ」（`B.turnMode = 'single'`）の決まり。ルールのテストがこの形で動いているため。画面ではいつも一斉。
- シナリオ（`rules.js` の `PRESETS`）。ルールのテストが使うため。画面の一覧からは外した。
- `texts_io.js`（texts.js の読み書きの道具）。texts.js の形を確かめるテスト（`tests/simul.js`）が使うため。
- `tests/autoplay.js`・`tests/mission_search.js`・`tests/playtest.js` などの、ルールの探索の道具。
