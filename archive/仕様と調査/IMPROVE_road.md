# IMPROVE_road — 1本の道と、盤面側で見える育ち（ラボ N、10/16）

元: オーナーとの会話（10/16）。NOTES.md「変化までの道のりの見せ方」。

## やること

### 1. ルール: N6「1本の道」（切り替え。クエスト制と「N 分かれ道」でオン）

- 魔法ごとに1本の道。変化のマスまで `len` マス（初期3）。
- ミッションを取ると、その形（やりたいことの形）でマスを1つ埋める。
  - 自分のやりたいことと合う形（覚醒方面の印）か、ほかの形（融合方面の印）か。数え方は N2 のまま。
- `len` マスが埋まったら変化。自分の形が多ければ覚醒側の姿、ほかの形が多ければ融合側の姿。
  - 同点（len が偶数のとき）は、最後に埋めた形で決まる。
- 変化するまで、何も閉じない。2本の道を作って「先に着いた方へ進み、もう片方を閉じる」はしない。
- 変化したあと:
  - 覚醒側: 自分の形の印が `awake`（N1、初期3）たまると覚醒。ほかの形の印は間の強化だけ。
  - 融合側: 道はここまで。印は間の強化だけ。
- 間の強化は今のまま（印1つで1つ。形に関係なく同じ並び）。
- N6 がオフなら、今の「2本の道・早い者勝ち」のまま。

### 2. 形と色

やりたいことごとに形と色を1つずつ（色は今の N の色）。

| やりたいこと | 形 | 色 |
|---|---|---|
| 倒す | ◆ | 赤 |
| 広げる | ● | 緑 |
| 動かす | ▲ | 紫 |
| 止める | ■ | 青 |
| どれでも | ★ | 灰（どの魔法でも自分の形として数える） |

### 3. 画面: 盤面側（左）だけで分かる

オーナーは遊ぶとき盤面側しか見ない。右の「ターゲット」はそのまま残す。

- **盤面の上**: ミッションを形つきで並べる。取ったら、取った魔法の名前を出す。
- **駒の下**: 道のマス（変化前は len マス、覚醒側に変化したあとは覚醒までのマス）。この戦いで取った印は、薄く先に入れて見せる（勝つと道に入る）。
- **味方を選ぶと、盤面のすぐ下に魔法カード**: 名前と動詞・形（小さな図）・性質（一言）・道・次の一手で何に変化するか・間の強化。
- 撃つ前の予測と育ちの画面の言葉も、1本の道の言い方にする。
- クエストボードの「行き先」は、仲間ごとに埋まる形（例 ◆◆○）で見せる。

## 作らないこと

- 変化したあとの道の形（オーナーが未決）。今は上のとおり仮。
- 魔法の性質の文の作り込み（一言の仮）。
