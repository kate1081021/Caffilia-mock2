## 1. これは何か

**カフィーリア**は、タイル型の盤面で魔法を撃って戦う戦略ゲーム。このモックは、そのうち**シナジー部分だけ**を確かめるためのもの。

- コア: **自分たちで広げた自然を、シナジーで一気にぶっ壊す快感。** 流れは「創造 → 繁栄 → 破壊」。
- 目的は敵を倒すこと。シナジーはその決め手。なくても削れるが、倒すにはシナジーが欲しい強さに置く。
- 作り: 素の HTML/CSS/JS。`index.html` をダブルクリックで動く。外部ライブラリ・ビルドなし。Claude Code で実装している。

### 目指すもの

- やりたいこと（必ず向かう）: シナジーを起こす快感／魔法を現実に存在させ、信頼を得る／盤面で楽しませる
- やってみたかったこと（このモックで試す）: 魔法で敵の進路を誘導する／何もない所に撃つ（味方撃ち）に価値を持たせる／環境を利用して倒す

### 1戦で起きてほしい4つ（10/6 決定）

1. 全然関係ないところに撃った一手が、勝利につながる（準備）
2. 敵を魔法で妨害し、罠にはめる（進路の誘導・妨害）
3. 敵を利用する（敵の魔法・自然を材料にする）。「同じ土俵で戦っている」裏付け
4. 見ているだけで楽しい（大きくなって、一気に変わる）

> 準備しておいた自然に、敵を誘導・妨害して誘い込み、敵自身の魔法も材料にして、最後に一気に変わって勝つ。

## 2. 守っている決まり

### 段階ごとの優先

| 段階 | 中身 | 優先すること |
|---|---|---|
| 創造 | 魔法を撃つとマスが自然になる。自然に別の魔法で別の自然に | 納得感。動詞と現実から結果が予想できる |
| 繁栄 | 自然が広がる（プレイヤーが並べる＋法則どおり自ら広がる） | 納得感と読みやすさ |
| 破壊 2段目 | 広げた自然を壊して敵ごと吹き飛ばす。現実の災害 | 気持ちよさ。予想できるが派手で大きい |
| 破壊 3段目 | 変わった自然をさらに壊す。超常の必殺技 | 気持ちよさと突飛さ。見て分かればいい |

- 突飛さが許されるのは3段目だけ。2段目までは「どの自然の性質 × どの魔法の動詞」で1文で説明できること。
- シナジーは結果から逆算しない。性質と動詞を先に決め、そこから導く。
- 時間で自然が広がるなら「見える（予告される）・一定（乱数なし）・曲げられる・現実に沿う・敵にも同じ」をすべて満たす。今あるのは「炎はターン終了ごとに隣の森へ燃え移る」。
- 順序がシナジーを決める。先にある自然が「舞台」、後から来た魔法が「出来事」。「〇〇があるところに△△が来たから□□になった」と言えること。

### 柱

1. 法則に例外はない。敵にも味方にも同じルール（味方も風で運ばれ、炎で焼ける）
2. 創造 → 繁栄 → 破壊
3. 立ち位置と向きで決まる（着弾点は選べない）
4. 見て楽しい。連鎖が1つずつ見え、決め手は派手に

### 魔法の動詞

| 魔法 | 動詞 | 進み方 |
|---|---|---|
| 草 | 植える | 置く。空きマスにいきなり森 |
| 土 | 盛る | 置く。空きマスにいきなり山 |
| 火 | 点ける | 単体では弱い（マッチの火） |
| 水 | 流れる | 正面へ流れ、ぶつかった所に作用 |
| 風 | 運ぶ | 術者の向きへ吹き抜け、通り道のものを風下へ |

ほかに雷（走る・高い所に落ちる）、氷（凍らせる）、闇（吸う・試し）がある。新しい魔法は動詞を1つ決めてから。

### カフィーリアの制約（モックでも必ず守る）

- 味方3人、1人1魔法。ターンは「味方全員 → 敵」。味方の行動順は自由
- 魔法は決まった複数マスの形を持つ。着弾点は選べない（立ち位置と向きで決まる）
- 移動してから撃つ。撃ったら手番終わり
- 盤面6×6・移動2（小さい規模で楽しめるかを確かめている）
- 1マスに自然は1つ。乱数なし。撃つ前に結果が全部見える
- 敵は大きく強く、こちらはほぼ一撃でやられる（意図した手触り）

### やらないこと

- マナや自然の濃淡／確率で起きる効果／条件を満たさない時間変化／正解の組み合わせがないと壊せない形／元からある地形に頼ること／現実でも珍しい事象（落石、鉄砲水など）
- 持ち帰り中（オーナーが決めるまで実装しない）: 渦（風がグルグル巻く。「運ぶ」とどう両立するか）、センタクキ（渦が決まってから）、向い火（表現が決まってから）

### オーナーの判断基準（これまでに決まったこと）

- イメージから遠い前提はいらない。「ここに撃ったら変わる」でいい（ゼルダの伝説のような手触り）
- 壊す方向（2段目）は現実とつながっているべき。空想（3段目）は少し違う方面でもいい
- 決め手のダメージは一定で20（敵1体を1発で倒せる）。材料の大きさで変わるのは範囲。ただし大きいほど強いとイメージできるものは、大きいほど強くてよい
- 盤面に置いてあるものは、全部魔法で作れるもの
- シナジーは基本1人で起こすものではない。ただし最終強化の融合魔法は一撃でシナジーを出せる
- 敵は予告を先に出す（敵の狙いが分かる → 潰す）
- 難しいのはいいが、分からないのは避ける
- 見たいのは、倒せなくても場面が大きく変わって、見ているだけで楽しい場面

## 4. 今の標準ルール（シナジー）

決め手の威力はどれも20。【試し】は切り替えで試している途中のもの。

### 魔法が自然になる

| 魔法 | 空きに撃つと | 自然に撃つと |
|---|---|---|
| 草（植える） | 森（4マス） | 山 → 桜【試し】 |
| 土（盛る） | 山（3マス） | 川・水たまり → 泥沼、炎 → 埋まって山 |
| 火（点ける・正面1マス） | 小さな炎 | 森 → 炎、山 → 山脈ごと火山、水たまり → 蜃気楼、氷 → 水たまり、風 → 火の渦【試し】、死の森 → オバケヤシキ【試し】 |
| 水（流れる） | 池（2マス） | 山 → 源流（盤の端まで川）、炎 → 消える、蜃気楼 → 川、火の渦 → センタクキ【試し】 |
| 風（運ぶ・正面2マス） | 通り道の者を1マス運ぶ。通り道に風が残る | 川 → 水たまり、炎 → 燃え広がり、桜 → 桜吹雪、蜃気楼 → 晴れる |
| 雷（走る） | 高い所に落ちる | 森 → 炎、水 → 感電 |
| 氷（凍らせる） | 最初に当たったものに作用 | 水 → 凍結、炎 → 消える、ユニット → 足が凍る |
| 闇（吸う）【試し】 | まわり2マス以内の者を1マス引き寄せる | 森 → つながった森がまとめて死の森 |

- **人の足元にも自然ができる（10/13 から標準）**: 草・土・水を人に当てると、立てる自然なら足元にもできる（敵にも同じ）。

### 2段目（現実の災害）

| 名前 | 流れ | 起きること |
|---|---|---|
| **燃え広がり** | 草 → 森 →（火）炎 →（風） | 炎から風下へ最大4マス。通り道とつながった森がまとめて燃える。山・川で止まる。一番の看板 |
| 火の渦【試し】 | 風（残る）→（火） | 2×2の渦。ターン終了で炎になる。火 → 風（燃え広がり）と順序で結果が変わる例 |
| 感電 | 山 →（水）源流で川 →（雷） | つながった水全体に走り、水の上と隣の全員に当たる |
| 凍結 | 川・水たまり →（氷） | つながった水がまとめて氷に。川の壁が氷の道に変わる（オーナーが面白いと感じた） |
| 落雷で山火事 | 森 →（雷） | 森に落ちれば燃える |

### 3段目（超常）

| 名前 | 流れ | 起きること |
|---|---|---|
| 桜吹雪【試し】 | 土 → 山 →（草）桜 →（風） | 桜から風下へ扇形に花びら。今の標準は草で桜（元は火山から） |
| センタクキ【試し】 | 風 →（火）火の渦 →（水） | 渦のまわりの輪が回る。渦は跡形もなく消える |
| オバケヤシキ【試し・中身は仮】 | 草 → 森 →（闇）死の森 →（火） | まわりを引き寄せ、中と隣に20。中身はオーナーが考え中 |

### 時間で変わる（ターン終了）

- 炎は隣の森へ燃え移る（「燃」と予告）、2回で燃え尽きる（「尽」と予告）
- 火傷: 弱い炎に当たると、ターン終了ごとに2を2回。水か氷で治る
- 小さな炎は消える、風はやむ、火の渦は解けて炎に、花びらは散る

### 育つ（一段と二段）【試し・切り替えで入る】

同じ魔法をもう1回当てると、そのものらしい大きさに育つ。土: 丘 → 山（十字5マス）、草: 草むら → 森、水: 水たまり → 川、風: 風 → 強風、火: 小さな炎 → 炎。測った範囲では盤面8×8が一番ゲームになっている（6×6は窮屈、10×10は遠い）。人の手触りは未確認。

### 外したもの

竜巻・火炎竜巻・つむじ風・旋風（風は「渦巻く」より「まっすぐ吹く」と想像されるため）、噴火の溶岩、闇で水を凍らせる、渦（山の陰で回る）。

### ラボを作って分かったこと（判定の前に知っておくとよいこと）

- **起こした本人が巻き込まれる問題**が、オバケヤシキ・水蒸気爆発・粉塵爆発・金の柱・雨の帯（感電）・最終融合でくり返し出た。火・闇・金・水の形が術者のすぐ隣から始まるので、まわりに広がる決め手は必ず本人に届く。デモは「丘の上から撃つ」「敵に点けさせる」「C2 を入れる」でよけている。法則を変えずに直すなら、形が離れて届く（G2・G3・高台）ことが前提になる。
- **一直線の決め手（花筏・土石流・雪崩・かまいたち・岩落とし）は強すぎる可能性。** どれも盤の端まで届き、並んだ敵をまとめて倒す。デモの多くが1ターン勝ち。
- **「人の足元にも自然ができる」で、「敵の足元に森を植えて燃やす」が1手で済むようになった。** 森に誘う手間（D1 欲「森」、E1 囮の森、E2 偽の姿）の価値が下がる。誘う系の案は、この決まりのオン・オフで判定が変わるはず。
- **今の法則では成り立たないと分かった案**: E6 向い火（燃え移りに向きがない）、E12 敵の風に乗る（直撃で倒れる）、D9／E8 の「壊す」（できた風の舞台を消す手がない）。
- デモが組めなかった案: E3 追い込み（逃げる先が読めない）、B18 吹雪（風が人を押し出すので吹雪に人が残らない）。

## 7. 今の課題

| 課題 | 邪魔している体験 |
|---|---|
| **3段目（決め手）が簡単に組めて強い。** 3人で1ターンに最後まで通せるので、作った自然を活用せずに毎回シナジーで片づく | 準備、縛る |
| **移動にデメリットがない。** 撃ちたい所にだいたい届く／敵の予告を歩いて避けられる | 準備、縛る |
| **3人＝3つの魔法なので、パーティがそのままレシピになりがち** | 準備、敵を利用 |
| 決め手の隣に術者が立ち、同じターンに起こすと巻き込まれる | 決め手 |
| 森の筋と山の筋が同じリズム（置く → 火 → 風）。案: 桜吹雪は高い所から舞うので壁を越える、燃え広がりは地面を走るので止まる | 見て楽しい |
| 人も山も1マスという縮尺の違和感 | 魔法を現実に |
| 盤面の印が多くて分かりにくい | 分からないのは避ける |

ラボの C（決め手）・A（地形）・F（移動と手番）・G（強化）は、上の上3つの課題への答えの候補として作ってある。

## 10. 案の出し方（Claude に新しい案を頼むとき）

次の順に照らしてから、1つずつ出す。

1. 制約とやらないことに触れていないか
2. 目指すもののうち、どれに近づくか（どれにも近づかない案は出さない）
3. どの段階か（創造・繁栄・破壊2段目・破壊3段目）
4. その段階の基準を満たすか（2段目までなら、どの性質と動詞から出るかを1文で）
5. 敵にも同じルールで働くか
6. 立ち位置・向きで結果が変わるか
7. 広げた自然が大きいほど結果が大きくなるか（破壊の案）
8. 見て楽しいか。連鎖が目で追えるか

```
案: （名前）
目指すもの: （どれに近づくか）
段階: 創造／繁栄／破壊2段目／破壊3段目
法則: （どの自然のどの性質と、どの魔法の動詞から出るか）
敵にも: （敵が同じことをしたらどうなるか）
見え方: （盤面で何がどう動いて見えるか）
```
