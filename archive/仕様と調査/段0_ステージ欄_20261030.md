# 段0 ステージ欄（IMPROVE_v3、10/30）

## 今の形

```
ステージ  直すたびに自動で残る
 名前 [〇〇の森]
 [一覧 ▼] [読み込む] [削除]          ← 段2で開発の最初の画面へ移す
 [新しいステージ] [ファイルに書き出す] [ファイルを読み込む]   ← ファイルの2つは段4でなくす
 自分のステージ 9つ。直すたびに、このブラウザに自動で残ります。
```

- **保存ボタン・JSON（文字）の書き出し・読み込みは、なくした。**
- 直すたびに、このブラウザの「自分のステージ」に自動で残る。読み込み直しても残っていた。
- 自分のステージが増えるとき: 新しいステージ・チュートリアルの写し・ファイルを読み込む。名前が重なると「新しいステージ（2）」「① 重ねるのコピー（2）」のように番号が付く。
- 名前を変えるとき、ほかの自分のステージと重なる名前は受け付けない（「もうあります」と出る）。名前を変えても「1手戻す」で戻せる。
- 削除: 確かめの窓を出してから消す。開いているステージとチュートリアルは消せない。
- 作るモードは、開くと最後に開いていたステージの続きから。
- 開発モードで自分のステージを遊んでいるときに E を押すと、写しではなく、そのステージを開く。

## 前の作りかけ・前の保存の移し替え

開発・作るモードを開いたときに、一度だけ自分のステージに移す。

| 前のもの | 自分のステージでの名前 |
|---|---|
| 作りかけ | 作りかけ |
| 1つ前の作りかけ | 1つ前の作りかけ |
| 前の保存（配置だけ） | その名前 |

- 中身が同じ自分のステージがあれば足さない（同じものが2つ並ばないように）。
- 今の形に直せないものは移さず、数をステージ欄に出す。
- 元のデータは消さずに残す。
- **オーナーのブラウザでは、次に開発か作るモードを開いたときに移る。**

## 確かめたこと（内蔵ブラウザ。確かめ用のデータで）

- 前の作りかけ・1つ前の作りかけ・前の保存2つ（1つは壊れたデータ）・保存済みのステージ1つ を用意して作るモードを開く → 3つが移り、壊れた1つは「直せず、移していません」と出た。元のデータは残っていた。
- 森を塗る → 読み込み直す → 森が残っていた。
- 名前を「保存済み」（もうある）にする → 受け付けない。「ぼくの森」にする → 一覧も変わる。1手戻す → 「作りかけ」に戻った。
- 新しいステージを2回 → 「新しいステージ」「新しいステージ（2）」。チュートリアル①の写しを2回 → 「① 重ねるのコピー」「（2）」。写しに①の会話の文も入っていた。
- 削除: 開いているステージ → 消せない。確かめで「いいえ」→ 残る。「はい」→ 消えた。チュートリアル → 消せない。
- E でテストプレイ → E で戻る → 同じステージのまま。
- 開発モード: 自分のステージ「保存済み」を遊んで E → 写しを作らず、そのまま開いた。チュートリアル②で E → 「② 2人で守るのコピー」ができた。
- ファイルを読み込む → 「保存済み（2）」として自分のステージに増えた。
- コンソールのエラーなし。
