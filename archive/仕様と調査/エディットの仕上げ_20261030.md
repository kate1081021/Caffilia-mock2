# エディットの仕上げ（10/30）

ステージを組んで、その場で遊んで、直して、また遊ぶための道具にした。開発モード（`#dev`）だけで使える。

```
  エディット ──E──▶ テストプレイ
      ▲                 │
      └───────E─────────┘  作っていた盤面と「1手戻す」の履歴のまま戻る
```

## 頼まれたことの判定

| できるか確かめたこと | 判定 | どうなっているか |
|---|---|---|
| 編集とテストプレイを1つの操作で行き来する | 足した | E か「▶ テストプレイ」「✎ エディットに戻る」のボタン |
| 盤面の大きさを変える | 足した | 前は正方形だけ。横と縦を別々に変えられる |
| 自然を置く（もとからある山も） | すでにあった | 24種類すべて。山の頂上と斜面は自動で決まり、描かれる |
| 味方を置く（魔法・向き） | すでにあった | |
| 敵を置く（種類・向き・動き方） | すでにあった | |
| 敵の HP | 足した | 敵ごとに数字で入れる |
| 村を置く | すでにあった | |
| 勝ち負けの条件を選ぶ | 足した | 6つから選ぶ（下の表） |
| 名前を付けて、いくつでも保存する | 足した | 前の保存は「配置」だけで、勝ち方の一部・HP・文が残らなかった |
| 一覧から選んで読み込む | 足した | シナリオの一覧の「作ったステージ」からも遊べる |
| チュートリアル①②③を写して編集し、別の名前で保存する | 足した | 元のチュートリアルと texts.js は書き換わらない |
| 会話の窓の文（開始・クリア・負け・やり直しのヒント）を打ち込む | 足した | エディットの欄に打つ。ステージと一緒に保存される |
| 書き出したファイルをほかのパソコンで読み込む | 足した | `cafilia-stage-名前.json` |
| 編集中の操作を1つ戻す | 直した | 前からあった。ただし遊んだ手の履歴とまざっていたので、編集だけの履歴に分けた |

### 勝ち方（どれも今あるルールの決まり）

| 選べるもの | 中身 |
|---|---|
| 敵を全員倒す | 今までの戦闘 |
| ボスを倒す | ③の決まり。味方が1人でも倒れたら負け |
| 村を守る | 決めたターンの終わりまで守る |
| 道をふさぐ | ②の決まり。ふさいだら「クリアする」（C）で勝ち |
| 馬車をゴールへ | 護衛 |
| 宝を持って帰り口へ | 奪取 |

足りない置きもの（村がない・ボスがいない など）があると、勝ち方の下に出る。

## できなかったこと・決まりで止めたこと

- 敵は3体まで、味方は3人まで。どちらもルールの値（`balance.js`）なので変えていない。
- エディットで変えられないもの。③や②の写しからは持ち越す。
  - 敵の大きさ（3×3）と浮いている体
  - ②の増援の出る所
  - ③の取り巻きの湧き方
  - 「敵だけの魔法」。①の写しでは山の魔法が敵だけのままで、味方に持たせられない。
- エディットの欄で打てる文は、開始・クリア・負け・やり直しのヒントの4つ。
  - ほかの場面（ターンの始め・決め手・③のミッション）の文は、写した中身をそのまま持ち越すだけ。
  - チュートリアルの写しには「（ここに文章）」の行も一緒に入る。要らなければ消す。
- ラボのシナリオ専用の中身（強化・2つ目の魔法など）は、ステージに入らない。
- ほかのパソコンでも同じに遊ぶには、条件が3つある。
  - 開いたモックが同じ版であること
  - 開発モード（`#dev`）で開くこと
  - 調整パネルで保存した数値がないこと（開発モードでは保存した数値が効く。展示モードでは効かない）
- ③の写しは、開発モードでは「魔法の出し方」が今の設定（初めは「1段ずつ」）。展示と同じにするなら、盤面の上で「つながる」を選ぶ。

## 前と動きが変わったこと

- テストプレイ中でない所から E を押したときの作り始めの盤面。
  - 前: 遊んでいる途中の盤面。
  - 今: そのシナリオの遊び始める前の盤面（敵が最初に動く前）。
- エディットを抜けると、ステージとして読み込んで遊ぶ。
  - 会話の窓・やり直しのボタン・ヒントが、チュートリアルと同じように出る。
  - そのとき遊び始めた盤面が「リセット」の戻り先。
- 盤面の大きさの変更。
  - 前: 正方形にして、味方を下の段・敵を上の段に並べ直していた。
  - 今: 置いた物は同じ位置のまま。はみ出した物は外し、外した数を出す。
- 「お題の種類」の選択は「勝ち方」になった。村・馬車・ゴール・宝・帰り口を置く道具は今までどおり。
- 前の保存（配置だけ）は、一覧の「前の保存」に出て読み込める。新しく保存すると、ステージの形になる。
- エディット中は「リセット」を押せない。盤面は「1手戻す」で戻す。

## ルールには触れていない

- `rules.js` の変更は、地形の1文字の対応表（`CH`）を外から読めるようにしただけ。
- テストプレイは、チュートリアルを読むのと同じ道（`R.buildPreset` → `R.startBattle`）で始まる。
- `run`・`scenarios`・`simul`・`ex3` の出力は、前のコミットと1文字も変わらない。
  - run 47件、scenarios 39件の失敗は前からあるもの。
  - `lab` も、違うのはエラーに出るファイルの場所だけ。

## 確かめたこと

- `node tests/stages.js`（新しく足した）: 113件すべて通った。
  - どのシナリオ・チュートリアル（21個）も、ステージに書き出して読み直すと同じ盤面になる。
  - 遊び始め（敵の最初の移動と予告）まで同じ。
- 内蔵ブラウザで、次の流れを最後まで通した。
  - ②の写しに山を3つ塗る → 頂上と斜面が出る → 文を打つ → 1手戻す。
  - ▶ で遊ぶ: 敵が動き、打った開始の文が会話の窓に出る → E で同じ盤面に戻る。
  - ③の写しでボスの HP を30にして保存する → テストプレイ: ③の決まり（魔法の出し方・ミッション）のまま、ボス HP 30。
  - 勝ち方を「村を守る」にしてから「ボスを倒す」に戻す → ③の取り巻きの湧き方も戻る。
  - JSON に書き出して、別の盤面を読んでから読み直す → 同じ盤面。
  - 8×6 に縮める → 3つ外れる → 1手戻すで元に戻る。
  - 読み込み直したあと、シナリオの一覧の「作ったステージ」から遊べる。E でその名前のまま編集に入る。
  - 空の盤面から 7×5 で味方2・敵1・村1・山1、勝ち方「村を守る 3ターン」→ テストプレイ。
  - 展示モードでは E が効かず、ボタンも欄も作ったステージも出ない。
- 試しに保存したステージは、内蔵ブラウザの保存から消しておいた。
