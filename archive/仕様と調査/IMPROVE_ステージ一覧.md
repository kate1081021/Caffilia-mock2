**範囲:** 開発モードの最初の画面だけ。展示の「ステージを選んで遊ぶ」は今のまま（オーナー「いったん開発のみで」11/03）。

## 段1 難易度

- 4段: **チュートリアル／やさしい／ふつう／むずかしい**。まだ決めていないものは「なし」。
- 持たせ方: ステージの定義に `difficulty: 'tutorial' | 'easy' | 'normal' | 'hard'`（ないときは「なし」）。
  - `game/stages_io.js` の読み書き（JSON の書き出し・読み込み・自分のステージ・共有）で残ること。
  - みんなのステージの置き場所（`tools/stage_worker.mjs`）は定義をそのまま持つので、変えなくてよいはず。`tests/stage_api.js` で確かめる。
- 内蔵の①②③は「チュートリアル」に決め打ち。
- エディットの「ステージ」の欄で、名前の下に難易度を選ぶ（4つ＋なし）。直すたびに自動で残るのは今どおり。

## 段2 一覧を1行に1つ

**今:** 開発の最初の画面に「チュートリアル」「みんなのステージ」「自分のステージ」の欄があり、ステージはカードで並ぶ。

**これから:** どの欄も、1行に1つのステージ。

```
[難易度] タイトル                使う魔法      クリア方法            [今のボタン]
[やさしい] 森を焼く              火・風        敵を全員倒す           遊ぶ 作る 消す
[チュートリアル] ② 2人で守る     山・水        村を守る（5ターン）
```

- **難易度:** 色つきの小さな札。「なし」は空ける。
- **タイトル:** ステージの名前だけ。名前に区分の言葉（「チュートリアル」など）が入っているなら、ラベルの方に任せて名前から外す。どの名前を直すかは、直す前と後の画面を撮ってオーナーに見せて決める。
- **使う魔法:** 味方の魔法から自動で出す（例「火・風」）。構える味方（指示できない仲間）の魔法も入れ、印を付ける（例「火・風（仲間）」）。
- **クリア方法:** 勝ち方から自動で出す。敵を全員倒す・ボスを倒す・村を守る（防衛はターン数も「村を守る（5ターン）」）・トロッコをゴールへ・宝を持ち帰る。
- 想定シナジーは出さない。
- 今のボタン（遊ぶ・作る・消す など）は行の右端に。
- **難易度で分ける:** 一覧の上に札「すべて／チュートリアル／やさしい／ふつう／むずかしい」。押すと、その難易度のステージだけになる。並びは難易度の順、その中は今の順（自分のステージは新しく直した順）。選んだ札は localStorage に覚える（読めなくても「すべて」で動く）。
- 狭い画面では、使う魔法とクリア方法を2段目に回して、横にはみ出さない。
- 「展示の並び」（ドラッグで並べ替える画面）は今回は変えない。

## 段3 戻せるゴミ箱

**今:** 自分のステージとみんなのステージには「消す」がある（確認の窓が出て、元に戻せない。`game/ui.js` の `deleteOwn`・`deleteShared`）。

**これから:** 「消す」はゴミ箱へ移す。ゴミ箱から戻せる。

- **自分のステージ:**
  - 「消す」でゴミ箱へ移す。確認の窓は出さず、代わりに「ゴミ箱に入れた [戻す]」を数秒出す。
  - ゴミ箱はこのブラウザに置く（localStorage に新しい置き場所 `cafilia-mock-trash-v1`。`{ 名前: { 中身, 消した時刻 } }`）。
- **みんなのステージ:**
  - どのパソコンからも見える共有のゴミ箱にする（共有の置き場所の KV に `trash` を足す）。
  - `tools/stage_worker.mjs` の API を変える・足す:
    - `DELETE /api/stages/<名前>`: 完全には消さず、ゴミ箱へ移す（展示の並びに入っているものは、今どおり消せない）
    - `GET /api/all`: 答えに `trash` も入れる
    - `POST /api/trash/<名前>/restore`: 戻す
    - `DELETE /api/trash/<名前>`: 完全に消す
  - ゴミ箱にも上限を付ける（`MAX_STAGES` くらい）。いっぱいのときは勝手に古いものを消さず、「ゴミ箱がいっぱい。完全に消してから」と断る。
  - **古い置き場所の見分け:** `GET /api/all` の答えに `trash` がなければ、古い置き場所（まだ公開していない）とみなす。そのときは今までどおりの「元に戻せない」確認の窓で消す。新しい画面から古い置き場所に「ゴミ箱へ」のつもりで DELETE を送ると、本当に消えてしまうため。
- 戻すとき、同じ名前のステージがもうあれば「名前（2）」で戻す。
- 開発の最初の画面の一番下に「ゴミ箱（n）」の欄を置く（ふだんは閉じている）。
  - 1行に1つ: 名前・どこのステージか（自分／みんな）・消した日時・[戻す]・[完全に消す]。
  - [完全に消す] は確認の窓を出す。みんなのものは「⚠ どのパソコンからも消えます」。
- ゴミ箱は自動では空にしない。

**公開:** 共有の置き場所のプログラムを変えるので、公開はオーナーのパソコンのセッションで行う（CLAUDE.md 10章「公開」。オーナーが頼んだときだけ）。公開したら公開先でも、ゴミ箱へ移す → 戻す → 完全に消す を確かめる。
