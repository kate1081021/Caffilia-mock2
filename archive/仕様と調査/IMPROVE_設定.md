# 設定: 画面の色と名前を変える（オーナー 11/03）

## オーナーの言葉（11/03）

- 今の画面の色は、全部 Claude 側が決めたこと。それをこっちで調整したい。全部の色を RGB で自分で決められるようにしたい。展示に出すものも、開発モードから色を変えられるようにしたい。設定の1つとして作ってほしい。一つ一つの自然の色は一旦いいから、枠組みや背景色などのメインとなるところを変えたい。
- 別件として、名前を変えられるようにしたい。自然の表示名、マップに出る名前、シナジーの名前などの、文字の部分。これも設定から変えられるようにしたい。
- （オーナーは寝ているので、決めたことは下に書いて、朝に見てもらう）

## 決めたこと（Claude。違っていたら直す）

- **どこで変えるか:** 開発モードの最初の画面に「設定」ボタン（「展示の並び」の隣）。押すと設定の画面。変えるとすぐ、その画面の色と名前が変わって見える（まだ保存していない）。
- **どこに残すか:** 共有の置き場所（Cloudflare の KV に `settings`）。展示の並びと同じく、保存するとどのパソコンの展示モードも開発モードもその設定で出る。
  - このブラウザにも写しを覚えておき、開いたらすぐ（つながる前に）その色で出す。つながらないとき（ネットがない など）は、覚えている写しか、元の色と名前。
  - 共有の置き場所のプログラムを変えるので、公開するまで、公開先では保存できない（画面は「公開してから使える」と出す）。`node tests/serve.js` で開けば手元で試せる。
- **変えられる色（メインのところ）:** 背景・パネル（枠の中）・枠線・文字・うすい文字・大事なボタン（発動など）・ボタンの地・盤面の枠・味方・敵・敵の予告・光る印。どれも RGB（0〜255 の3つの数）と色を選ぶ窓の両方で決められる。1つずつ、と全部を「元に戻す」。
  - 自然一つ一つの色（森・山・川…）は今回は入れない（オーナー「一旦いい」）。
- **変えられる名前:**
  - 自然: 表示名（押したマスの情報・エディットの塗る道具・ログの文など）と、マップに出る字（マスの中の1〜2文字）。
  - 魔法: 名前（駒の字・ログの文など）。
  - シナジー: 名前（真ん中に出る文字・ログの文。燃え広がり・桜吹雪…）。
  - 空にすると元の名前。長さは 12 文字まで。
- **ルールは変えない。** 中で使う名前（テストやルールが見分けに使う名前）はそのままで、画面に出す名前だけを変える。node のテストは元の名前のまま動く。

## 作り

- `game/settings.js`（新しく）: 変えられる色の一覧（元の色つき）・設定の形を整える `clean`・色を当てる `applyColors`・名前を当てる `applyNames`（元の名前を覚えておき、戻すときはそこへ）・ブラウザの写し。開いたらすぐ、写しの色を当てる（`game/mode.js` のすぐあとに読む）。
- `game/style.css`: 盤面の枠（`--board-frame`）とボタンの地（`--button-bg`）を変数にする（前は決め打ちの色）。
- `tools/stage_worker.mjs`: `GET /api/all` に `settings`（まだなければ null）。`PUT /api/settings` で保存（形を確かめる）。
- `game/ui.js`: 設定の画面。共有の置き場所から読んだら、設定を当てる（設定の画面で直している間は当てない）。シナジーのログの文も、変えた名前で出す。ブラウザの「戻る」は設定の画面から一覧へ（変えたところがあれば確かめる）。
- テスト: `tests/settings.js`（形を整える・名前を当てて戻す）、`tests/stage_api.js`（保存と読み出し・正しくない形は受け取らない）。CLAUDE.md 11章のテストの一覧に足す。
