# LAB_L — ターゲットで育つ（サブターゲットと魔法の道）

始める前に、`LAB_00_base.md` の「大前提」と `LAB_PROGRESS.md` を読み直す。大前提はこのファイルでも同じ（`lab` ブランチだけで作業する、全部オフなら今と同じ、`latest` は更新しない、展示に触らない）。

## このカテゴリで確かめたいこと

魔法の強化を、戦闘の中のターゲット（サブクエスト）で決める形を試す。

オーナーの前提（10/14）

- 単なるレベルのような数値は扱いたくない
- 強化のリソースは有限で、その分配を楽しみの一つにしたい
- 戦闘でやったことを強化にしたい
- なるべく戦闘の中で悩ませたい

仕組み

- 戦闘ごとに、あらかじめ決めたターゲットが3つある
- 達成した魔法は、そのターゲットの方向に道を1マス進む
- 同じ方向に3マス進むと、魔法が覚醒して姿が変わる（草 → 大樹 など）。覚醒は戻れない

ねらい

- ターゲットという限られたものを、誰に取らせるかを戦闘中に考えさせる。シナジーで倒すと最後の一手を撃った魔法が取るので、決め手役（3人目）が取りやすい。ほかの仲間に回すか、育てたいキャラで達成するかを考える
- 戦闘でやったことが、そのまま強化になる
- ステージのマイルストーン（とりあえずターゲットを達成しよう）にもなる

オーナーが気にしていること: 分かりにくいかも。ターゲットに気が散って難しくなるかも。

関わる判定（10/13）

- H13「ここに撃とう」は ×。目標をそのまま褒美にするのは直球すぎる。ただ「撃った魔法が強化されるマスはありかも」
- G2 は △。強化の方向は魔法ごとに変えたい
- G1（一気に二段）・I5（蔓）・I6（雨）は ◎ で、強化の枝として読まれた
- G8（強化は敵が先に見せる）は ◎。このファイルでは扱わず、次の段階で足す

このファイルでは、仕組みが面白いかを確かめる。道の中身は草だけ本物を作り、ほかの魔法は仮でよい。

## 4つの方向

- **起点**: 何もないところに、自然を作る
- **育てる**: 作った自然を大きくする、つなげる
- **破壊**: 決め手を起こす、敵を倒す
- **足止め**: 敵を止める、敵の手を潰す

方向ごとに色と印を決め、ターゲット・道・予測で同じものを使う【仮】。

魔法ごとに、4つのうち3つの方向を持つ【仮】。

- 草: 起点・育てる・足止め
- 土: 起点・足止め・破壊
- 水・火・風: 育てる・足止め・破壊
- 雷・氷・闇: 育てる・足止め・破壊（仮）

## L0 土台（ルールに関係なく作るもの）　★

`balance.js` の `lab.L0`。オフならターゲットも道も出ず、今と同じ。L1〜L5 は L0 を needs に持つ。

### ターゲット

- ターゲットはデータで持つ（`lab_targets.js`）: 名前、方向、達成の判定、表示の一言。
- 2種類ある。どのステージにも出せる「型」と、そのステージだけの「目標」。シナリオは、出すターゲットを指定する（数は L3）。
- 型【仮】
  - 起点: 敵から3マス以上離れたマスに自然を作る
  - 育てる: 同じ自然を5マス以上つなげる／自然を二段に育てる（X1 育つ がオンのときだけ）
  - 破壊: 決め手で敵を倒す／決め手で2体以上に当てる／敵を1体倒す
  - 足止め: 敵が自分の番に動けなかった（泥沼・凍結・蔓・囲まれた、など理由は問わない）／敵が予告した決め手が起きなかった
- ステージだけの目標の例: 「この山に水を撃つ」。方向はシナリオで決める。
- 書き方は結果だけにする（「森を作れ」ではなく「同じ自然を5マス以上つなげる」）。どの魔法でも取れる書き方を基本にする。
- 1つのターゲットは、1戦に1回だけ取れる。1つの手で複数を達成したら、それぞれ取る。

### 誰が取ったかの記録

- 達成した瞬間に、どの手で達成したか（撃った魔法と、その材料になった自然を作った魔法）を記録する。誰が取るかは L1・L2 で決まる。
- F5（構えて一斉に発動）がオンのときは、発動の順で「最後の一手」を決める。
- 取った味方がそのあと倒れても、取ったものは残る【仮】。

### 表示

- 盤面の横に「ターゲット」の一覧: 方向の印、名前、まだ／取った味方。シナリオを選ぶ画面にも同じものを出す。
- 撃つ前の予測（一斉発動なら構えの予測）に「この一手で『同じ自然を5マス』達成 → 草の育てるが1マス進む」と出す。
- その魔法がその方向の道を持たないとき、または覚醒で閉じた方向のときは、予測に「達成するが、草は育たない」と出す。
- 達成した瞬間に、一覧のその行を光らせる。
- **レベル・経験値・点数のような数字は出さない。** 道の進み具合は印（●●○）で出す。

### 戦闘の終わり（育ちの画面）

- 勝ったら、取ったターゲットを1つずつ順に見せる。「『同じ自然を5マス』 草が達成 → 草の育てるが1マス進む」。
- その魔法の道を出す。持っている3方向、それぞれの進み具合（●○○）、覚醒先の名前。
- 同じ方向が3マスに届いたら、覚醒を見せる（魔法の名前と駒の印が変わる）。
- 負けたときは L4 に従う。

### 魔法の道

- 道はデータで持つ（`lab_paths.js`）: 魔法ごとに、持つ方向、各方向の3マスの中身（効果）、3マス目の覚醒先の名前。
- 1マス進むと、そのマスの効果がすぐ魔法に付く。予測にもそのまま出る。
- 同じ方向が3マスに届くと覚醒する。覚醒したら、その魔法のほかの方向は閉じる。それまでに進んだマスの効果は残る。閉じた方向のターゲットを取っても進まない。覚醒は戻れない。
- 覚醒した魔法は、元の動詞を含んだまま姿が変わる（草の覚醒先も、植える魔法のまま）。

### 連戦と持ち越し

- 「ターゲット連戦」: 決めた順にシナリオを続けて遊び、道の状態を持ち越す。H1（周回のミニ版、`lab_run.js`）があれば、その流れに乗せてよい。
- エディットで、味方の道の状態を直接いじれるようにする（すぐ覚醒を試せるように）。リセットもできる。

## 草の道（本物）　★

すでにラボにある案は、その処理を使う。なければこのファイルで簡単に作る。

**起点**
1. 川・水たまりに撃つと葦原（B14。渡れる、水としてつながったまま）
2. 風が残るマスに撃つと、風下の空き1マスにも森（B4 の種が飛ぶ、を草の側から）
3. 覚醒「種まき」: 形のマスに加えて、正面の奥、最初に何かに当たる手前の空きマスにも森が1マスできる

**育てる**
1. 森の形が横に1マス広がる
2. 森に撃つと、そのかたまりの外側へ1マスずつ森が広がる（I3 の茂らせる、と同じ）
3. 覚醒「大樹」: 撃った形の真ん中が大樹になる（森の一種。通れない・高い）。大樹とつながった森が燃えると、燃え広がりが2マス長く走る

**足止め**
1. 森の隣にいる者に当たると、蔓が足に絡んで次の移動ができない（I5）
2. 蔓が届くのが、森から2マス以内の者まで
3. 覚醒「茨の牢」: 森に上下左右のうち3方向以上を囲まれたマスにいる者は、移動も予告もできない（E9 と同じ扱い）。囲んでいる森がなくなるまで続く

数値・形はすべて【仮】。

## ほかの魔法の道（仮）

- 持つ方向は「4つの方向」の表どおり。
- どの方向も、1マス目と2マス目は「形が1マス増える」。伸びる向きは属性で決まる（水・風・雷・氷は奥へ、土は横へ、火・闇は斜め前へ）。G2 があればその処理を使う。
- 3マス目の覚醒は、魔法の名前と駒の印が変わるだけ。
- 覚醒先の名前【仮】
  - 水: 育てる「大河」・足止め「氷」・破壊「激流」
  - 火: 育てる「野火」・足止め「炎の壁」・破壊「業火」
  - 風: 育てる「追い風」・足止め「向かい風」・破壊「かまいたち」
  - 土: 起点「山脈」・足止め「城壁」・破壊「岩落とし」
  - 雷・氷・闇: Claude Code が仮に付ける
