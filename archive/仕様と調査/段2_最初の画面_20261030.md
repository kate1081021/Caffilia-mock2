# 段2 開発の最初の画面（IMPROVE_v3、10/30）

## 今の形

```
開発（#dev）を開く
  ┌ 開発 ─────────────────────────────┐
  │ チュートリアル   [① 重ねる] [② 2人で守る] [③ 3人でつなぐ] │
  │ 自分のステージ   [〇〇の森|消す] [作りかけ|消す] …（新しく直した順） │
  │ [＋ 新しく作る]                                          │
  └──────────────────────────────┘
      │ ステージを押す → 遊ぶ側で開く ⇄ E で作る側
      │ 上のバーの「⌂ 最初の画面」で、いつでも戻る（作っていた盤面は残る）
```

| 押すもの | どうなる |
|---|---|
| チュートリアル | そのチュートリアルを遊ぶ。E で作る側にすると「〜のコピー」が自分のステージにできる（元は変わらない） |
| 自分のステージ | テストプレイで遊ぶ。E で、そのステージを作る側へ（写しは作らない） |
| ＋ 新しく作る | 作る側で開く【仮】。味方3人・敵1体。押した時点で自分のステージが1つ増える |
| 消す | 確かめの窓のあとに消える |
| ⌂ 最初の画面 | 一覧に戻る。エディット中なら、その盤面を自分のステージに残してから |

- 展示モードは変わらない（「⌂ 最初の画面」も出ない）。
- 「みんなのステージ」は段4、「展示の並び」は段3、「試し中」は段5で足す。

## 今まで通りに動かなくなったもの

| もの | どうなったか |
|---|---|
| 開発モードを開いたとき | 最初の画面から（前は、最後に開いていた自分のステージのエディットから） |
| エディットのステージ欄 | 一覧・読み込む・削除・新しいステージがなくなった（最初の画面へ移した）。名前とファイルの書き出し・読み込みは残っている |
| チュートリアルの写しの作り方 | 前はエディットの一覧から直接。今は 最初の画面 → チュートリアル → E |
| 「開いているステージは消せない」 | 最初の画面では何も開いていないので、どれでも消せる。前に開いていたステージを消したときは、作っていた盤面も手放す |
| 前の保存を移せなかった数の一言 | エディットから最初の画面へ移した |

テストの結果は前と同じ（ルールには手を入れていない）。

## 確かめたこと（内蔵ブラウザ）

- 開発モードを開くと最初の画面。上のバーは「遊び方」だけ。
- チュートリアル① → 遊ぶ（プレイ中）→ E で「① 重ねるのコピー」ができて作る側に → 山を塗る → ⌂ で一覧に戻ると、いちばん上に並ぶ。
- 「① 重ねるのコピー」を押す → テストプレイで山が残っている → E で同じステージを作る側へ（写しは増えない。1手戻すの履歴も残っている）。
- ＋ 新しく作る → 「新しいステージ」（味方3・敵1）が作る側で開く → ⌂ で一覧のいちばん上に並ぶ。
- 消す → 確かめで「いいえ」なら残り、「はい」なら消えた。
- 最初の画面で E を押しても何も起きない。
- 展示モードは今までどおり（チュートリアル①から。⌂ は出ない）。コンソールのエラーなし。
- 確かめに作ったステージは消した。
