# 「1段ずつ」を外す・人数の上限・作るモード（10/30）

## 1. 「1段ずつ」を外した

魔法の出し方の選択肢に残っているのは、次の2つ。

| 選択肢 | 中身 |
|---|---|
| ターンの終わりにつながる | 初めの形。展示・作るモードはいつもこれ |
| 撃った瞬間に発動 | 開発モードの③だけで選べる |

- 外した処理: できたばかりの自然を覚える `s._fresh`、そこに反応しない `isFresh`（置く・火山・風の3か所）、`B.simul.stepwise`。
- ターンの形の「一斉発動」「1人ずつ」は今のまま。
- 開発モードで「1段ずつ」を覚えていた場合は、「つながる」になる。

## 2. 人数の上限をなくした

- エディットで、味方も敵も好きな数だけ置ける。6人と5体で置いて遊べた。キーの 4 で4人目も選べた。
- 新しいステージの初めの形は、今までと同じく味方3人・敵1体。
  - エディットの「空の盤面から」は「新しいステージ」に変えた。押すと、この形で始まる。
- 調整パネルから「味方の人数の上限」「敵の数の上限」を外した。
- **CLAUDE.md 7章に「味方は3人」と書いたまま**です。直すかどうかはオーナーが決めてください（Claude は書き換えていない）。

## 3. モードを3つに

```
  index.html          → 展示モード（今のまま）
  index.html#make     → 作るモード（チームに渡すのはこれだけ）
  index.html#dev      → 開発モード（今のまま）
```

- **どう分けたか**
  - 作るモードの印は `#make`（`?make` も可）。開発モードの印 `#dev` とは別。
  - `#make` があれば、`#make&dev` のように開発の印が一緒に付いていても作るモードになる。
  - `#remake`・`#develop` のような似た印は、どちらにもならない（展示モード）。
  - 作るモードの画面には、開発モードへ行くボタンもリンクもない。
  - 開いたまま URL の印を書き換えたときだけ、読み込み直してモードが変わる。
- **作るモードで出すもの**
  - エディット（置く・動かす・消す・盤面の大きさ・勝ち方・会話の文）
  - テストプレイ（E）
  - ステージの保存・読み込み・書き出し
  - 遊ぶための操作: 発動・1手戻す・リセット・遊び方・やり直す
  - 今のモードの札（エディット中・テストプレイ中）
- **作るモードで出さないもの**
  - 調整パネル・ラボ・スーパープレイ・新案プレイ
  - シナリオの一覧・ターンの形・魔法の出し方
  - くわしく・ログ・文章パネル
  - キーは展示モードのものに E だけ足した（ラボの Q・B・K は効かない）。
- **作るモードの決まり**: 展示と同じ。一斉発動・つながる。調整パネルで保存した数値も共有リンクの数値も使わない。
- **開くと**: エディットから始まる。前に作りかけがあればその続き、なければ新しいステージ。
- **気をつけること**
  - 調整の共有リンク（`#tune=…`）・`#run`・`#q`・`#n` などの開発用の入口は、今までどおり開発モードで開く。チームに渡さないでください。
  - 作ったステージ・作りかけは、同じブラウザなら作るモードと開発モードで共有される（保存場所が同じ）。
