# カフィーリア シナジーモック

**自分たちで広げた自然を、シナジーで一気にぶっ壊す快感。**

カフィーリアは、タイル型の盤面で魔法を撃って戦う戦略ゲーム。このリポジトリは、そのシナジー部分だけを確かめるためのモック。

## 遊んでみる

- `index.html` をダブルクリック → 展示モード（試遊の人が遊ぶ形）。最初の画面の「はじめから遊ぶ」で、チュートリアル①②③を順に遊べる。
- `index.html#dev` → 開発モード（ステージを作ってすぐ試す・共有する）。
- 公開版: https://caffilia-jkwzvlbc7.kate108superstar.workers.dev/latest/

## どんなゲームか

味方3人がそれぞれ1つの魔法を持ち、小さな盤面で、大きくて強い敵と戦う。

- 魔法を撃つとマスが自然になる（草で森、山の魔法で山、水で水たまり…）。
- 自然に別の魔法が当たると、別の自然に変わる（森に火で炎、山に火で火山…）。
- 自然を並べて広げる。自然も法則どおりに広がる（炎が隣の森へ燃え移る、炎に風で**燃え広がり**、山に水で川が流れ出す…）。
- 広げた自然を、超常現象で一気に壊す（火山に風で**桜吹雪**）。広げた自然が大きいほど大きく壊れる。

```
魔法（作る・変える）   →  シナジー（広げる）               →  超常現象（壊す）
草 → 森、森に火 → 炎      森を並べる、炎に風 → 燃え広がり！
山 → 山、山に火 → 火山    山をくっつけて山脈に                  火山に風 → 桜吹雪！
```

着弾点は選べない。どこに立ち、どちらを向くかで魔法の当たる所が決まる。3人が動いて構え、ターンの終わりに構えた順に一斉に撃つ。前の人が作った自然に後の人の魔法が当たって、シナジーが起きる。法則に例外はなく、敵の魔法も自然を作り、味方も炎で焼ける。

## 動かす・確かめる

素の HTML / CSS / JavaScript だけ。ビルドも `npm install` もない。node だけでテストが動く。

```bash
node tests/run.js
```

```bash
node tests/scenarios.js
```

```bash
node tests/serve.js
```

- `tests/run.js` はルールのテスト、`tests/scenarios.js` は決まった手順を最後まで動かして確かめる。ほかに `tests/simul.js`（一斉発動・チュートリアル）・`tests/ex3.js`（③）・`tests/stages.js`（エディットのステージ）・`tests/stage_api.js`（共有の置き場所）。ルールを変えたら全部通す（11/03 にすべて通るようにした）。
- `tests/` のほかのファイル（`_play.js`・`autoplay.js`・`mission_search.js`・`ex3_search.js` など）は、手を探したり数を見たりする調べもの用の道具。
- `tests/serve.js` は http://localhost:8765 で画面を開く（共有の置き場所も手元で動く）。
- Cloudflare への公開は、Claude Code に「クラウドフレアにあげて」（`.claude/skills/cloudflare-publish`）。
